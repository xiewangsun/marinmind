R4-P0 D1-01 按钮视觉重量不统一：同语义操作跨视图用不同重量

脑图 header / 阅读器工具行 / 主页 / 复习 改动量：~20 行 CSS
设计原则（R1 第五章）：「花胆量在一个地方」——签名元素之外保持克制。 按钮重量应与服务目的对齐：高频操作（工具行）用轻量 ghost 钮；关键动作（弹窗 CTA）用实底强调；开关类（自动收录）用胶囊。
现状六套按钮配方并存：.marinmind-tool-btn（reader，ghost 图标+文字）、 .marinmind-mm-autocollect（脑图，胶囊边框开关）、 .marinmind-mm-header-btn（脑图，纯图标）、 .marinmind-home-btn（主页，ghost 带边框）、 .marinmind-review-btn（复习，实底）、 .marinmind-selection-btn（选区工具栏，纯图标 30×30）。 P2-2 已文档化激活态语义（工具态 accent 实底 / 导航态 hover 底色），但未做视觉收敛。 核心问题：「复习」入口在三处重量不同——阅读器工具行是 ghost 钮、脑图 header 是胶囊开关、主页导航是 div 行。

R4-P1 D4-02 同功能菜单项顺序不一致

脑图 / 阅读器 / 主页 改动量：~15 行 TS（仅 reorder）
三视图右键菜单中「编辑标题/批注」「打标签」「设卡组」「删除」的排列顺序不同：
  • 脑图节点：编辑 → 标签 → 卡组 → 链接 → … → 删除
  • 阅读器高亮：查看原文 → 编辑 → 标签 → 卡组 → … → 删除
  • 主页卡片：编辑 → 标签 → 卡组 → … → 删除
「编辑」应在最前（最高频操作），「删除」应在最后（危险操作，需扫到末尾才触发）。现状基本符合，但「翻译」/「复制」等工具类操作位置不统一。
改法：统一菜单项顺序为：定位类 → 编辑类 → 链接类 → 工具类（翻译/复制/书签） → 复习类 → 脑图类 → 删除。 风险：低（仅顺序调整）。验证：三视图右键菜单顺序一致。
