# 使用教程

> 当前版本（0.1.x）处于**开发早期**：数据层已就绪，尚无完整用户界面。
> 本文档先覆盖安装与开发流程；随功能落地逐步补充使用说明。

## 安装插件（开发者方式）

1. 克隆本仓库并安装依赖、构建：

   ```bash
   npm install
   npm run build
   ```

2. 将构建产物放入 Obsidian 库的插件目录：

   ```
   <你的库>/.obsidian/plugins/marinmind/
   ├── main.js        # 构建产物（含内嵌 SQLite WASM）
   ├── manifest.json  # 插件元数据
   └── styles.css     # 样式（当前为空）
   ```

   Windows 也可用符号链接代替复制（需管理员权限）：

   ```bat
   mklink /D "<库>\.obsidian\plugins\marinmind" "D:\work\ff_ProjCollection\marinmind"
   ```

3. 在 Obsidian 中打开 **设置 → 第三方插件**，关闭安全模式后启用 **MarinMind**。

## 日常验证

- 点击左侧功能区 📖（book-open）图标，或命令面板（Ctrl+P）执行
  **"打开 MarinMind 阅读器（选择 PDF）"**——模糊搜索库内 PDF 后新标签页打开。
  （"打开 MarinMind 工作区"仍为占位提示。）
- 执行 **"显示库统计（文档 / 卡片 / 待复习）"**——验证数据库是否正常初始化，
  会显示当前 文档数 / 卡片数 / 待复习数。
- 启用插件后，库根目录会出现隐藏目录 `.marinmind/`，其中 `marinmind.db`
  即 SQLite 数据库（删除该目录 = 清空 MarinMind 数据）。

## 用阅读器做区域摘录（v1 核心功能）

1. **打开 PDF**：功能区 📖 或命令面板 → 选择库内 PDF（支持输入目录名过滤）。
2. **浏览**：连续滚动阅读；工具栏 ＋ / ／"适应宽度"按钮调整缩放，
   拖动窗格宽度会自动重排。
3. **摘录**：点击工具栏 **✏（square-pen）** 开启摘录模式（按钮高亮）→
   在页面上按住左键拖出矩形 → 松手即生成知识卡片，黄色高亮即时回显。
   - 拖拽过程中点右键可取消；
   - 过小的框（< 6px）视为误触自动忽略；
   - 从右下往左上反向拖拽也可以，会自动归一。
4. **查看/删除卡片**：点击任意黄色高亮 → 菜单显示卡片信息 → 可删除。
5. **持久化**：关闭标签重开、重启 Obsidian 后高亮原位恢复；
   在文件管理器里重命名 PDF，卡片归属自动跟随。
6. 再次点击 ✏ 关闭摘录模式，恢复正常滚动/点击。

> 说明：阅读器是独立视图，**不改变** PDF 的默认打开方式——
> 文件管理器双击 PDF 仍是 Obsidian 内置视图。
> 文字划选摘录（textLayer）在下一版本提供，当前请用区域框选。

## 开发工作流

```bash
npm run dev   # watch 模式：修改 src/ 自动重建 main.js（Obsidian 中重载插件即可看到变化）
npm test      # 运行全部单元测试（vitest）
npm run build # 生产构建（类型检查 + 打包）
```

## 常见问题

- **启用后提示"数据库初始化失败"**：查看控制台（Ctrl+Shift+I）中的错误日志；
  尝试删除 `.marinmind/marinmind.db` 后重启（当前版本尚无生产数据，可安全重建）。
- **升级插件后数据丢失**：数据存放在 `.marinmind/`，与插件目录分离，
  正常更新插件不影响数据。
