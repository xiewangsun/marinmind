# 使用教程

> 当前版本（0.1.x）：**主页 / 阅读器（PDF·EPUB·Markdown）/ 脑图 / 复习四视图均已就绪**，
> 数据层为 Markdown 文件存储（库内 `MarinMind/` 目录，可直接阅读与同步）。
> 本文档覆盖安装与全部使用流程。

## 安装插件（开发者方式）

1. 克隆本仓库并安装依赖、构建：

   ```bash
   npm install
   npm run build
   ```

2. 将构建产物放入 Obsidian 库的插件目录：

   ```
   <你的库>/.obsidian/plugins/marinmind/
   ├── main.js        # 构建产物（md 存储引擎 + 迁移期保留的 SQLite 读取器）
   ├── manifest.json  # 插件元数据
   └── styles.css     # 样式（阅读/复习/脑图）
   ```

   Windows 也可用符号链接代替复制（需管理员权限）：

   ```bat
   mklink /D "<库>\.obsidian\plugins\marinmind" "D:\work\ff_ProjCollection\marinmind"
   ```

3. 在 Obsidian 中打开 **设置 → 第三方插件**，关闭安全模式后启用 **MarinMind**。

## 日常验证

- 点击左侧功能区图标（layout-dashboard），或命令面板（Ctrl+P）执行
  **"打开 MarinMind 主页"**——进入主页总览（见下节）；打开 PDF 改为主页侧栏底部
  「打开 PDF」按钮或命令 **"打开 MarinMind 阅读器（选择 PDF）"**。
  也可用「学习/研究模式工作区」一键分屏（见下文）。
- 执行 **"显示库统计（文档 / 卡片 / 待复习）"**——验证数据层是否正常初始化，
  会显示当前 文档数 / 卡片数 / 待复习数 / 脑图数。
- 做第一条摘录后，库根目录会出现 `MarinMind/` 目录——**你的全部笔记数据就是普通
  Markdown 文件**（每书一个 md、每图一个 md、媒体附件在 `assets/`），
  可直接在 Obsidian 中浏览搜索（删除该目录 = 清空 MarinMind 数据）。
  这是默认位置——可在插件设置中把数据目录改到其他位置（见下文「设置与数据管理」）。

## 主页：书库总览与文档分类（㉟，㊲ 增强）

点击功能区图标或命令「打开 MarinMind 主页」，进入 **Linear 风格主页**（默认深色；
㊸ 起可在设置中切换**浅色**或**跟随 Obsidian 主题**）。左侧窄栏导航 + 右侧内容区，四个页面：

- **概览**：文档/卡片/待复习/脑图四块统计（点击数字跳对应页）；快捷操作行
  （打开 PDF / 开始复习 / 新建脑图）；最近卡片 8 条（点击弹**摘录预览**，㶈）、
  最近文档 5 条、最近脑图 3 张。
- **文档**：左列是**多层分类文件夹树**（全部 / 未分类 / 各分类，带数量，子分类
  缩进显示；搜索框旁的 ▣ 按钮可**整栏收起/展开**（㊸）——收起后列表/书架占满
  全宽，选择自动记住）；右侧**搜索框**（按标题或路径过滤，输入即时生效）与
  **列表 / 窗格切换按钮**（㊵，见下）+ 文档列表或封面书架（卡数 + 最近更新时间；
  「库外」「已失联」徽标提示状态）。**点击 = 打开文档**；右键有归档菜单，
  也可直接**拖拽到左列文件夹**归档（见下）。
- **卡片**（73 两列布局）：全部卡片按更新时间倒序浏览——**左列卡组树**（全部 /
  未分组 / 多层卡组文件夹，见下「卡片卡组管理」；筛选行最左 ▣ 按钮可整栏收起，
  与文档页各自独立记忆）+ 右侧**书籍 / 形态 / 标签 / 颜色四下拉筛选**（70 起含
  颜色：选项从全库卡片实际用色派生，含旧色相与「未设色」；可任意组合，与左列
  卡组选择叠加；标签下拉带 # 前缀，一卡多标签含即命中）+ 结果计数，每页
  50 条分页翻页（上一页 / 下一页——箭头为图标；点击卡片弹**摘录预览**，见下；
  卡片行右键 / 拖拽可归入卡组，行尾显示卡组徽标）；选中某个**卡组路径**后计数旁
  出现**「复习本组」**按钮——按该组**及其子卡组**开练；**任一筛选**激活后出现
  **「复习筛选结果」**按钮——按当前五维筛选出的卡片临时组一场复习（70）；
  「待复习」统计砖旁另有**「统计」**弱链接打开复习统计面板（69）。
  **批量删除（74）**：筛选行右侧的 ☑ **「批量」按钮**进入批选模式——每行卡片
  首尾出现勾选框（点击行即勾选/取消，可跨页翻页累积），计数变为
  **「已选 N / M 张」**，旁有**「全选本页 / 取消本页」**与**「删除 N 张」**
  （选中为 0 时禁用）——删除前有确认弹窗（连同附件、双向链接、脑图节点与
  复习进度一并删除）；再点「批量」按钮退出模式。**改动任何筛选条件或切走
  页面会自动清空选择**（防止跨筛选误删）。
- **脑图**：全部脑图列表（节点数 + 更新时间 + 📖 书籍图徽标），点击打开；
  右上「＋ 新建脑图」。

阅读器里新建/编辑/删除卡片时，打开的主页会**自动刷新**（约 0.1s 内合并更新）。

### 文档分类（多层虚拟文件夹）

分类**不移动任何文件**——只是给书打一个分类标签（存在该书的数据文件 frontmatter
里），列表按分类分组显示。删除分类不会删除任何文档或卡片。分类名支持**多层路径**
（用 `/` 分隔，如 `学习/英语`），左列按层级缩进显示成文件夹树；**点击某个文件夹
显示它及其全部子孙分类下的文档**。

- **归档（三种方式）**：① **拖拽**文档行到左列某个文件夹上（高亮提示）松手即
  归入——拖到「未分类」即取消归类，「全部」不可作目标；② 右键文档行 →
  「归入分类」下点某个分类全路径；或「新建分类并归入…」输入新分类名；③
  「移入未分类」取消归类。
- **新建分类**：文档页左列底部「＋ 新建分类」——输入多层路径即建，**空分类也会
  保留**（76 起写入数据根的 `分类.md` 清单，重开主页/重启后仍在树上；把全部文档
  移出后分类也不消失）。
- **重命名/删除分类**：右键左列的具名分类（悬停节点有「右键或长按」提示，74）→
  重命名（该分类**及其子分类路径**
  一起跟随，如重命名「学习」后「学习/英语」变为「新名/英语」）/ 删除（其下
  全部文档含子分类移入「未分类」；**空分类直接删除不弹确认**）。
- **搜索**：文档页列表上方搜索框，按标题或文件路径过滤（不区分大小写），与
  左侧分类选择叠加生效；中文输入法连续输入不会被打断。
- **手编清单（76）**：空分类记录在数据根的 `分类.md`（每行一个 `- 路径`）——
  可直接在 Obsidian 里增删行（保存后主页树即时更新，删除文件 = 清空清单；
  有文档在用的分类不受影响，它们由书文件自身携带）。`卡组.md` 同理。
- **窗格视图（㊵ 封面书架）**：文档页搜索框右侧的两个图标按钮切换
  **列表 / 窗格**——窗格以 **PDF 封面缩略图书架**展示每本书（**每行 6 个**瓷片，
  ㊸——窄窗口自动降为 4 个/2 个防挤碎；封面 + 书名 +
  卡数；库外/失联/分类徽标叠在封面右上角）。选择会**自动记住**（重启后保持）；
  封面按需渲染（第一次稍候即出，之后走缓存秒显）；打不开的文件（失联 /
  移动端库外）显示占位图标。瓷片的点击打开、右键菜单、拖拽归档与列表行为
  完全一致。
- 移动端：右键菜单用**长按**唤出，操作相同（拖拽归档不可用）。

### 卡片卡组管理（73，操作与文档分类一致）

卡组（deck）是卡片的分组标签——**每张卡片至多属于一个卡组**，与文档分类一样
不建实体、删除卡组不删卡片。卡组名支持**多层路径**（用 `/` 分隔，如
`学习/英语`），卡片页左列按层级缩进显示成文件夹树；**点击某个卡组显示它及其
全部子孙卡组下的卡片**（「复习本组」也按此子树范围开练）。

- **归组（三种方式）**：① **拖拽**卡片行到左列某个卡组上（高亮提示）松手即
  归入——拖到「未分组」即移出卡组，「全部」不可作目标；② 右键卡片行 →
  「归入卡组」下点某个卡组全路径；或「新建卡组并归入…」输入新卡组名；③
  「移出卡组」取消归属。
- **新建卡组**：卡片页左列底部「＋ 新建卡组」——输入多层路径即建，**空卡组也会
  保留**（76 起写入数据根的 `卡组.md` 清单，与空分类同款）。
- **重命名/删除卡组**：右键左列的具名卡组（悬停节点有「右键或长按」提示，74）→
  重命名（该卡组**及其子卡组路径**
  一起跟随，如重命名「学习」后「学习/英语」变为「新名/英语」）/ 删除（其下
  全部卡片含子卡组移出卡组，卡片与复习进度不受影响；**空卡组直接删除不弹确认**）。
- **设卡组的其他入口（76 起为选择器）**：复习界面导航条「⋯」管理图标按钮（106
  起纯 icon 化，悬停提示「管理卡片」）与卡片摘录预览
  弹窗的动作行——点「设卡组」弹出**卡组选择列表**：可输入筛选、当前卡组带
  「当前」徽标、列表含全部已定义卡组与「＋ 新建卡组…」（输入新名即建即归入），
  已有卡组的卡可「移出卡组」；命令面板「按卡组复习」的选卡器与卡组树同源。
- 移动端：右键菜单用**长按**唤出，操作相同（拖拽归组不可用）。

### 卡片摘录预览（点卡片先看摘录区域，㶈；91 分区重排）

在主页**概览的最近卡片**或**卡片页**点击一张卡片，不再直接跳去文档——先弹出
**只框定摘录区域**的预览弹窗（91 起为卡片式分区布局，自上而下）：

- **卡片头**：标题（标题 > 批注 > 摘录文字 > 形态占位，与列表显示同源）+
  徽标行（形态胶囊 + 《书名》· 第 N 页）；
- **摘录区域图**（视觉主体）：
  - 手写/照片/语音卡直接显示**内容快照/附件**（套索快照保持原始轮廓裁形）；
  - 文字/留白卡显示**原文页裁剪窗口**——只有摘录附近一小块（自动带少量上下文行），
    摘录区域以彩色下划线/描边轮廓**框定标示**（㊹ 线稿同源观感），不用在整页里找；
    **111 起矩形/套索卡同显页裁剪窗口**（与复习卡同形态，110 起裁剪范围参照
    文字摘录——页比例上下文 + 约半页宽最小窗口，不再紧贴区域显窄），内容快照
    降为原文失联时的兜底；
- **加载速度（112）**：弹窗打开瞬间先显示「摘录图加载中…」占位；同一本书的
  卡片在 60 秒内重复打开**即时出图**（已解析文档空闲保留复用），只有冷首开
  （该书本次会话第一次预览）需要稍候（读文件 + 解析 + 渲染）；
- **「摘录 / 批注」带标签分区**（85-D + 91）：摘录块（OCR 识别文字即在此）与
  批注块各有独立展示位——未被标题吸收的内容都可见，与复习正反面同语义；
- **元信息行**：卡组徽标 + 标签（#tag）+ 相对时间；
- 预览确认要看上下文时，点 **「跳原文」**（右上箭头图标）进阅读器精确定位（同原跳转行为）；
  直接关弹窗则不打扰当前工作区。
- 操作区（91 起 MN3 式收敛）：**跳原文 / 标题批注 / 复制链接** 三钮直放
  （跳原文仅文档卡显示）；其余动作收进 **「⋯」菜单**（与阅读器工具栏溢出菜单
  同一范式）：**复制嵌入 / 打标签 / 设卡组 / 删除**（确认后弹窗关闭、列表自动
  刷新）；**照片卡的「编辑遮挡」**（71）也在 ⋯ 里——在快照上拖框划复习遮挡，
  见「闪卡遮挡」；**语音卡的「重录」**（84-C）同在 ⋯ 里——确认后删除旧卡
  （含附件）并立即开始新录音，见「语音摘录」。
- 附件缺失或原文文件读不了时降级为提示文字（跳原文入口照常可用，失联请走
  文档管理重关联）。

## 用阅读器做摘录（v1 核心功能）

MarinMind 提供 MarginNote 同款的四类摘录工具：**文字 / 矩形 / 套索 / 留白**。
阅读器有**单行工具栏**（89 起 MarginNote 3 式只放图标、悬停显示名称；90 起为
**唯一顶栏**——原生标题行已隐藏，文件名显示在工具栏最左侧）：
文件名 ·「目录」（目录/书签侧栏，见下文）· 四个摘录工具（左下角带**色点**显示当前
色系，**再点一次已激活的工具 = 循环切色**）·「手写」（PDF 专属，见「媒体摘录」）
·「复习」·「搜索」（当前文档全文检索，见「文档内搜索」）· 右侧**视图切换循环钮**
（见「视图切换」）· 末尾
**「⋯」溢出菜单**——低频工具折叠于此（菜单里图标+文字齐全）：手型 / 选择 /
插入图片摘录 / 录音摘录（见「媒体摘录」）/ AI 摘录（PDF 专属）/ 缩放… /
摘录目标脑图 / 自动转闪卡，勾选态随当前状态
刷新（当前工具是手型/选择时 ⋯ 按钮点亮提示）。
窗口/分屏变窄时工具栏**恒为单行**（91）——先收缩截断文件名，图标按钮不换行
（极窄时右缘按钮才会被裁剪）。**选中的摘录工具保持激活**，可连续摘录不必重复点按钮；按 **Esc** 随时退回
文字摘录（默认工具）。

### 通用流程

1. **打开文档**：主页侧栏底部「打开文档」按钮或命令面板 → 选择库内 PDF 或
   Markdown 文档（㊻-B，见「阅读 Markdown 文档」一节；支持输入目录名过滤）；
   桌面端还可打开库外 PDF（见下节）。**重新打开自动回到上次读到的页**（80）——
   每本书独立记忆（滚动停下片刻后记录，存于书文件），从主页/命令/文档管理
   打开都生效；记忆的是**你最后停留的阅读位置**——从卡片「跳原文」/工作区
   恢复这类定位式打开（82）看完即关不会改写它（在落点继续滚动阅读才从落点
   续记），阅读器内目录/书签跳转则算移动阅读位置照常记录。
2. **浏览**：连续滚动阅读；**Ctrl+滚轮**缩放（以鼠标位置为中心，仅 PDF），
   或「⋯ → 缩放…」菜单（放大 / 缩小 / 适应宽度，菜单顶部显示当前百分比；
   89 起原头部三枚缩放按钮并入于此）。**精确缩放（104-A）**：菜单里
   100% / 150% / 200% 预设一键直达，或「输入缩放比例…」直接输入百分比
   （支持 `150` / `150%` / 全角 `％`，回车即用，超出 20%-500% 自动钳到边界
   并提示）。**固定缩放档位与页内阅读位置会记忆**
   （㊳）——重启 Obsidian、切走再切回标签，缩放和滚到的位置原样恢复，不再弹
   回页顶；"适应宽度"档随窗格宽度实时变化，不做记忆。
3. **选工具**：点工具行的四枚摘录工具（当前工具高亮）；手型（只读平移）与
   选择（纯文本复制）在「⋯」菜单里切换（见下文各节）。
4. **摘录**：按各工具方式选取内容，确认后即生成知识卡片，高亮即时回显。
5. **查看/管理卡片**：点击任意高亮 → 菜单可 转为闪卡 / 编辑标题/批注 / 颜色… /
   翻译 / 加入思维导图… / 删除卡片。
6. **持久化**：关闭标签重开、重启 Obsidian 后高亮原位恢复；
   在文件管理器里重命名 PDF，卡片归属自动跟随。

### 手型工具（只读浏览）

- 在「⋯」菜单选中后**按住拖拽即可平移页面**（滚轮照常滚动）；此时为纯阅读
  模式，不会误触发文字选中或摘录；⋯ 按钮点亮提示当前处于非常规工具。

### 选择工具（纯文本选择，㉖）

- 在「⋯」菜单选择（对标 Acrobat 的「文本选择工具」）：在页面上**划选文字后
  Ctrl+C 复制**——只想摘抄一段话到别处、又不想生成卡片时用它。
- 与「文字」摘录工具的区别：**划选不建卡**（选区纯用于复制）；想划选成卡请用
  「文字」工具。选中状态下点击高亮块仍可打开卡片管理菜单。

### 文字摘录（默认工具，适合定义/结论/段落）

- 像普通网页一样**按住左键划选文字**，松开弹出**划选工具栏**（75 起，见下节），
  点工具栏按钮生成卡片：摘录文本 + **逐行彩色下划线**
  （㊹ 线稿式——只画下划线不填充背景；多行选区 = 逐行下划线；
  77 起线型可选波浪线/删除线，见「摘录颜色」节）。
- **逐行自动修剪**：PDF 每行行尾常带成段空白，多行选区会把它们一并圈进来——
  生成卡片前会**逐行收缩到每行首/末个实际文字**，高亮只覆盖文本本身、
  摘录文本按行拼接（行内多余空白折叠），整行空白自动丢弃。
- 选区跨页会提示"跨页摘录请分次选择"；扫描版 PDF 无文字层无法划选
  （可先用矩形摘录，再走 OCR 识别文字）。

### 划选工具栏（75，微信读书式）

- 划选松开后浮出在**选区上方**（上方空间不够自动落在下方，水平自动钳在
  阅读器范围内），选区保持高亮可见；**滚动页面时工具栏跟随选区移动**。

| 按钮 | 功能 |
| --- | --- |
| 四个色点 | **以该颜色一键建卡**（浅黄/浅绿/浅蓝/浅红——选色摘录一步到位，最快捷） |
| 摘录 | 以当前文字工具色建卡（色系可用工具行循环切色预设） |
| 线型 | 弹三选菜单切换**文字摘录线型**（下划线/波浪线/删除线，当前项打勾；按钮图标随当前线型变化）。选后工具栏与选区保留，接下来的色点/摘录建卡即用新线型（77） |
| 翻译 | 打开翻译弹窗（13 种目标语言；译文可复制或**存为留白**——落在原文正下方并排对照） |
| 复制 | 选中文本复制到剪贴板 |
| 添加书签 | 在选区所在页加书签（书签名 = 选中文本前 30 字）；Markdown 文档书签停用不显示此钮 |
| 全局搜索 | 把选中文本填入 Obsidian 全局搜索 |

- **关闭/收起**：按 **Esc** 或在页面空白处按下鼠标即收起（选区保留，可继续
  用 Ctrl+C 复制）；点工具栏任一按钮执行动作后自动收起并清空选区。
- **恢复旧版直接建卡**：设置 → MarinMind → **「阅读」→ 划选工具栏** 关闭，
  划选松开即直接建卡（75 之前的原有行为）；默认开启。
- 「选择」工具（纯文本选择）划选**不弹工具栏也不建卡**，语义不变（㉖）。

### 矩形摘录（适合图表/公式/版面）

- 切到矩形摘录后在页面上**按住左键拖出矩形**，松手生成卡片（㊹ 只画**彩色边框**
  不填充）。
- 拖拽中右键取消；过小的框（< 6px）视为误触；从右下往左上反向拖拽自动归一。
- **内容快照**（⑳，㉛ 起 WebP；㊽ 起 md / EPUB 电子书同样支持）：框选区域的内容
  会同时截成图片存档（WebP 格式，比 PNG 小很多；iPhone 上自动回退 PNG）——拖进脑图
  的节点、复习界面的正面都直接**显示所框的图像**（不再只有占位文字）；
  旧版本创建的区域卡在对应页面再次渲染时**自动补拍快照**，无需重新摘录。

### 套索摘录（适合不规则区域）

- 切到套索摘录后在页面上**自由绘制闭合路径**，松手生成套索卡片（㊹ 只描
  **彩色轮廓线**不填充）；
  工具保持激活可**连续圈选**多块区域；右键取消当前套索；极小抖动自动丢弃。
- **高亮保持原始轮廓**：圈出的形状原样保存与回显（凹凸不规则形状也原汁原味，
  拖动中实时预览同款）；跳转原文按轮廓包围盒精确定位。
- **内容快照**（⑳；㊽ 起 md / EPUB 电子书同样支持）：圈选内容截成图片（轮廓外的
  部分透明），脑图节点与复习正面按原始形状显示；旧卡同样在页面再次渲染时自动补拍。
- 升级前创建的套索卡片（三块矩形近似）不受影响，照常显示；重新圈选一次即变为原状轮廓。

### 留白摘录（适合随时补充想法）

- 切到留白摘录后**点击页面任意空白处** → 弹出"留白备注"输入框 → 保存后生成
  **备注胶囊**（㊹ 不透明主题底 + 彩色边框，直接显示备注前 40 字，悬停看全文），
  保存有成功提示；
  6×6px 锚点矩形同时入库保证可精确定位。
- 工具保持激活，可**连续点击**添加多条备注；点已有高亮块不触发。
- **挪开挡住正文的胶囊（101）**：胶囊左缘有竖排抓握点（grip），**按住它拖动**
  即可把胶囊挪到页面任意位置（拖动范围限本页），松手自动记住新位置——
  译文留白、AI 摘要卡等所有胶囊都能挪。

### 摘录颜色（㊹ 四色体系 + 循环切色，MarginNote 3 式）

- 摘录颜色共 **浅黄 / 浅绿 / 浅蓝 / 浅红** 四色，全部为线稿式标注：
  文字 = 下划线、矩形 = 边框、套索 = 轮廓描边、留白 = 胶囊边框，不遮挡原文内容。
- **循环切色**：**再点一次已激活的摘录工具按钮**即循环切换该工具色系
  （黄→绿→蓝→红，按钮左下角色点即时变化 + 提示条显示当前色）——
  切好后接下来的摘录都按新色生成；**文字/矩形/套索/留白四种工具各自独立记忆**，
  重启 Obsidian 后保持。
- **改已有卡片颜色**：点击任意高亮块 → 菜单选 **「颜色…」** → 弹出四色色板任选
  ——按主题分类标注：比如定义用黄、结论用绿、疑问用红。
- 改色**即时同步到所有地方**：本页高亮、其他标签页打开的同一本书、
  脑图节点的标题栏底色、往脑图拖卡时的预览，全部一起变；重启后保持。
- 各摘录形态的默认色：文字/矩形/套索/留白跟随各自工具色（默认浅黄）、
  手写绿、照片/语音浅红；旧版本创建的其他色卡照常按原色显示。

### 文字摘录线型（77 下划线 / 波浪线 / 删除线）

- 文字摘录的高亮形态有三种：**下划线**（默认）、**波浪线**、**删除线**——
  颜色与线型自由组合（比如红色波浪线、蓝色删除线）；线型只作用于文字摘录，
  矩形/套索/留白等其他形态不受影响。
- **切换新建卡线型**（三入口，全局记忆）：
  1. **划选工具栏「线型」钮**：弹三选菜单（当前项打勾），选后工具栏与选区保留，
     接下来的色点/摘录建卡即用新线型；
  2. 设置 → MarinMind → **「阅读」→ 文字摘录线型** 下拉；
  3. AI 一键摘录的批量文字卡同样跟随该设置。
- **改已有卡片线型**：点击文字高亮块 → 菜单选 **「线型…」** → 三选菜单任选
  （当前项打勾）——按语义标注：比如重点用下划线、待斟酌用波浪线、已否定内容用删除线。
- 改线型**即时同步到所有地方**：本页高亮、其他标签页打开的同一本书，全部一起变；
  复习溯源缩略图与主页卡片预览里的行下划线/波浪线/删除线同观感；重启后保持。

> 说明：手型/矩形/套索/留白任一工具激活时，指针被工具接管、文字层暂不可划选——
> 按 Esc 或点"文字"切回即可恢复划选。
> 阅读器是独立视图，**不改变** PDF 的默认打开方式——
> 文件管理器双击 PDF 仍是 Obsidian 内置视图。

### 打开库外文档（桌面，㉞；㊼ 起收 PDF/EPUB）

电脑上放在 Obsidian 库**之外**的文档（如网盘同步目录、移动硬盘里的书）也可以直接阅读，
**不会把文件复制进库**：

1. 任选一个入口：
   - 文档选择弹窗底部的 **「📂 打开库外文档…」** 按钮（弹出系统文件对话框，可选
     PDF / EPUB）；
   - 命令面板 **「打开库外文档（桌面）」**（可绑定热键）。
2. 选中文件后立即打开——摘录/复习/脑图/自动入图与库内文档**完全一致**，
   文档管理面板里会标「库外」徽标。
3. 阅读器右上角「⋯」面板菜单里有**「复制完整路径」**，方便把路径分享给别处。

**再次打开（㉞-A）**：打开过的库外文档会自动出现在 **文档选择弹窗的列表顶部**
（带「库外」徽标，最多列最近 8 本），模糊搜索文件名或路径即可一键重开——
关闭标签后不用再走系统对话框找文件。另外两个兜底入口：文档管理面板该行的
【打开】按钮；关闭前未关标签时重启 Obsidian 会随工作区自动恢复。

注意事项：

- **仅桌面端可用**（手机/平板上库外入口不出现；复习时跳转这类原文会提示移动端不支持）。
- **同目录改名/移动会自动跟随（㊳）**：插件监视库外文档所在目录——文件在原目录
  内改名后，记录自动跟上（弹 Notice 告知新文件名），正在打开的阅读器也不受影响。
  文件被移到**别的目录**或一次出现多个新文件、无法确定归属时**宁拒不赌**——
  弹提示让你到「文档管理」面板手动「重关联」（卡片与复习进度全部保留）。
- **「复制入库」一键转正（㊳）**：想让某个库外文档参与备份打包、跨机器不失联？
  文档管理面板该行或主页文档右键菜单选 **「复制入库」**——文件被复制到库根目录
  （同名冲突自动加 -2/-3 后缀，**保留原扩展名**：epub 复制后还是 .epub），记录随之
  改指库内副本，之后与普通库内文档一致。
- **备份不打包库外文档**：`.marginpkg` 只保留其记录（导出完成提示会单独计数
  "库外文档 N 个未打包"）。想在另一台电脑完整恢复时，请自行把原文件一并带走
  （或先「复制入库」），恢复后该文档显示失联，重关联到本机路径即可。

## 阅读 Markdown 文档（㊻-B 核心版）

除了 PDF，**库内的普通 Markdown 笔记也能加入阅读器**做摘录——网页剪藏、
学习笔记、他人分享的 md 书稿都可以当作"书"来读：

1. **打开方式与 PDF 相同**：主页「打开文档」按钮 / 命令面板 → 列表里选择 md
   文件。**数据目录 MarinMind 里的卡片文件不会出现在列表中**——那些是插件
   自己的数据，从源头排除误开。
2. **排版与导航**：正文按 Obsidian 原生预览排版渲染（固定阅读栏宽居中，随窗格
   自适应），**笔记里的内部链接可以直接点击跳转**；工具行「目录」侧栏自动变成
   **md 标题导航**（h1-h6 层级树，点击滚动到对应标题）。书签页签显示提示文案
   （单页长文没有页码概念，标题才是导航粒度）。
3. **摘录能力照常**：**划选文字建卡 / 留白 / 矩形 / 套索**（矩形/套索同样有内容
   快照——㊽ 对渲染内容直接截图，插图/表格照进快照）、**照片 / 语音**（锚定页 1）；
   卡片进脑图（自动建《md 文件名》同名图）、转闪卡、复习、跳回原文、翻译、闪卡遮挡
   全链路与 PDF 完全一致。
4. **不支持项（v1）**：手写批注、AI 一键摘录、OCR（这三者依赖 PDF 位图/文字层，
   按钮与菜单项不出现）、缩放（栏宽自适应窗格，「⋯」菜单不出现缩放项）、书签。
5. **注意**：md 文件被编辑后内容会变，**已摘录区域的高亮位置是近似锚定**——
   跳回原文仍能到附近位置，但可能在增删段落后来回偏移。

## 阅读 EPUB 电子书（㊼）

电子书最通用的 EPUB 格式也可以直接加入阅读器——**库内与库外（桌面）都支持**，
打开方式与 PDF 完全相同（「打开文档」列表里直接选 .epub 文件）：

1. **章 = 页模型**：每章算一"页"（书脊 spine 顺序），页码显示为「第 N 章」。
   目录来自书的内嵌目录（EPUB3 nav / EPUB2 NCX），点击条目直达对应章节
   （条目指向章内锚点时精确滚到该小节）；书签照常可用——「**＋ 当前章**」
   的默认标题就是**章节名**（目录里 ≤ 当前章的最近条目），不用手动改。
2. **统一主题排版**：忽略书籍自带样式，正文按 Obsidian 原生预览排版渲染
   （自动跟随亮/暗主题）——标题层级、列表、表格（横向滚动）、图片、脚注、
   ruby 注音都保留；**书内插图直接显示**（不联网、不加载外部资源）；
   **章节内链接可点击跳转**（跳到书内其他章节），网页链接在浏览器打开。
3. **摘录能力**：划选文字建卡 / 留白 / 矩形 / 套索（矩形/套索同样有内容快照——㊽
   对渲染内容直接截图，书内插图也一并进快照）/ 照片 / 语音（锚定当前章）；
   卡片进脑图（自动建《书名》同名图）、转闪卡、复习、跳回原文（回到摘录所在章）、
   翻译、闪卡遮挡全链路与 PDF 一致。
   复习/主页等界面的出处都会显示「第 N 章」。
4. **性能**：章节**渐进渲染**——只渲染视口附近的内容，长书秒开（打开时也只解压
   目录等结构文件，正文按需读取）；跳目录/书签/恢复阅读位置/跳回原文**直达目标
   章节**，附近章节渐进补齐且阅读位置稳定，几百章的长书深位置也秒级到达
   （滚动条随章节渲染逐步稳定，唯一可见变化是滚动条拇指长度）。
5. **不支持项（v1）**：手写批注、AI 一键摘录、OCR（依赖 PDF 位图/文字层）、
   缩放（栏宽自适应窗格，「⋯」菜单不出现缩放项）；**DRM 加密书（含字体混淆）
   直接拒开**并明确提示；书籍自带的音频/视频不播放。

## 文档内搜索（89-D，MarginNote 3 搜索对齐）

点阅读器工具行的 **「搜索」** 按钮（放大镜，在「复习」右侧）打开搜索弹窗，
对**当前文档全文**检索（PDF / EPUB / Markdown 三种形态都支持）：

- **输入即搜**（停顿约 0.25 秒后开始），子串匹配不区分大小写；结果每行
  **摘要左对齐自动换行**（最多三行截断）+ **页/章/段徽标行尾右对齐**同一行
  （92 行式重排），摘要取命中词前后各约 24 字符、命中词**高亮标黄**，
  **↑↓ 选择、Enter 或点击跳转**；
- **跳转定位**：PDF 自动跳页并滚动到命中行、该行叠**闪烁框**标示；EPUB 跳到
  所在章节滚动到命中段落并闪烁；Markdown 直接滚动到命中段落并闪烁；
- **一次性出结果**（91）：大文档逐页/逐章扫描期间只显示进度「搜索中 ·
  第 p/P 页…」，收齐后**整表一次性上屏**（不再逐条流式追加）；改关键词或
  关弹窗立即中断在途扫描，无残留；
- **防刷屏上限**：每页（章）最多列 5 条、全文档最多 200 条（达到上限时计数行
  注明「已达上限」）；搜常见词建议换更长的关键词；
- **中文友好**：PDF 的文字层常把中文按字符块拆分，搜索前会按行重组拼接——
  跨字符块的中文短语（如四字成语跨两个文本块）也能搜到；
- EPUB 搜索**不依赖章节已渲染**（直接检索书源文件），长书深处的章节照常命中。

## 目录与书签（阅读导航，㉓ + ㉙ 分页重排）

PDF 没有目录时最影响阅读效率——点工具行最左的 **「目录」** 按钮打开侧栏
（再点一次或点侧栏 × 收起），侧栏覆盖在页面左侧，不影响正在阅读的布局。
侧栏顶部是 **「目录 | 书签」分页切换条**（㉙），两个页面各占整个侧栏高度，
当前分页在面板重开/刷新后仍保持：

- **目录（PDF 内嵌大纲，㉝ 与 Obsidian 默认 PDF 阅读器的目录样式一致）**：
  文档自带的书签/大纲以**朴素树形**展示——层级缩进、▸/▾ 折叠箭头 + 标题，
  无其他附加格式；**点击任意条目直接跳到对应页**；悬停条目只提亮文字。
  千条目的大书首次打开侧栏会先显示「正在解析目录…」（大纲解析推迟到打开
  侧栏才做，不拖慢打开文档本身，㊾），稍候即出树。手动展开/折叠的状态在侧栏
  刷新后不会丢失。个别条目跳转目标损坏时置灰不可点。
- **书签（自定义）**：PDF 本身没有大纲也没关系——切到「书签」页点
  「**＋ 当前页**」（EPUB 为「＋ 当前章」，默认标题即章节名）把当前阅读位置
  加为书签（弹窗里可把默认的"第 N 页"改成章节名），点击书签随时跳回；行内同样
  显示页码，悬停时出现 × 删除。
  书签保存在笔记文件里，关闭重开、重启 Obsidian 都在；同一本书开了多个阅读
  标签时，任一标签增删书签，其他标签的侧栏即时刷新（㊳）。
  （Markdown 文档没有书签——单页长文用标题目录导航。）
- 目录与书签都为空时，侧栏会给对应提示。

## 用复习界面背卡片（v4 核心功能）

1. **转闪卡**：在阅读器点击任意高亮（下划线=文字摘录，边框=区域，轮廓=套索，
   胶囊=留白）→
   菜单选「转为闪卡」。卡片默认只是摘录，转为闪卡后才进入复习队列。
   - 同一菜单还能「编辑标题/批注」（78 起弹窗双字段——与脑图节点右键的编辑器同款）。
     **批注即"问题"**（MarginNote 同款正反面
     语义）：写了批注的卡复习时正面显示批注（问题）、背面显示摘录内容（答案）——
     把想考自己的问题写进批注即可制卡；**标题**是卡片的显示名（㊺ 起各处列表、
     脑图节点标题栏、复习列表均优先显示标题）。
   - **自动转闪卡（㊷，按书开关）**：阅读器「⋯ → 自动转闪卡」（89 起从工具行
     按钮移入 ⋯ 菜单，勾选即开启）开启后，本书的**新摘录**自动进入复习队列
     （划选/框选/套索/留白/
     手写/照片/语音/AI 批量/翻译留白全都算）；开关**每本书独立记忆**，换书互
     不影响。批量摘录只弹一条「已自动转为闪卡：N 张」汇总提示，不刷屏。
2. **开始复习**（六种入口）：
   - 命令面板（Ctrl+P）执行「开始复习（到期闪卡）」；
   - **阅读器工具行的「复习」按钮**（视图切换循环钮左侧，㉑ 新增）；
   - **脑图顶部的「复习」按钮**（🎓 图标，㉑ 新增）；
   - **按卡组复习（卡组批）**：命令面板执行「按卡组复习（选择卡组）」弹出卡组
     选择器，或主页卡片页选中某卡组后点计数旁的「复习本组」——只考该组的到期卡；
   - **按颜色筛选复习（70）**：主页卡片页颜色下拉选中某色后，计数旁出现
     「复习筛选结果」——把当前五维筛选（书/形态/卡组/标签/颜色）命中的卡临时
     组一场复习；
   - **复习此分支（70）**：脑图里右键任意节点 → 「复习此分支」——只考该节点
     整棵子树下的卡片（比如只复习某一章的知识点）。

   打开复习标签页（已开过则复用并重新加载）。刚转为闪卡的卡片立即到期，马上可复习。
   复习界面与阅读器/脑图同为**顶栏合一**（107）：原生标题行隐藏，单个工具行从左到右
   = 列表开关 · ◀ 第 i/N 张 ▶ · 出处段（范围胶囊/书名 · 页码 · 剩余张数）·
   撤销 · 翻译 · ⋯管理 · ↗跳转原文。
   - 复习**范围四态**（㊷ 按书 + 卡组批扩卡组 + 70 临时卡片集）：全部书籍 /
     只考某书 / 只考某卡组 / 临时卡片集（颜色筛选结果或脑图分支）。
     阅读器与脑图的「复习」按钮、「学习模式」工作区只考**当前书籍**——脑图
     优先考图绑定书的到期卡（默认同名图），跨书主题图回退当前正阅读的书；
     限定范围时工具行出处段显示范围胶囊（《书名》/卡组名/临时范围名，点 × 一键
     切回「全部书籍」）；命令面板入口考全部书籍；空屏/完成屏也提供
     「考全部书籍」与「按卡组复习…」按钮。
3. **卡片流程（正反面）**：
   - **正面（问题）**：有批注显示批注；否则显示摘录的**区域形貌**（108 展示形态
     统一：文字/矩形/套索显示原文页裁剪图——带高亮标示与上下文余量、居中展示；
     **110 起矩形/套索的裁剪范围参照文字摘录**——每侧至少带 10% 页宽/5% 页高
     的上下文、窗口不小于约半页宽，不再是紧贴摘录的一小块放大图；手写显示
     笔迹快照、照片显示照片图，均居中；留白显示文字、语音显示播放器；
     原文文件缺失或非 PDF 书时回退显示摘录文字）；
   - 顶部工具行中段**出处**（书名 · 页码 · 剩余张数，107 并入顶栏单行）；
   - 超长批注/摘录在卡片内**限高滚动**（滚动条在内容块内，评分按钮不会被
     推出屏幕——长内容卡也能一眼找到四档按钮）；
   - **空格 / 回车**（或点"翻面看答案"）翻面：正面是批注时显示摘录内容（答案）
     与出处；无批注时显示出处；背面底部有**「溯源上下文」切换条**（见第 4 条）；
   - **1 / 2 / 3 / 4**（或点按钮）评分：重来 / 困难 / 良好 / 简单，自动排下次到期。
4. **溯源上下文（㉒，翻面后按需查看；71 进阶）**：背面底部的**「溯源上下文」**切换条提供
   两个栏目，点击才展开（再点一次收起）：
   - **📄 文档**：摘录所在页的缩略图并**高亮摘录位置**——区域/套索卡"想不起这是
     哪里"时一眼定位；照片/语音卡无页面定位时会提示改看脑图栏；原文文件已移出库
     时静默跳过。**71 起缩略图可点击**——直接跳原文并精确定位到摘录位置
     （悬停有描边提示可点）。
   - **🧠 脑图**：卡片在各张脑图中的**位置摘要**（祖先 › **本卡** › 子节点/同级
     数量）——回忆"这个知识点挂在哪"时用；**71 起每张图的摘要上方带缩略图**
     ——迷你版整图布局（当前卡的节点高亮描边），点击打开该脑图并**居中定位到
     这张卡**（已折叠/已移出会提示）。
   - **自动展开（71）**：切换条右侧的眼睛开关打开后，每张卡翻面**自动展开**上次
     看的栏目（记住上次选的是文档还是脑图）——适合"每张卡都要看上下文"的刷卡
     节奏；默认关，保持先回忆后看。
   - 参照 MarginNote 手册的建议，上下文**默认收起**、只在翻面后出现、切换卡片自动
     收起——**先回忆，记不起来再看**，一开始就看会降低主动回忆的效果。
5. **切换卡片（◀ ▶）**：顶部导航条 **◀ 第 i / N 张 ▶** 或键盘 **← / →** 在卡片间
   浏览切换——可以回看**已考过的卡**（正反面一起显示 + "已考·档位"徽标，只读）、
   也可以提前看**后面的卡**（只显示正面）。评分永远只作用于当前待考的卡，
   浏览不影响复习进度。**浏览只切换卡片本身、不跳原文**（深度复习三窗格下同样
   不驱动阅读/脑图侧定位）——想看原文点导航条右侧的 **↗ 跳转原文图标按钮**（106
   起纯 icon 化，悬停提示「跳转原文」，不用翻面即可跳回）或翻面后展开溯源上下文。
6. **撤销评分（67，Ctrl+Z）**：评完想改主意？点导航条右侧操作组的**撤销按钮**（或按
   **Ctrl+Z / Cmd+Z**）——回到上一张评分的卡**未翻面状态**重新作答：调度器、
   当日统计、复习日志全部**同步回退**（连"重来"的队尾重现也会一并撤销）；
   可连续撤销多步。**改评 = 撤销后重评**。会话中删除某张卡后其余卡照常可撤销
   （103-B 起撤销栈随删卡同步迁移，被删卡自身的评分步骤作废）；
   输入框内 Ctrl+Z 仍是原生文本撤销。
7. **卡片组列表（70）**：导航条的**列表面板开关**（左侧图标按钮）展开本组卡片的
   列表侧栏——每行显示状态徽标（未考 ○ / 已评档位色 / "重来"重现 ↻）与卡片
   标题，**点击任意一行直接跳到那张卡**（已考的自动显示背面只读态）；面板头部
   可**排序**（队列序 = 到期顺序 / 文档位置 / 文本）与**筛选**（按书 / 按颜色）
   ——比如"只看这本书的卡"或"按页码顺序过一遍"。
8. **⋯ 管理卡片（卡组批；65 起可编辑批注，78 起统一为标题/批注双字段）**：导航条右侧 **「⋯」管理图标按钮**（106 起纯 icon 化，与相邻撤销/列表等图标钮同款方形；已考回看与后面的卡同样
   可用）：
   - **查看卡片**：弹摘录预览（与主页同款）；
   - **编辑标题/批注**（78）：弹**双字段窗口**（标题一行 + 批注多行）——与脑图节点
     右键「编辑标题/批注」同款；批注就是正面的考题当场改到满意，标题是各处显示名。
     阅读器高亮菜单、主页卡片预览弹窗动作行、照片/语音预览弹窗同为该双字段入口
     （全应用统一，不再有单字段"编辑批注"）；
   - **打标签**：空格或逗号分隔输入多个标签（如 `英语 词汇`），留空清除全部——
     标签在主页卡片页可按标签筛选；
   - **设置卡组**（76 起为选择器）：弹出**卡组选择列表**——可输入筛选、当前卡组带
     「当前」徽标、点某个卡组即归入（每卡至多一组，改选即换组）；列表尾部
     「＋ 新建卡组…」输入新名（支持多层路径如 `学习/英语`）即建即归入，已有卡组
     的卡另有「移出卡组」。卡组也可以从主页卡组树「＋ 新建卡组」先建好空组再用。
   - **删除卡片**：确认后删除（连带附件、脑图节点与链接，不可恢复），复习队列
     即时剔除该卡。在阅读器或主页删除的卡，打开中的复习会话同样实时剔除。
   标签与卡组也可以在**主页卡片预览弹窗**的动作行设置（标题/批注 / 打标签 / 卡组 / 删除）。
9. **"重来"的卡**：本组末尾会再次出现（Anki 风格），直到评过其他档位。
10. **新卡与批次（68）**：每批卡 = **到期的复习卡在前 + 新卡殿后**（复习优先）；
    设置页「复习」小节可调**每批张数**（默认 20）与**每日新卡上限**（默认 0=不限）
    ——设了上限后，当天新卡最多出「上限 − 当日已考新卡」张（撤销评分会返还
    额度），次日自动恢复。
    > 提示：如果库里有大量"转了闪卡但一直没考"的囤积新卡，不限额的首批会很大
    > （复习卡满批 + 全部到期新卡），建议先设一个新卡上限（如 20）再开练。
11. **跳转原文**：点 ↗ 图标按钮 → 打开阅读器并**精确定位到摘录矩形**
   （滚动到矩形上方约 1/4 视口处并闪烁高亮两次）；照片/语音卡则闪烁页角徽标。
   **109 起同一文档已开着阅读标签时不新开**——直接切到该标签原地定位，
   只有没开过（或开的是别的书）才新开标签；卡片预览弹窗、脑图右键
   「跳转原文」等入口同此行为。
12. **完成**：队列耗尽显示四档统计；「再查一批到期卡片」可续刷下一组（每组张数
   见设置，保持当前范围），「查看统计面板」打开**复习统计**（见下），「◀ 回看
   本组卡片」仍可翻看刚考过的内容。
13. **取消闪卡**：回到阅读器点该卡高亮 → 「取消闪卡」即移出复习队列（调度历史保留）。

**复习统计面板（69）**：命令面板执行「复习统计」（或完成屏 / 主页卡片页「统计」
链接）打开——**今日复习数 / 连续打卡天数**（来自复习日志，按本地日历日计算）/
**累计复习与闪卡数** / 库规模（文档/卡片/脑图）+ **12 周热力图**（GitHub 风格，
颜色越深当天复习越多，悬停看具体数字）+ **未来 7 天到期分布**条形图（逾期的计入
今天）。三项复习指标**同源复习日志**（103-C 起统一口径：升级前按旧算法估算的
历史计数已一次性折算入累计基线，面板脚注有说明）；面板是打开那一刻的快照，
重开即刷新。日志数据存数据根 `复习日志.md`
（按日聚合的普通 md，随备份打包；手改或删除该文件 = 以你的修改为准，之后的新
评分会在此基础上继续累计）。

### 闪卡遮挡（㊷：划重点区域，复习时遮住）

适合"看图记结构 / 划重点背细节"类内容（Anki Image Occlusion 同思路）：

1. **划遮挡**：在阅读器点该卡高亮 → 菜单选「遮挡区域…」→ 在页上**拖框**盖住重点
   （可连续画多个，Esc 或切换工具结束；**起点可以直接落在摘录区域内部**——遮挡
   通常就盖在摘录上）。遮挡在页面上以**虚线框**标示位置，正常阅读不受影响。
2. **复习时**：正面自动出图（内容快照 / 原文裁剪，与主页卡片预览同一画面）并用
   **实心色块遮住**你划的区域——色块颜色跟随该条摘录的高亮色系（㊿-C）；
   先回忆再验证：**点击单块**临时揭开看一眼（再点重遮），**「显示全部遮挡」**
   一键全揭（可再点「重新遮住」）；**翻面看答案 = 同一张画面，遮挡块变透明、
   保留同色系虚线边框**（㊿-B/C）——各形态摘录（文字/矩形/套索/留白）与正面
   完全同构，答案内容可见且能看到重点区域原本遮在哪。
3. **管理**：点页上的遮挡块（或高亮菜单）可**删除此遮挡 / 清除全部**；「遮挡预览」
   开关在阅读器里直接预览复习时的遮挡观感（实心覆盖），关掉恢复虚线标记。
4. **文字卡的遮挡利器（71 起；74 调整）**：文字摘录的高亮菜单里——
   - **「遮挡行吸附」开关**（默认开）：文字卡拖遮挡框时**自动对齐到完整文字行**
     （垂直方向吸附到盖住的行、多行一并盖严吞入行间空白，水平方向保持你拖的
     宽度）——不用再纠结框子歪一点就盖漏半行字；
   - **「文字遮罩…」（74）**：进入"划选即遮罩"模式——**像平时划选文字一样选中
     一段**（可连续多段，Esc 结束），选中文字的**逐行精确矩形**直接变成该卡的
     遮挡块。比拖框更精确：只遮选中的字符，做"挖空填词（cloze）"类卡首选；
     pdf / Markdown / EPUB 文档通用。同一划到底或跨页选择会被拒绝并提示
     （遮挡须与卡片同页）；重复划同一段会提示"已遮罩"不会叠块。
     （74 起原「遮住全部文字行」一键模板已移除——精确遮罩请用「文字遮罩…」。）
5. **照片卡也能划遮挡（71）**：主页点开照片卡的**摘录预览**，动作行「遮挡」按钮
   进入编辑态——直接在照片上**拖框**盖重点（图内坐标；点遮挡块删除、可清除
   全部），复习时正面显示照片并遮住框选区域（点击揭开，与文字卡一致）。
   语音卡不支持遮挡。
6. **脑图遮挡徽标（71）**：划过遮挡的卡在脑图节点标题栏右侧显示小"眼睛斜杠"
   图标（悬停提示"已设遮挡"）——扫一眼就知道哪些节点带复习遮挡。
7. 遮挡支持文字/矩形/套索/留白/手写（页内拖框）与照片（预览弹窗拖框，71）——
   语音卡无视觉内容不给入口；遮挡随卡片保存进书文件（重启不丢），划了遮挡的卡复习正面
   优先出图，没有图时退回摘录文字并近似遮住对应区域。

> 提示：复习界面只在它处于**激活标签页**时响应键盘；切到其他标签页按数字键不会误触。
> Obsidian 窗口右上角自带的"后退/前进"箭头与卡片切换无关——切换卡片请用界面内的
> ◀ ▶ 按钮或 ← / → 方向键。

## 用思维导图组织卡片（v1 核心功能）

### 建图与加卡片

1. 命令面板执行「打开思维导图（选择 / 新建脑图）」→ 选图器里选已有图
   （书籍同名脑图带 📖 徽标，见「摘录自动入图」——**打开一本书时会自动建好它的
   同名脑图**，无需手动创建），或选首项「➕ 新建脑图」
   输入名称（留空默认"未命名脑图"）。
2. **四条加卡路径**：
   - **阅读器里**：点击高亮 →「加入思维导图…」→ 选图/新建图，卡片落在根节点区；
   - **脑图「⋯ → 添加已有卡片…」**（list-plus；90 起自标签页头部迁入）：模糊搜索
     最近 200 张卡片，
     次行显示出处（《书名》· 第 N 页 / 手工卡片），已在当前图中的不会出现；
   - **双击画布空白**或「⋯ → 新建文字卡片」（plus）：输入文字生成手工卡（无文档归属）；
   - **键盘**（52）：选中节点后 **Tab 建子卡 / Enter 建兄弟卡**（见「键盘操作」）。
3. 新节点自动落位：加到图里的卡片排在根节点区最下方顺延。

### 节点三栏与编辑（㊺，MarginNote 3 式；㊺-A 交互回调）

每个节点分**三栏**，颜色跟随摘录色系（黄/绿/蓝/红及存量旧色相）：

- **上栏·标题栏**：彩色底条 + 卡片**标题**，默认显示三个点「…」，左对齐加粗；
- **中栏·摘录内容**：区域/套索/手写/照片显示快照图片（OCR 出的文字作图注），
  文字摘录显示摘录文本；
- **下栏·批注栏**：有批注才显示（虚线分隔、灰字）——默认不占地方。

**编辑标题与批注**：**右键节点 → 「编辑标题/批注」**在节点下方弹出编辑面板——
标题框 + 批注框 + 取消 / 原文 / 保存。保存后节点三栏即时刷新（含连线重锚）；
标题会同步到主页卡片列表、卡片预览、复习脑图栏等所有显示位置。
面板操作：**Esc 取消、Ctrl/Cmd+Enter 保存**；拖动/缩放画布时面板跟随节点移动；
点击画布空白或点击其他节点关闭。标题留空保存 = 恢复默认「…」；批注即复习正面的"问题"。

**左键单击节点 = 直接跳原文**（㊺-A 恢复旧行为；联动模式下文档侧直接滚过去并闪烁）；
编辑面板的「原文」按钮与右键菜单「跳转原文」为另外两个出口。

### 拖拽组树与画布操作（㉜ XMind 式分区拖放）

1. **拖节点到另一节点上** = 按落点分区处理：
   - **命中节点上 1/3** → 插为同级**前方**（节点出现在目标上方/左方）
   - **命中节点下 1/3** → 插为同级**后方**（节点出现在目标下方/右方）
   - **命中节点中间 1/3** → 挂为**子节点**
   - **拖到空白** = 自由定位（整棵子树跟随指针移动）
2. 拖动中会有**实时提示**：命中节点时高亮显示，before/after 出现插入线（黄色 3px 条）；
   命中自己或自己后代时不提示（避免误导）。
3. 松手后，**受影响分支自动整理**：只有新旧两个父节点的子树按标准布局回流归位，
   连线锚点自适应（tree 样式下子在左侧时连线从左边出，不再打结）；
   **无关分支的连线与位置一律不动**（不会满图重排）。
4. **拖到自身后代节点**会被拒绝（防止成环），但位置照常保存。
5. **平移**：普通滚轮或按住左键拖空白处；**缩放**：Ctrl+滚轮（以鼠标位置为中心，0.25x–2.5x）。
6. 拖动过程中**点右键或按 Esc** 取消（㊳），整棵子树回到原位；指针距视口边缘时自动滚屏。
   自由拖动时还有**对齐吸附 + 网格兜底**（58，见「拖拽对齐吸附」）。
7. **折叠子树**：鼠标悬停**有子节点的节点**，右缘出现 ▾ 按钮——点击折叠整个子树，
   节点缩为 "▸ N" 计数胶囊（N = 隐藏的后代数）；再点展开。折叠状态重启后保留。
   折叠期间拖卡到该节点照常挂为其子节点，展开后自动排到兄弟下方。
8. **节点右键菜单**：跳转原文（新开阅读器**精确定位到矩形并闪烁**）/ 编辑标题/批注
   （打开节点编辑器，㊺）/ 转为·取消闪卡 / **复习此分支（70——只考该节点整棵子树
   下的到期卡，如只复习某一章）** / 分支样式… / **设为固定根节点（㉗，📌 徽标；
   之后的新摘录都挂到该节点下）** / 复制卡片链接·复制嵌入代码 / 链接到卡片…·解除卡片
   链接…（53，见「卡片互链」）/ 合并到卡片…（60，见「卡片合并」）/ 坍缩为子脑图·
   打开子脑图·解除子脑图（61，见「子脑图」——按节点状态显示其一）/ 移出脑图
   （卡片保留，其子节点上浮为根）/ 删除卡片（节点与卡片数据一并删除，**附件同步
   清理**，51 修复）。

### 键盘操作（52，MarginNote 风格）

**先点选一个节点**（左键单击或方向键命中；单击有原文的卡仍会跳原文并选中它，
手工卡单击仅选中），出现蓝色描边选中框后：

| 按键 | 行为 |
| --- | --- |
| **↑ / ↓** | 跳到父节点 / 第一个子节点（折叠中的节点 ↓ 无动作，先展开） |
| **← / →** | 前/后一个同级节点（**多根之间也能左右互通**） |
| **Tab** | 新建**子**卡片（弹输入框；选中节点折叠中会先自动展开再挂接） |
| **Enter** | 新建**兄弟**卡片（在根上按 = 新建根卡片） |
| **Delete** | **移出脑图**（= 右键「移出脑图」，卡片保留；选中转移到原父节点） |
| **Esc** | 清除选中（弹窗/编辑面板开着时优先走各自取消） |

细节：方向键跳转后画布自动滚动保证节点可见；导航/新建的节点自动选中（含新建卡）；
任何弹窗、菜单、输入框开着时键盘让位不误触；Tab/Enter 弹出的输入框取消则不建卡、
选中保持不变。未选中节点时按六键会弹一次操作提示（每视图一次）。85-A 修复：单击
节点联动跳原文后键盘**立即可用**（此前 activeLeaf 被阅读器抢走导致 Tab 等按键
失效）；键盘事件跟随视图所在窗口（弹出窗口里同样可用）。

### 分支样式（树形 / 斜树 / 直线 / 双向 / 框架）

参照 MarginNote 4 分支样式，共九种——**树形（右）**（默认，经典左根右叶）、
**树形（左）**（镜像，根在右子向左）、**树形（下）**（组织架构图，子节点横排在下）、
**斜右下树**（57，父顶对齐首子、子级瀑布向下，MN4「树形3」）、**斜右上树**
（57，父底对齐子块底、子级瀑布向上，MN4「树形4」）、**直线**（横向链条，适合
步骤/时间线；57 起连线两端带**端点圆点**）、**直角连线**（57，直线细节——水平段
接垂直段的直角折线）、**双向**（根居中左右对称展开）、**框架**（子节点收进圆角
收纳框，不画连线，适合分类归纳；57 起**父节点嵌在框内顶部**当标题栏）。

1. **整图默认**：脑图「⋯ → 分支样式…」（89 起从标题旁下拉框改为二段菜单，
   当前样式打勾）——未单独设置过的节点全部跟随。
2. **单个分支覆盖**：**右键节点 →「分支样式…」**——只影响该节点的子树
   （它的子节点如何挂出）；选「跟随全局」恢复继承。
3. 样式决定**连线的形状**与**自动布局的排列方向**；切换样式不移动节点位置，
   连线立即变形；想让节点也按新样式排好，接着点「⋯ → 自动布局」即可。
4. 新拖入/挂上的子节点会按父节点样式自动落位（如树形左落左侧、树形下落下方、
   斜树沿瀑布方向顺延）。

### 卡片互链（53：跨位置卡片关联）

除了树形父子关系，两张卡片还可以建立**双向链接**（不改变树结构）：

1. **建链**：右键节点 →「**链接到卡片…**」→ 搜索选择另一张卡（最近 200 张可模糊
   搜索，已链接的和它自己不会出现）。
2. **看链**：两张卡在**同一张图**里时，画布上会出现它们之间的**虚线关联边**
   （强调色，不随分支样式变化）；一端被折叠隐藏或不在本图时虚线暂不显示，
   链接本身仍在。
3. **解链**：右键节点 →「**解除卡片链接…**」——只有一个关联时直接解除；多个时
   弹出列表逐个选择（列表对端**不必在本图**——解除是全局的，任何图里右键都能解）。
4. 复制出去的卡片链接/嵌入代码（㊻-A）不受互链影响；互链关系随备份导出/导入。

典型用法：同一概念在两本书里的摘录互相链接、章节骨架卡与它的核心结论卡链接——
复习时在某一张卡的详情里能看到关联（后续可扩展显示）。

### 拖拽对齐吸附（58）

自由拖动节点（松手前不悬停在任何目标上）时：

- **对齐吸附**：被拖节点靠近其他节点的左/上边缘 8 像素（画布世界坐标）以内时，
  自动吸附对齐并显示**强调色参考线**（一竖一横最多两条），方便排出整齐的行列；
- **网格兜底**：某个方向上没有可对齐的邻居时，落点自动**取整到 20 像素网格**
  （不画参考线，只是让坐标"落在格子上"，反复微调后排面不散）。
- 悬停到目标节点上（出现挂接高亮/插入线）时吸附自动让位，不会干扰挂接与排序；
  拖拽取消/落点后参考线消失。吸附结果随松手一起保存。

> 注：画布背景的点阵是屏幕像素（不随缩放变），与 20 像素世界网格不视觉对应——
> 网格只影响落点坐标的整洁度。

### 撤销与重做（59，Ctrl+Z / Ctrl+Shift+Z）

脑图支持**多步撤销**（栈深 50 步，51 的"撤销布局"单步快照已并入）：

- **可撤销的操作**：拖动节点（自由定位/挂接/排序三类）、折叠/展开（单个与批量）、
  切换分支样式（节点覆盖与整图默认）、自动布局——每一步一条记录，**连续撤销
  可以一路退回多步之前**；
- **操作方式**：`Ctrl+Z`（Mac `Cmd+Z`）撤销，`Ctrl+Shift+Z` 重做；脑图「⋯」
  菜单里也有「撤销」「重做」两项（无可撤销/重做时置灰；89 起从工具栏按钮
  移入菜单，快捷键不变）；
- **不进撤销栈**：建卡/删卡/移出脑图/固定根/合并卡片/子脑图坍缩解除——这些
  操作牵连面大（级联删除复习进度等），做成"可撤销"反而危险，确认弹窗就是安全网；
- 输入框/弹窗开着时 `Ctrl+Z` 是文本编辑的原生撤销，不会误触画布；
- 切换到另一张图后栈清空（每张图独立的最近操作历史）。

### 卡片合并（60：两卡并一卡）

两张卡片内容重复或想合并笔记时：**右键节点 →「合并到卡片…」**（git-merge 图标）
→ 搜索选择合并目标卡 → 确认弹窗 → 完成。合并规则：

- **文本并入目标**：批注双有时拼接（目标在前）；摘录文字/标题/卡组/颜色/遮挡、
  标签（并集去重）在目标为空时取源卡的值；
- **结构迁移**：源卡在各图里的节点改挂到目标卡的节点下（同图无目标节点时节点
  直接改挂目标卡；一图一卡约束冲突会提前整批拒绝）；互链邻居、复习进度
  （SM-2 调度字段）一并转移到目标；
- **以目标为准**：原文锚点（页码/矩形）、摘录形态与媒体附件**保留目标卡的**——
  源卡删除、其附件清理；合并不进撤销栈（确认弹窗写明取舍）。

### 子脑图（61：大图拆分）

一张图太大时，把某个分支**坍缩成单个"传送门"节点**，子树搬进独立的子图：

- **坍缩**：右键有子节点的节点 →「**坍缩为子脑图**」（fold-vertical）——直接
  子树整体迁入一张新建子图（在选图器里可找到），原节点左上角出现 🗂
  **子图徽标**（folder-tree）；
- **进入**：**双击**带徽标的节点（或右键「打开子脑图」）——当前脑图标签切换到
  子图；子图里照常摘录/拖拽/复习；
- **解除**：右键 →「**解除子脑图**」（unfold-vertical）——子图全部节点迁回挂到
  原节点下，子图删除（有节点数确认；若本图已有相同卡会整批拒绝，子图保留）；
- 子图被单独删除后，传送门节点自动还原为普通节点（悬空自愈）；把传送门节点
  移出脑图不影响子图（它保留为独立脑图）。

### 从文档目录一键建脑图框架（55 PDF；62 起 EPUB/Markdown 也可，MarginNote「路径三」）

脑图「⋯ → 从文档目录建框架」：选一份文档，插件读取它的
目录，**一键生成整棵章节骨架卡**挂到《书名》分组卡下——读书前先把书的骨架搭
出来，边读边往对应章节里填摘录：

1. 选文档：**PDF / EPUB**（库内/库外均可）或 **Markdown**（仅库内；EPUB 取
   nav/ncx 目录、Markdown 取标题树——大 md 渲染量测要几秒，有进度提示）；
   未打开过的书会自动建档。
2. 确认弹窗显示将创建的章节卡数量（大目录有规模提示）→ 确认后逐章建卡。
3. 目录里页码损坏的条目自动跳过，其子章节就近挂到有效章节下。
4. **自动归章（55；62 泛化）**：框架建好后，这本书的**新摘录不再直挂《书名》
   分组，而是自动挂到「起始位置 ≤ 摘录位置」的最近章节分支下**——PDF/EPUB 按
   **页码/章号**比较，Markdown 在同一篇长文内进一步按标题的**纵向位置**比较
   （同一屏里"第三章标题下方"的摘录归第三章）；位置在第一章之前的摘录仍挂
   分组下；固定根对本书生效时优先挂固定根、不归章。
5. 每张图每本书只建一份框架（重复会提示）；同一本书可以在不同图里各建一份。
   ⚠️ 若这本书的摘录目标图不是当前图（比如你把框架建在了自己的主题图里），
   完成后会提示——到阅读器「⋯ → 摘录目标脑图」把目标切到这张图，新摘录才会归章。

> 归章判定按目录位置就近，与节点位置无关——把某张摘录拖出章节分支后，后续摘录
> 仍按位置归章，不会跟着挪。点章节骨架卡「跳原文」可直达对应章节（md 直达标题）。

### 摘录自动入图（边摘录边生成脑图，㊴：打开即建同名图 + 按书切换目标图 + 固定根节点）

摘录**自动**进入脑图并连成树是默认行为（MarginNote「自动添加到脑图」同款）——
脑图顶部的 **「添加到脑图」** 开关（分叉图标）默认开启（点击可关/再开，**全局生效并记住**，
重启后保持）。开启后，任何阅读器里的新摘录（文字/矩形/套索/留白/手写/照片/语音）
自动入图，落点按以下优先级决定：

1. **固定根节点优先（80 起仅所属文档生效）**：在某脑图的一个节点上右键
   **「设为固定根节点」**（节点右上角出现 📌 徽标）后，新摘录直接挂到该节点
   之下、不归章。生效范围由**钉点归属**决定：
   - 钉在**某本书的图**（同名脑图等有文档绑定的图），或钉节点本身是某本书的
     摘录卡时——只有**阅读那本书**的摘录会挂进来；读其他书时固定根让位，
     摘录照常走那本书自己的目标图（第 2/3 级）。
   - 钉在**无文档归属的主题图**（图和钉节点卡片都不属于任何书）时——保留
     **跨文档收拢**：所有书的新摘录都挂到该节点下，适合"这一轮读的东西都归
     到这个主题"。
   再右键该节点「取消固定根节点」或点脑图顶部「📌 固定根」按钮即可取消，
   回到各书自己的目标图。
2. **本书目标图（按书记住，㊴）**：每本书默认目标就是它的**同名脑图**；你也可以
   阅读器「⋯ → 摘录目标脑图」，把"这本书的摘录"切到任意图——**每本书独立
   记住自己的目标**，互不影响。切过去后，这本书的新摘录就进那张图（图里会自动
   建一个《书名》分组卡归拢它们，多本书共用一张图也各自分组），随时可再切回
   「同名脑图（默认）」。
3. **同名默认脑图（默认行为）**：**一本书一张默认脑图，书名就是根节点**——
   **打开书的那一刻就自动建好**（不用等第一张摘录），根节点是《书名》分组卡，
   之后该书的全部摘录依次挂到这个根下面（纵向顺延，连线随分支样式走）。
   多本书各自成图，互不混入。

**「摘录目标脑图」（阅读器「⋯」菜单，㊴；89 起从工具行按钮移入）**：点击弹出
菜单——顶部显示当前目标（《图名》或「📖 同名脑图（默认）」）；固定根对本书生效
时有置灰提示（80：无归属主题图 = 所有书都提示「所有书的摘录优先进入」；归属本书 =
「本书摘录优先进入」；归属他书时不提示——本书实际走当前目标路径）；
覆盖过目标的书会出现「切回同名脑图（默认）」；「选择其他脑图…」打开选图器
（选到书的同名图等同切回默认）。

说明与细节：

- **每张卡入图后右下角会提示「已自动加入脑图《书名》」**（连续摘录/AI 批量建卡
  时合并计数为一条提示）——按提示里的图名即可在选图器找到它；选图器里书籍脑图
  带 **📖 徽标**和「书籍脑图」副行说明。
- 自动入图**不需要打开脑图视图**——后台静默完成；正开着对应脑图时节点实时长出来。
- **改名跟随（㊴）**：重命名 PDF 后再打开，同名脑图的图名与《书名》根节点会跟着
  换成新书名——但如果你手动改过图名或分组卡文字，那一样**不会被覆盖**（改过什么
  保什么）。
- 分组卡《书名》在脑图里可正常操作：拖动换位置、改父子、点击编辑标题/批注（比如把
  《书名》改成章节主题）。若把它移出脑图，下一张该书摘录会重建分组。
- **分组卡不算你的卡片（81）**：《书名》根节点只是脑图的结构锚点，**不会出现在
  卡片列表、卡片统计、「最近卡片」和复习里**——每本书显示的卡片数只算你真实的
  摘录（刚打开还没摘录的书显示 0 张），右键它也没有「转为闪卡」（结构卡不进
  复习队列）。
- 作为目标的图被删除后，那本书的摘录自动回到默认同名图（不会悬空丢失）。
- 自动入图**只影响新摘录**——已有卡片仍走手动加入（「加入思维导图…」/拖卡入图），
  且手工卡（双击新建的文字卡）不会被自动收录。
- 关闭「添加到脑图」后新摘录不再入图，已入图的节点不受影响；同名图与目标设置
  不受开关影响（开关只管"摘不摘进去"）。

> 提示：与拖卡入图的关系——拖卡是"我来决定挂到哪"，自动入图是"按书自动归组/
> 按固定根收拢"，两者可并用；自动加入的节点随后照常可拖拽重排。

### 节点搜索（89-C，MarginNote 3 搜索对齐）

大图里找节点不用肉眼扫——点脑图 header 的 **「搜索」** 按钮（放大镜，在
「复习」右侧）打开搜索弹窗：

- 输入关键词，匹配范围 **标题 > 批注 > 摘录文字**（每节点取首个命中字段，
  一节点一行）；行式布局与文档搜索一致——**文字左对齐自动换行、命中字段
  徽标（标题/批注/摘录）行尾右对齐**（92 起）；
- **↑↓ 选择、Enter 或点击定位**：画布自动平移居中到该节点并**闪烁标示**；
  节点藏在**折叠子树深处也能定位**——所在折叠祖先链自动展开（不进撤销栈）；
- 结果最多列 100 条（计数行显示「前 100 个匹配」），搜常见词建议换更长的关键词。

### 图的管理

脑图的工具都在视图内 header 单行里（90 起为**唯一顶栏**——原生标题行已隐藏）：
图名 · 节点数 | 添加到脑图 | 复习 | 搜索 | 折叠全部 | 视图切换循环钮 |
**⋯ 溢出菜单**——图标+文字，低频操作分组收纳（卡片组：添加卡片/新建文字卡片；
管理组含导出）。

- 「⋯ → 添加已有卡片…」：模糊搜索最近 200 张卡片加入当前图（已在图的不出现）；
- 「⋯ → 新建文字卡片」：输入文字生成手工卡（无文档归属），同**双击画布空白**；
- 「⋯ → 重命名 / 删除脑图」（删除需确认；卡片保留，只删组织结构）；
- 「⋯ → 分支样式… / 固定根」：整图默认分支样式（二段菜单）与固定根开关
  （89 起从 header 下拉框/按钮移入）；
- 「⋯ → 自动布局」：一键把全部节点按各自的分支样式整理
  （同层对齐、父居中、多根堆叠；间距按节点**实际高度**计算，含图片的高节点
  不会与相邻节点重叠），完成后**保持你当前的缩放档平移居中（104-B 不再自动
  缩放适配）**——想把整张图缩到屏幕内用下一项「适配视图」——**会覆盖手动
  摆放的位置**，执行前有确认弹窗；折叠隐藏的子树也一并排好，展开后位置合理；
- 「⋯ → 适配视图」（104-B）：把可见节点缩放到全图可见并居中（折叠隐藏的
  不参与）——布局不再隐式缩放后，这是显式的"看全图"动作；
- 「⋯ → 撤销 / 重做」（59）：多步撤销重做（栈深 50）——拖动/挂接/折叠/样式/
  自动布局逐条回退或前进，无可撤销/重做时置灰；快捷键 `Ctrl+Z` /
  `Ctrl+Shift+Z`；建删卡等级联操作不进栈（见上「撤销与重做」）；
- header「折叠全部 / 展开全部」按钮（搜索钮右侧，chevrons 双态钮，51；90 起从
  标签页头部迁入）：大图导航——有可折叠的
  分支时显示「折叠全部」（一键收起全部子树），全部收起后变为「展开全部」；
  没有任何可折叠/展开内容时按钮置灰；
- 「⋯ → 从文档目录建框架」（55/62）：见上「从文档目录一键建脑图框架」；
- 「⋯ → 导出（大纲 / OPML / 图片）…」（download，54/63；90 起从标签页头部迁入）：
  点击弹出**三选菜单**——
  **Markdown 大纲**：导出为库内 `图名 大纲.md`——层级结构与画布一致的嵌套列表，
  每行是指向对应卡片锚点的 wiki 链接，**点击即跳到书文件中那张卡的位置**（数据
  目录在库外/隐藏目录时降级为纯标题版）；**OPML 大纲**：导出 `图名.opml`——通用

  **PNG 图片**：整图所见即所得快照导出 `图名.png`（主题底色、自动等节点图片加载
  1.5 秒、瞬态高亮不入镜；超大图自动降倍率并提示）。重名自动加 -2 后缀，
  不会覆盖已有文件；
- 「⋯ → 刷新」：加入/移出节点等结构变化后手动同步画布；
- 重启 Obsidian 后标签页自动恢复上次打开的图。

## 用工作区模式同屏学习（v1 核心功能）

### 学习模式（阅读 + 复习）

1. 命令面板执行「学习模式工作区（阅读 + 复习）」。
2. 没有已开的阅读器标签时会先弹出 PDF 选择器：选文件 → 阅读器在新标签页打开，
   右侧自动分裂出复习窗格并开始到期会话；**按 Esc 取消选择器则什么都不发生**
   （不会动你正在看的笔记）。
3. 已有阅读器/复习标签则直接复用（不重复开窗格），复习会话重启，焦点回到阅读器。
4. 重复执行、两种模式交替执行都不会累积窗格（至多 阅读器 + 复习 + 脑图 三个）。

### 研究模式（阅读 + 脑图）

1. 命令面板执行「研究模式工作区（阅读 + 脑图）」。
2. 布局同上，右侧是脑图窗格并**自动定位当前书的目标图（㊴）**——同名图/按书
   覆盖的图/固定根所在图（即"下一张摘录会进的图"），无需手动选图；没有可定位
   的图时才弹选图器——**输入框可以直接打字过滤**（焦点不会被工作区抢占），
   选图/新建图后即可开始组织卡片。

### 深度复习工作区（阅读 + 脑图 + 复习三窗格，79）

1. 命令面板执行「深度复习工作区（阅读 + 脑图 + 复习）」——大屏/分屏下的
   MN4「学习集」式布局：左侧阅读原文、中间脑图、右侧复习，一次到位。
2. 没有阅读器标签时先弹 PDF 选择器（**Esc 取消则什么都不发生**），随后自动
   补齐脑图（定位当前书目标图）与复习窗格，焦点落在复习窗格、按**全部书籍**
   开始到期会话。
3. **翻卡即联动**：复习显示哪张卡，阅读侧自动滚到该卡原文位置、脑图侧自动
   定位到对应节点——卡片在别的图里时脑图会**自动切图**再定位。评分/翻面
   重复渲染不会反复滚动（同一张卡只导航一次，换卡才动）；**◀ ▶ 浏览切换与
   列表跳转不联动**——只换复习卡，两侧窗格保持原位，想看原文点 ↗ 跳转原文图标按钮。
4. 键盘评分（空格翻面 / 1-4 评分 / Ctrl+Z 撤销）照常可用——导航过程不会
   抢走复习窗格的焦点。
5. 三窗格布局下从其他入口（如主页「开始复习」）进入复习同样享受联动；
   复习窗格在后台时（比如你正在阅读侧看别的）**不会**打扰你当前的位置。

### 拖卡入图（研究模式核心交互）

1. 在阅读器里**按住任意高亮并拖动**（无需开任何模式，与单击弹菜单不冲突）。
2. 超过约 5px 即进入拖拽：一张半透明卡片预览跟随指针。
3. 拖到脑图画布上：画布出现轮廓高亮；拖到某个**节点上**：该节点高亮。
4. 松手落卡：
   - 落在**空白处** = 新增根节点（就在指针所指位置）；
   - 落在**节点上** = 挂为它的子节点（自动排到该父节点既有子节点下方，连线正确）。
5. 该卡片已在此图中会有提示；拖到脑图以外区域松手 = 取消，无任何变化；
   拖动中点右键也可取消。
6. 注意：**单击**高亮（没拖动）仍然弹出管理菜单，两者互不影响。
7. **跨弹出窗口（popout，桌面 79）**：把脑图拖成独立窗口后，从主窗的阅读器
   一样能把高亮拖过去——拖出主窗后预览自动隐藏，popout 里的脑图画布/节点
   出现高亮，松手落卡（回到主窗内则一切如常）。多显示器混合缩放下命中
   可能有数像素偏差，属已知近似。
8. **触摸屏（79）**：手指**按住高亮约半秒**（不移动）后开始拖卡；按住后
   立即滑动 = 正常滚动页面，轻点 = 弹菜单，互不干扰；长按不会弹出系统
   菜单。拖卡期间页面不会跟着滚动。

> 提示：脑图「⋯ → 刷新」可同步阅读器里后续对卡片的修改（编辑标题/批注/删除）。
> v1.1 起：批注/OCR/删卡在打开着的脑图与同文档阅读标签间**实时同步**，一般无需手动刷新
> （加入/移出节点等结构变化仍需刷新）。

## 视图切换：单文档 / 单脑图 / 左文档右脑图 / 左脑图右文档（MarginNote 学习集同款）

阅读器工具行右侧与脑图顶部都有**视图切换循环钮**（90 起单 icon 化：图标随当前
视图变化，**左键点击按 文档→脑图→左文档右脑图→左脑图右文档→文档 循环切换**，
**右键弹出四项直选菜单**可一步跳转；循环钮左侧另有「复习」入口按钮，一键打开/复用复习窗格）：

- **文档（单文档视图）**：隐藏脑图窗格，阅读器独占。你正看的图会被记住——
  切回"联动"时原样恢复（包括当时打开的是哪张图）。
- **脑图（单脑图视图）**：隐藏文档窗格，脑图独占。阅读的**文件和页码**同样被记住，
  切回时回到原来那一页。切到本模式时脑图窗格**自动定位当前书的目标图（㊴）**——
  优先同名图/按书覆盖的图/固定根所在图（即"下一张摘录会进的图"），其次恢复
  本会话上次浏览的图，两者都没有才弹选图器手动选。
- **联动（两档，93 起分左右方位）**：文档 + 脑图并排，两档只差窗格左右位置——
  **左文档右脑图**（常态档）/ **左脑图右文档**（镜像档）。切换到方位不符的档位时
  自动交换两侧窗格（文件与页码、当前图都原样保留）。脑图侧**始终跟随当前书的
  目标图（㊿ 一对一）**——同名图/按书覆盖的图/固定根所在图（即"下一张摘录
  会进的图"），不会弹出选图器；在联动下**打开另一本书、或用阅读器「脑图」
  按钮切换目标图，脑图侧会立即切换跟随**。**点击互相定位**——
  - 在**文档**里点击任意摘录高亮：脑图画布自动平移到对应节点并**闪烁标示**；
    该卡不在当前图中则无动作。**节点被折叠藏在子树里也能定位（79）**——
    所在的折叠祖先链会自动展开（只是展开画布，不进入撤销栈，Ctrl+Z 不会
    把它折回去）；
  - 在**脑图**里**单击**节点：文档侧滚动到该卡原文位置并闪烁高亮
    （同文件就地定位不开新标签；若该卡属于另一本书，阅读窗格直接切换过去）。
    标题/批注编辑走右键菜单「编辑标题/批注」（㊺-A），与单击跳原文互不冲突。
  - **关一半、另一半跟着关（㊿ 联动互关）**：联动下关闭文档标签 → 脑图标签
    随之关闭；关闭脑图标签 → 文档标签随之关闭。（切到"文档"/"脑图"单侧模式
    只是隐藏另一侧，不会误关。）

说明：

1. 四种模式也可用命令面板切换（"切换视图：单文档 / 单脑图 / 联动（左文档右脑图）/
   联动（左脑图右文档）"）。
2. 手动关闭某个标签页等于隐式切换（比如在联动视图直接关掉脑图标签，联动互关
   会把文档标签一起关掉；若还有其他标签，模式状态由实际布局决定），
   切换条的高亮状态会实时跟上。
3. 重启 Obsidian 后保持的是**退出前的实际布局**（工作区布局由 Obsidian 自己恢复）；
   隐藏侧记住的页码/图**跨重启依然有效（79）**——比如退出前在"单文档"视图，
   重启后切"脑图"或"联动"，会恢复你之前看的文件和页码/那张图（文件/图已被
   删除则自动落回选择器）。
4. 单脑图模式下单击节点不会跳原文（没有文档窗格，避免误改布局）；
   右键菜单的「跳转原文」仍会新开阅读标签。
5. 与"研究模式工作区"的关系：研究模式 = 打开联动布局的一种快捷方式；
   切换条在此基础上随时隐藏/恢复任一侧。
6. 联动的自动跟随只发生在你**点击切换条/研究模式**之后（会话内有效）——
   自己并排摆出的"文档 + 脑图"布局（比如从主页分别打开）不会被强行改图。
7. **联动方向可调（79，设置 → 工作区 → 联动方向）**：双向（默认）/ 仅文档→脑图 /
   仅脑图→文档 / 关闭。「关」= 两窗格完全独立——点高亮不跳脑图、点节点不跳
   文档、切文档不跟随、联动互关也停用。无论哪一档，**你主动点的命令不受影响**
   （切换条/工作区命令/深度复习照常编排定位）。
8. **主页不占分屏（102）**：切换四种视图时，如果"MarinMind 主页"标签还开着，
   它会被自动**收进标签组作后台标签**——文档/脑图单侧视图并入唯一窗格、联动
   视图并入左侧窗格，不会再与文档/脑图并排成一块分屏；点标签栏里的主页标签
   随时回去（停在离开时所在的导航页）。从主页打开文档本就与主页同组（后台
   标签），此规则只收拾切换过程中被"孤悬"成独立窗格的主页。

## 备份与恢复（.marginpkg）

### 导出备份

1. 命令面板执行「**导出备份（.marginpkg）**」。
2. 插件把全部笔记数据（Markdown 文件：书/卡片/脑图/复习进度）+ 库内全部 PDF 文档 +
   媒体附件打包成单个文件，写入 `Backups/MarinMind/marinmind-<时间戳>.marginpkg`
   （大库打包时界面可能卡顿数秒，属正常）。
3. 已从库中移除的 PDF 会在提示中计数说明（记录仍在，文件不再打包）；
   **库外文档的 PDF 不打包**（仅保留记录），提示会单独计数并提醒自行备份原文件。
4. 该文件可拷贝到网盘/移动硬盘留存；它本质是 zip，改后缀即可用解压工具查看内容。

### 导入备份

1. 命令面板执行「**导入备份（.marginpkg）**」→ 弹出**系统文件选择器**
   （可选库外任意位置的备份文件）。
2. 确认对话框会显示备份统计（文档数 / 卡片数 / 导出时间）；继续后：
   - 当前数据先自动快照到 `MarinMind/pre-import-snapshot/` 目录（只保留最近一份）；
   - **库内已存在的同名 PDF 跳过不覆盖**（你本地的版本优先），缺失的才从备份恢复；
   - 全部笔记数据（卡片/脑图/复习进度）被备份中的数据**整体替换**。
3. 桌面端导入完成后 Obsidian **自动重载**（注意：其他未保存的编辑会丢失）；
   移动端需**立即手动重启** Obsidian，否则旧会话可能把数据写回覆盖。
4. 误导入想回退：把 `MarinMind/pre-import-snapshot/` 里的 md 文件复制回
   `MarinMind/` 根目录（覆盖同名文件）再重启即可回到导入前状态。

> **旧版备份兼容**：SQLite 存储时代（㉚ 之前）导出的 v1 备份包仍可导入——
> 导入时会弹「导入旧格式备份」确认框，自动把旧数据转换为 Markdown 存储，之后流程相同。

> 损坏的包、来自更新版本插件的备份会被拒绝导入，原数据不受影响。

## 设置与数据管理

**设置 → 第三方插件 → MarinMind** 进入插件设置页。

### 外观（主页主题）

三选一（㊸ 起支持浅色），切换立即生效，无需重开主页：

- **Linear 深色（默认）**：主页恒为深色，与 Obsidian 当前主题无关；
- **Linear 浅色**：主页恒为浅色（白底 Linear 风格），与 Obsidian 当前主题无关；
- **跟随 Obsidian 主题**：主页随当前亮/暗色主题变化（亮色主题下主页即亮色）。

### 复习（65/68/103-A）

- **每批张数**：一次「开始复习」装载的卡片数量（默认 20，范围 5-200）——到期的
  复习卡优先，新卡殿后；
- **每日新卡上限**：每天最多进入复习的**新卡**（首次考试的卡）数量，0 = 不限
  （默认）。设了上限后当天额度 = 上限 − 当日已考新卡（撤销评分会返还额度），次日
  自动恢复——适合控制每天的新知识量；到期老卡不受此限制照常全出。
- **调度算法**：**SM-2（Anki 简化版，默认）** 或 **FSRS-4.5**——后者用「记忆
  稳定度 + 难度」双参数建模遗忘曲线，间隔安排通常更贴近真实记忆。切换即时
  生效，老卡无需任何迁移（首次按新算法评分时自动换算）。拿不准就先保持
  SM-2，两边的复习记录与统计完全互通。

### 阅读（75/77/84）

- **划选工具栏**（默认开）：阅读器里划选文字松开后弹出浮动工具栏
  （四色点摘录 / 摘录 / 线型 / 翻译 / 复制 / 添加书签 / 全局搜索），按钮说明见
  「用阅读器做摘录 → 划选工具栏」；关闭后恢复 75 之前的**划选松开即直接建卡**
  （按当前文字工具色）。
- **文字摘录线型**（默认下划线）：新建文字摘录的高亮形态——下划线 / 波浪线 /
  删除线三选；已有卡片点击高亮块菜单「线型…」单独修改，详见
  「用阅读器做摘录 → 文字摘录线型」。
- **照片入库压缩**（84-E，默认开）：超 300KB 的照片在保存前自动缩放到最长边
  2560px 并转 WebP（画质 0.85，肉眼无损），显著减小库体积与备份体积；GIF、SVG
  与小图**原样保留**，压缩后反而更大的也回退原文件。详见「媒体摘录」一节。

### AI（96，模型接入配置）

MarinMind 的 AI 功能（划选 AI 操作、文档问答与摘要、AI 制卡与相关卡、脑图
整理与 AI 大纲、复习助手，96-101 六批已全部上线）全部通过你自己的
**OpenAI 兼容 API** 工作——插件本身不内置任何模型或订阅，你的密钥只与你
自己选择的服务商通信。

- **第一步：添加预设**。设置 → AI → 「管理预设…」→「新增预设」，填四项：
  - **名称**：随便起（如 "DeepSeek" / "公司中转"）；
  - **Base URL**：填到 `/v1` 层级，如 `https://api.deepseek.com/v1`（智谱
    `https://open.bigmodel.cn/api/paas/v4`、OpenAI
    `https://api.openai.com/v1`、oneapi/new-api 系中转站按其说明填）；
  - **API Key**：服务商控制台创建（DeepSeek/智谱注册即送额度；OpenAI 需绑卡）；
  - **模型名**：如 `deepseek-chat` / `glm-4.6` / `gpt-4o-mini`。
  保存后若这是第一个预设会自动启用；之后在设置页下拉切换启用哪个。
- **第二步：点「测试连接」**：向该预设发一条最小请求——成功提示模型名，
  失败按状态码给中文排查提示（401 核密钥 / 404 查地址层级与模型名 /
  429 额度或限频）。
- **采样温度**（默认 0.3）：越低回答越确定；制卡、脑图整理这类要稳定
  结构化输出的功能建议保持低值。
- **流式输出**（默认开）：AI 回复逐字显示；个别自建网关或移动端不支持时会
  自动降级为整包返回（并记住，不再反复尝试）；追求最稳可改为「关闭」。
- **上下文 token 预算**（默认 24000）：文档问答/摘要一次能"读"进去的内容量
  上限，中文约一字一 token；大书全文问答会被截断（有提示）或分块处理。
- **累计用量**：请求次数与 token 消耗的本地统计（流式为估算），可随时清零。
- **自定义 AI 指令**（97）：「管理指令…」添加名称 + 指令（如「出题」+「针对
  这段内容出 3 道练习题并附答案」），保存后出现在划选工具栏 AI 菜单尾部。
- **安全提示**：API Key 明文存于插件数据文件，**不要在共享库中使用**。

### 划选 AI 操作与卡片 AI 评论（97，需先启用模型预设）

- **划选 → AI**：text 工具划选文字 → 工具栏点 **✦ AI** 钮 → 选操作：
  - **解释**：说明内容含义 + 背景知识与相关术语；
  - **总结**：压缩为至多 5 条要点（保留关键数字）；
  - **改写**：更通顺简洁、保持原意；
  - **自定义**：你在设置里添加的指令（出题/翻译/举例……）。
- **结果弹窗**：结果流式逐字显示；**停止**保留已生成部分；**复制结果**进
  剪贴板；**转为卡片**把结果存为原文正下方的留白卡（与译文留白同款并排
  对照；自动入图、转闪卡等与手动留白一致）。
- **卡片 AI 评论**：点已有摘录高亮（或主页卡片预览 / 复习翻面 ⋯ 菜单）→
  「AI 补充解释」——AI 结合卡片标题与你的批注给出 200 字内补充解释；点
  **「填入批注」**预填批注编辑弹窗，确认或修改后保存（AI 不直接写库，落库始终
  经你确认）。
- **全摘录类型支持（104-C）**：
  - **文字类**（文字/留白/已 OCR 的区域）：同上，文字作材料；
  - **图片类**（区域/套索/手写/照片，无需先 OCR）：附件快照直接发 AI 视觉
    解释——弹窗顶部显示摘录缩略图，AI"看图说话"；**需要多模态模型**
    （如 gpt-4o / glm-4v 系列），纯文本模型发图会报 400 并提示换模型；
  - **语音摘录**：写了批注即可（批注文字作材料，标签显示「批注」），无批注
    不出现入口；
  - 图片附件读取失败且无文字时提示降级，不会静默失败。

### AI 助手与 AI 摘要（98，文档级 AI）

- **打开 AI 助手**：阅读器 ⋯ 菜单「AI 助手…」，或命令面板「打开 AI 助手」
  ——面板停靠在右侧。先在阅读器打开一本书，然后提问。
- **上下文范围**：面板顶部下拉二选一——「当前页为上下文」（pdf 当前页 /
  epub 当前章，回答快、针对性强）或「全文为上下文」（大书会受 token 预算
  限制，超出部分从头截取并提示）。**每次提问都现取当前文档**——切换文档
  后直接继续问，无需重开面板。
- **多轮对话**：面板记住最近几轮问答；「⟲ 重置对话」清空重来。
- **🌐 联网搜索（105，叠加开关）**：输入框旁的 🌐 按钮开启后，**文档内容
  照常作上下文**，同时让模型联网搜索——适合「这篇文档的观点结合最新资料
  还成立吗」「作者提到的概念现在有新进展吗」这类文档 + 网络结合的问题；
  回答下方出现 🌐 来源 chip（点击用外部浏览器打开原文）。需模型支持：
  **GLM 系**（glm-*，走智谱 web_search 工具）/ **gpt-4o-search-preview 系**
  / **Perplexity sonar 系**；用 DeepSeek、普通 gpt-4o 等模型时点开关会提示
  换预设。注意事项：联网搜索可能**按次额外计费**（各家价格不同）；经中转站
  使用时搜索参数可能不被透传（回答照常，只是少了来源列表）；开关为内存态，
  关闭面板后重开自动复位为关；「重置对话」不影响开关。
- **跳转原文**：AI 回答里提到「（第 N 页）」时，回答下方出现页码 chip，
  点击直接跳到那一页/章。
- **AI 摘要**：阅读器 ⋯ 菜单「AI 摘要…」→ 选范围（全文/当前页章）→「开始
  摘要」。长文自动分块提炼再合并（进度行可见）；完成后「存为摘要卡」——
  摘要变成一张卡片（页顶留白卡，标题《书名》AI 摘要），自动进入脑图
  按章节归位，也会按你的设置进入复习队列。

### AI 制卡与相关卡推荐（99）

- **AI 制卡**（三个入口任选其一）：
  - 划选：text 工具划选一段内容 → 工具栏 **✦ AI** 钮 →「AI 制卡…」；
  - 高亮：点已有文字摘录 → 菜单「AI 制卡…」；
  - 卡片：主页卡片预览 ⋯ 菜单「AI 制卡…」（以该卡摘录文字为材料）。
- **预览勾选**：AI 生成问答卡与填空卡（正面/背面双行 + 类型徽标），默认
  全部勾选；去掉不想要的 →「生成 N 张卡」。
- **生成之后**：卡片带 AI/制卡 标签；划选/带原文锚点材料的卡**自动入图
  归章**、可跳回原文；设置里「AI 制卡自动转闪卡」默认开——生成卡直接
  进入复习队列（问答：问题为正面、答案为背面；填空：挖空句为正面、
  原句为背面）。
- **相关卡推荐**：主页卡片预览 ⋯ 菜单或脑图节点右键菜单 →「相关卡片（AI）…」
  ——AI 从**同一本书**的其他卡片中推荐语义相关的（附一句理由，宁缺毋滥），
  勾选 →「建立 N 条链接」——写入双向链接，同图两卡间出现虚线边（跨图
  链接在卡片预览/复习的关联区可见）。手工卡（无文档归属）暂不支持——
  候选按同文档收集。

### AI 整理与 AI 大纲（100）

- **整理整图**：脑图 ⋯ 菜单 →「AI 整理…」——把根级的散乱卡片按语义归组。
  AI 给出分组建议（每组显示组名与成员摘要）→ 勾掉不想要的组 →「整理
  （N 组）」：新建分组卡、成员移入其下、自动布局归位。**Ctrl+Z 可一步
  撤销**（分组关系与位置整体回退；撤销后空的分组卡会留在原位，可手动删除）。
- **整理子级**：右键某个节点 →「AI 整理子级…」（子级 ≥4 时出现）——只
  整理该节点的直接子级，分组卡挂在该节点下。
- **AI 大纲建框架**：在阅读器打开一本书 → ⋯ 菜单 →「AI 大纲建框架…」——
  AI 通读全文提炼层级大纲（预览树中「页码未核对」的条目不会入库）→
  「创建 N 张章节卡」——章节骨架卡建入本书的**摘录目标图**（通常是与
  目录建框架相同的图），之后阅读时的摘录会按页码自动归入对应章节。
  已经有目录框架的书会提示重复、不再另建。

### AI 复习助手（101）

复习现场的 AI 四件套（MarinMind 特色，MN4 没有）——待考卡有"问题"
（批注）时才出现：

- **AI 提示（未翻面）**：卡壳了点「AI 提示」——AI 只给**方向性线索**
  （相关概念、思路方向、关键词类别、首字/字数），不剧透答案（请求本身
  就不携带答案，并有"严禁复述/暗示答案"约束双保险）。提示显示在答案
  之前，一眼能看出有没有泄底。
- **选择题自测（未翻面）**：点「选择题自测」——AI 出 3 个同范畴的迷惑性
  错误项，与正确答案混成 4 个选项；点选后锁定上色（正确的绿、选错的
  红）。**自测不影响评分**——仍按真实记忆难度用 1-4 四档评分。
- **AI 解释（翻面后）**：看完答案还想深入，点「AI 解释」——弹出解释
  弹窗，可一键**填入批注**（把理解写回卡片，下次复习就是自己的话）。
- **错题总结（收尾屏）**：一轮考完，完成屏出现「错题总结（AI）· 本组
  N 张」（N 是评"重来"的卡数）——AI 流式归纳**共性薄弱点 + 每点一条
  复习建议**，看完可「存为卡片」留档（在卡片列表可搜「错题总结」）。

### 工作区（79 联动方向）

- **联动方向**四选一（默认**双向**，存量行为不变）：
  - **双向联动**：点高亮跳脑图定位、点节点跳原文、切文档脑图跟随，全部生效；
  - **仅文档 → 脑图**：只有点高亮定位/切文档跟随，点节点不跳原文；
  - **仅脑图 → 文档**：只有点节点跳原文，点高亮/切文档不带动脑图；
  - **关闭（两窗格独立）**：以上自动联动全部静默，联动互关也停用。
  显式命令（切换条、工作区模式、深度复习工作区的导航）不受此开关约束。

### 数据目录（Markdown 笔记与媒体附件的存放位置）

- 默认存放在库内 `MarinMind/`——**你的全部笔记数据就是普通 Markdown 文件**：
  每本书一个 `<书名>.md`（内含该书的摘录卡片、批注、书签、复习进度）、
  每张脑图一个 `脑图/<图名>.md`、媒体附件在 `assets/`。可以直接在 Obsidian 中
  打开阅读、搜索、打标签，也能用 git/同步盘管理版本。
- **手动编辑 md 即生效**：修改卡片的批注/摘录文本/标签（callout 正文与 `#tag`）后
  保存，插件会自动重新读入；重命名文件或删除文件也会被识别
  （删除 = 删除该书/图的全部记录，会弹提示）。几何位置、复习进度等机器数据
  存在行内注释 `<!--mm …-->` 中，**不建议手改**（改坏了单张卡会被跳过并提示，
  不影响其他卡片）。
- 桌面端可改为**本机绝对路径**（如 `D:\MarinMindData`，可移出 Obsidian 库与同步盘；
  注意 vault 外目录**没有**手动编辑回灌能力）；移动端仅支持库内相对路径。
  输入时即时校验，非法值（`..`、反斜杠等）红字提示。
- 修改后点击 **「应用并迁移数据…」**：确认弹窗 → 验证目标可写 →
  把全部 md 文件与媒体附件**复制**到新位置（旧位置原样保留作为回退）→ 自动重载。
  - 目标位置已有 md 文件时，会询问是否继续，**默认取消**（不会静默覆盖）；
  - 迁移失败（目录只读、被网盘/杀软锁定等）时原数据不受影响，插件回到旧目录继续可用；
  - 确认新位置一切正常后，旧目录可手动删除（插件不会自动删）。
- **从旧版本升级**：老版本（SQLite 存储）用户首次启动时，若检测到旧数据
  `.marinmind/marinmind.db`，会弹窗引导「转换为 Markdown 存储」（也可随时从命令面板
  执行「**从旧版数据库导入**」）。转换是复制式的——旧 `.marinmind/` 原样保留，
  确认无误后可自行删除。
- **不要把数据目录设成点开头的隐藏目录**（如 `.marinmind`）：Obsidian 的库索引
  会跳过点开头目录——里面的卡片笔记无法被搜索、阅读，卡片链接/嵌入也全部
  解析失败（启动时与复制链接时都会有提示）。若你的数据目录还是旧版 `.marinmind`，
  在上方输入框改为 `MarinMind` 并点「应用并迁移数据…」即可（复制式迁移，
  旧目录保留可回退）。
- 多设备同步库注意：数据目录设置保存在各设备自己的 `data.json`；
  桌面设置的绝对路径在移动端会自动回退默认目录（有提示，不影响使用）。

### 备份目录

`.marginpkg` 备份的落点，默认库内 `Backups/MarinMind/`，同样支持桌面绝对路径。
修改即时保存——只影响之后的导出，已生成的备份文件不动；不能与数据目录相同。

### 附件健康（孤儿扫描与清理，84-E）

- **启动自动扫描**：每次启动插件会核对 `assets/` 里的文件与全部卡片的引用——
  发现**孤儿文件**（文件还在、没有任何卡片引用它，通常是历史误删卡片的残留）时
  弹确认框列出数量与前 5 个文件名，**默认取消**（宁拒不赌），确认后删除并报数；
  一切正常则静默不打扰。
- **卡有引用但文件丢失**（缺失附件）不弹窗不删卡——仅在控制台记日志并弹一次
  计数提示，相关卡片在预览/复习时自动降级为提示文字（走文档管理重关联或从备份
  恢复文件即可）。
- 主动体检：命令面板 **「扫描并清理附件…」**——随时手动扫描，无孤儿时提示
  「附件完好」。

### 文档管理（失联检测与重关联）

入口：命令面板 **「文档管理（重关联失联文档）」** 或设置页「打开文档管理面板」。

- **失联是什么**：插件运行期间在库内移动/改名 PDF，卡片记录会自动跟随；
  但插件未运行时移动、或文件被移出/删除，记录就找不到原文件了——
  表现为跳原文提示"原文文件不在当前库中"。
- 面板列出全部文档记录（标题 / 路径 / 卡片数 / 状态徽标）：
  - **徽标三种**：「正常」（库内文件就位）/「库外」（桌面绝对路径文档，中性色）/
    「已失联」（文件找不到了——库内被移出/删除，或库外路径已失效，红色）。
  - **失联行 →「重关联」**：选中该 PDF 现在的位置（可选库内文件，也可选库外路径），
    卡片、复习进度、脑图节点**全部原地保留**（只改记录指向，零丢失）。若目标文件
    已关联另一份**有卡片**的文档记录，会拒绝并提示（不做自动合并）；若目标只是一条
    空记录（打开过但没做摘录），确认后由失联记录接管。
  - **失联行 →「删除记录」**：确认后删除该文档记录及其全部卡片（含媒体附件文件）、
    复习进度、脑图节点——**不可恢复**，确认弹窗会写明影响范围。
  - 正常行 →「打开」直接进阅读器（手机上库外文档不提供此按钮——移动端打不开）。
- 提示：执行重关联/删除前，若该文档正被阅读器打开，请先关闭对应标签页。
  库外文件在库外被改名/移动后**不会自动跟随**（插件收不到库外的文件变动通知），
  需在此面板手动重关联。

## 媒体摘录（照片 / 手写 / 语音）

阅读器内的三种摘录形态**要求当前打开了文档**（卡片锚定当前阅读位置所在页）；
不打开文档也有入口——命令面板可建**自由媒体卡**（落「未归类卡片」，见下节）。
附件保存在数据目录的 `assets/` 子目录（默认 `MarinMind/assets/`，单文件 ≤ 20MB），
会随 `.marginpkg` 备份一并导出；超 300KB 的照片入库前自动压缩
（缩放到最长边 2560px 转 WebP，画质 0.85 肉眼无损；GIF、SVG 与小图原样保留，
设置 → 阅读 → 「照片入库压缩」可关）。

### 照片摘录

1. 打开 PDF 后，任选一种方式插入图片：
   - 「⋯ → 插入图片摘录…」（90 起自标签页头部迁入）选择图片文件（可多选）；
   - 直接 **Ctrl+V 粘贴**截图（阅读器标签页处于激活状态时生效）；
   - 把图片文件**拖入**阅读视图。
2. 卡片建在当前视口中心所在的页；页面上不留矩形痕迹，
   该页右上角出现「N 个媒体摘录」徽标作为入口。
3. 点击徽标 → 菜单列出该页媒体卡 → 点击打开预览弹窗
   （查看图片 / 编辑标题/批注（78 双字段）/ 转闪卡 / 删除）。
4. **定位到页面（84-D）**：徽标菜单打开预览弹窗 → 「定位到页面…」→
   回到阅读器在目标页拖一个框，照片即以**虚线展示框**锚定在该处
   （框内照片铺满显示，点击弹卡片菜单，可再次拖框微调，Esc 结束）。
   已定位的卡跳转原文时**精确滚动到展示框并闪烁**；「取消定位」
   （卡片菜单 / 预览弹窗均可）清空展示框，回到仅页码锚定的徽标形态。

### 手写批注（手写摘录）

1. 点击工具栏 **✏（pencil，摘录工具组右侧，仅 PDF 显示；90 起自标签页头部迁入）**
   开启手写模式（与摘录工具互斥，开启一个会关闭另一个）。
2. 在页面任意位置直接书写（红色笔迹，支持触屏/手写笔）；此时页面不响应滚动，
   缩放后笔迹依然清晰（内部按页面比例记录）。
3. **压感笔锋（84-A）**：手写笔的按压力度实时影响线宽（轻笔细、重笔粗，
   导出 PNG 同步变宽）；鼠标书写保持恒定线宽（与旧版观感一致）。
4. **撤销 / 橡皮擦 / 清空（84-A）**：手写模式下页面底部悬浮工具条——
   ↶ 撤销（或 **Ctrl/Cmd+Z**，回退上一笔/上一次擦除/清空，最多 50 步）、
   橡皮擦（按住拖过笔迹，命中线段 12px 内整笔删除）、🗑 清空本页笔迹
   （可撤销）。
5. **提交**：滚动离开该页 / 再点 ✏ 退出模式 / 切换文档 / 关闭标签页时，
   该页笔迹自动聚合成一张卡片（透明底 PNG 图片，精确裁剪到笔迹范围）。
6. 回显为**绿色虚线框内的图片**：单击弹管理菜单（转闪卡/批注/删除），
   按住拖动可拖入脑图——与其他高亮的操作完全一致。

### 语音摘录

1. 点击「⋯ → 录音摘录」（90 起自标签页头部迁入，录音中该项变为「结束录音」并
   打勾）开始录音：页面顶部出现状态条
   （红点呼吸 + **实时波形（84-B）** + 计时 + 「保存并建卡」「丢弃」按钮；
   环境不支持波形采样时自动降级为纯计时）。
2. 再点一次菜单项或点「保存并建卡」结束并建卡（锚定当前页）；
   点「丢弃」弹确认框，确认后放弃本次录音。
3. 误关标签页/切换文档时**录音自动保存**，不会丢失已录内容。
4. 回放：该页徽标 → 菜单 → 预览弹窗中直接播放（标题显示时长，如
   「语音摘录 · 1:23 · 第 5 页」）；复习界面媒体卡正面也可播放。
5. **重录（84-B/84-C）**：预览弹窗「重录」→ 确认后删除旧卡（含附件）并
   立即开始新录音——阅读器内锚定当前页；主页卡片预览弹窗也可重录
   （锚定原卡归属）。注意旧卡的标题/批注/复习进度不保留。
   （范围决策：不做波形裁剪保留片段——整段重录更省事。）

### 自由媒体卡（84-C：不打开文档的快速捕捉）

命令面板（Ctrl/Cmd+P）两条命令，卡片落「**未归类卡片**」
（主页 → 卡片页可见，可后续归组/复习；不参与自动入图）：

- **「捕捉照片为自由卡片」**：选一张或多张照片批量建卡；
- **「录音摘录（自由卡片）」**：toggle 语义——首次执行开始录音
  （录音条悬浮在界面顶部，跨视图存续），再次执行保存。

阅读器录音与全局录音互斥（麦克风独占）：一边在录时另一边会提示先处理当前录音。

### 复习媒体卡

媒体卡（照片/手写/语音）转为闪卡后，复习界面正面直接显示图片或音频播放器
（下方标注形态与页码，语音卡含时长），翻面评分流程与普通卡一致。
照片卡可在主页预览弹窗里给图片**添加遮挡**（拖框区域复习时遮住，
图内坐标——与文字卡的页级遮挡是两套体系）。

> 注意：语音摘录需要系统授予 Obsidian 麦克风权限（首次会弹系统询问）；移动端录音格式
> 依平台自动回退（webm/mp4/ogg）。

## OCR 识别扫描版文字

扫描版 PDF 没有文字层（划选不出文字）——用区域摘录 + OCR 补齐：

1. 按前文「区域框选」把要识别的部分框成摘录（彩色边框）。
2. **点击该高亮 → 菜单选「识别文字 (OCR)」**。
3. 首次使用会联网下载识别引擎与语言包（约 10-20MB，看网络需几十秒），
   之后缓存在本地、离线可用；识别中提示条显示进度百分比。「首次需联网
   下载」提示**每次会话最多出现一次**（85-C：同会话引擎已就绪后不再提示，
   失败提示也会按是否就绪给出不同指引）。
4. 识别结果自动写入卡片的摘录文字——**复习正面直接显示文本**、脑图节点也改用该文字，
   与普通文字摘录卡一致。卡片原本已有文字时会弹确认框（结果替换旧文字）。
   85-D 起，识别出的文字在**编辑标题/批注**面板与**卡片预览弹窗**中以
   「摘录（只读）」块展示（编辑面不改摘录文字，OCR 纠错仍走重新识别覆盖）。
5. 手写摘录（绿色框）同样可以 OCR——识别的是**笔迹本身**（笔迹 PNG 合成白底
   放大后识别，83 修复了旧版误识笔迹下方原页的问题）；tesseract 对自由手写
   识别率有限，较工整的字迹效果更好。

### OCR 设置（83）

设置 → MarinMind → **文字识别 (OCR)**：

- **识别语言**：12 种组合下拉（中简繁/日/韩/法/德/西/意/葡/俄 ±英，默认
  中英混排）。切换后首次识别会联网下载对应语言包（约 10-20MB，之后缓存
  离线可用）。
- **拖框即识**：开启后区域摘录**框完松开即自动识别**（免二次点菜单）。默认关
  ——首次会静默联网下载引擎，且连续摘录会被逐框识别等待打断；仅桌面端 PDF
  生效。引擎层串行队列保证连续拖框时进度条逐框依次显示互不抢乱。
- **识别后自动翻译**：OCR 成功后自动把识别文字翻译（目标语言与引擎跟随
  「翻译」节设置），译文**存为原文正下方的留白胶囊**——扫描版外文书一步到位
  （MN4「AI OCR 翻译」）。翻译失败不影响已识别的文字（会弹提示说明）。

### 整页 OCR（83）

PDF 页面**右键 →「识别本页文字 (OCR)」**：整页一次识别，按行生成一张文字
摘录卡（逐行下划线回显、可跳原文、可转闪卡/入脑图）。整页识别不走自动翻译
（防整页长文翻译与留白洪水）。仅桌面端 PDF 可用。

> 提示：识别失败多为网络问题（引擎下载被墙/代理未生效），恢复网络后重试即可
> （引擎不会重复下载）。小区域精度由 PSM 版面模式自动细分（大块/单行/单词
> 各用对应模式）。**移动端不支持 OCR**，菜单项已禁用。

## 翻译并保存译文（㉔，83 多引擎 + 三入口）

参照 MarginNote「翻译及保存译文」：把摘录文字翻译成目标语言，译文可以
**存为留白卡片（与原文并排对照）**或**复制到剪贴板**——外文书的定义、结论
随手一译，不用切出去查词典。

**三个入口，语义分工（83-E）**：

- **划选工具栏「翻译」** → 译入**侧栏翻译页签**（即时对照，不建卡）；
- **点击已有高亮 →「翻译」** → 翻译弹窗（对照 + 存留白）；
- **复习界面顶部「翻译」钮**（83-F）→ 同弹窗；有页码定位的卡可存留白，
  手工卡（无页码）仅对照 + 复制。

### 翻译弹窗 / 侧栏通用

1. 上方下拉切换**目标语言**（MN4 同款 13 种：简体/繁体中文、英语、日语、
   韩语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语、粤语、文言文）——
   切换立即重译，且会**记住你的选择**（下次翻译默认用它，也可在
   设置 → MarinMind → 翻译 里改）。源语言自动检测并显示在语言旁。
2. 译文出来了，两个动作任选：
   - **「存为留白」**：译文以留白胶囊**放在原文正下方**（色随「留白」工具当前色系），
     与原文并排对照；
     它就是一张普通卡片——可编辑标题/批注、转闪卡、拖入脑图；「添加到脑图」
     开着（默认开）也会自动入图。
   - **「复制译文」**：复制到系统剪贴板，可粘贴到任意地方。
3. 翻译失败（网络不通、凭据缺失、引擎不支持该目标语言等）会显示原因，
   点「重试」即可；单次上限 5000 字符，超长会提示拆分。

### 翻译侧栏页签（83-E，划选即时翻译）

阅读器左侧边栏第三个页签（目录 · 书签 · **翻译**）：

1. 文字工具划选 → 点工具栏「翻译」→ 侧栏自动打开翻译页签，原文/译文对照
   即时显示（**不建卡**——MN4「研究 → 翻译侧栏」语义）。
2. 侧栏停在翻译页签时，**再划选自动刷新**译文（500ms 防抖）。
3. 侧栏内可切换目标语言、「存为留白」「复制译文」（与弹窗同款动作）；
   引擎/凭据问题在侧栏内直接显示错误态，不弹 Notice。

### 译文留白折叠（83-F）

留白胶囊（含 OCR 自动翻译落下的译文）右侧有 **chevron 小钮**：点击展开
**多行全文**（32em / 30vh 内滚动），再点收起回单行省略；全文也可悬停 title
查看。点胶囊**本体**仍是打开卡片菜单。展开状态会话内记忆（重开文档回到折叠）。

### 翻译引擎（83 起：Google / 百度 / 有道 / DeepL）

设置 → MarinMind → 翻译 → **翻译引擎**：

- **Google**（默认）：免费接口免密钥；**需要网络可达
  translate.googleapis.com（国内通常需要代理）**。
- **百度翻译**：国内免代理直连——fanyi.baidu.com 注册「通用翻译API」（标准版
  免费，限 1 次/秒）获取 APP ID 与密钥填入。侧栏自动刷新的 500ms 防抖即是为
  该限频设计。
- **有道翻译**（85-B）：国内免代理直连——ai.youdao.com 注册并创建「自然语言
  翻译服务」应用（文本翻译，新用户有免费额度），在应用详情查**应用 ID 与
  应用密钥**填入，并确认应用已绑定「文本翻译服务」（错误码 110 即未绑定）。
- **DeepL**：deepl.com/pro#developer 注册 DeepL API Free（每月 50 万字符免费）
  获取密钥；免费版密钥以 `:fx` 结尾（自动走免费版端点）。

> 说明：粤语/文言文目标语言仅 Google 与百度支持（有道/DeepL 会报「不支持目标
> 语言」友好提示，切换目标语言或引擎即可）；凭据明文存于插件数据文件，请勿在
> 共享库中使用。移动端全部入口可用。OCR 过的区域/手写卡要先「识别文字」再翻译
> （翻译的是卡上的文字）。

## AI 一键摘录（批量建卡，㉓）

参照 MarginNote「一键摘录」：**基于文档文字层自动识别 标题 / 正文 内容块**，
预览勾选后**批量生成卡片**——不用逐段划选，整页/整章一次性变成卡片集
（「添加到脑图」开着的话（默认开），生成的卡会自动入图）。

1. 打开 PDF 后点「⋯ → **AI 摘录**」（89 起从工具行按钮移入 ⋯ 菜单）。
2. 选**范围**：当前页，或输入页码范围（单次最多 50 页）。
3. 选**元素类型**：标题 / 正文（按需勾选——先筛元素再摘录，与 MN4 建议一致；
   页眉、页脚自动排除，不会生成无意义的页码卡）。
4. 点「开始识别」→ 列出检出的内容块（每行：类型徽标 + 页码 + 文字摘要），
   **逐项勾选**或全选/清空。
5. 点「生成 N 张卡片」——每块一张文字卡：摘录文本 + 逐行高亮矩形，与其他摘录
   完全同构（点高亮管理、跳原文精确定位、拖入脑图、转闪卡全部可用）。
   **标题紫、正文黄**（同类型同色，MN4 同款），一眼区分两类内容。
6. **重复内容自动去重（㉕）**：再次对同一范围执行时，与已有卡片重复的块会
   灰显并带「已有」徽标、**默认不勾选**（认为已摘过），需要补建可手动勾选。

> 说明：识别基于 PDF 自带文字层的**版面几何**（字号/位置/间距的规则分析），
> 不联网、不调用外部 AI 服务。扫描版 PDF 没有文字层，会提示改用矩形摘录 + OCR。
> 标题识别（㉕ 增强后）看四类信号：字号明显大于正文、章节词/编号等文本模式
> （第X章、1.2、Chapter 1、INTRODUCTION）、居中短行、行距突增——仅加粗但
> 字号相同的小标题大多也能被文本模式认出；个别列表编号行可能被误判为标题，
> 预览里取消勾选即可。中文书籍的**段首缩进**会正确切分段落（相邻段不黏连），
> 英文行尾断词自动拼接（不出现 "pow-ered" 破碎词）。

## 与 Obsidian 笔记整合（㊻：卡片互链与嵌入）

MarinMind 的每张卡片都存在数据目录里的标准 Markdown 文件中（默认
`MarinMind/书名.md`——每张卡片是一个 `> [!excerpt]` 标注块，带 `^card-xxx`
块锚点）。这意味着**任何普通笔记、白板（Canvas）都可以直接链接或嵌入这些卡片**，
Obsidian 原生解析，无需任何配置。

### 复制入口（三处）

| 位置 | 操作 |
| --- | --- |
| 阅读器 | 点击高亮 → 菜单「复制卡片链接」/「复制嵌入代码」 |
| 思维导图 | 右键节点 → 「复制卡片链接」/「复制嵌入代码」 |
| 主页 | 卡片列表点开预览弹窗 → 「复制链接」/「复制嵌入」（链接/复制图标） |

### 两种形态

- **链接**：`[[MarinMind/书名#^card-xxx|卡片标题]]`——贴进任何笔记，点击跳到
  卡片所在位置，悬停可预览标注块内容。
- **嵌入**：`![[MarinMind/书名#^card-xxx]]`——把卡片标注块**整块渲染**进当前
  笔记。在 **Canvas 白板**上新建卡片、粘贴嵌入代码，即可把摘录卡当作白板节点
  摆进画布自由组合。

### 说明

- 卡片里的行内 `#tag`、批注中的 `[[双链]]` 本来就是标准 md 语法——全局搜索、
  关系图谱、Dataview 等其他插件天然可用。
- 链接在**点击复制的那一刻实时生成**；之后修改书名或移动文件，Obsidian 会
  自动更新已粘贴的链接（vault rename 联动）。
- **数据目录配置在库外（桌面绝对路径）时无法生成链接**——Obsidian 只认库内
  路径，此时会弹提示；需要此功能请把数据目录设回库内（见「数据目录」一节）。
- **数据目录是隐藏目录（以 `.` 开头，如旧版的 `.marinmind`）时链接同样不生效**
  ——Obsidian 索引不到点开头目录里的任何笔记（搜索、阅读、链接全部失效），
  复制入口会弹提示并停止；请在 **设置 → MarinMind → 数据目录** 迁移到普通文件夹
  （如 `MarinMind`，迁移是复制式、旧目录保留可回退）。提示「未创建，点击以创建」
  时**不要点击创建**——那会新建一个空白文件，与卡片数据无关。

## 常见问题

- **启用后提示"数据层初始化失败"**：查看控制台（Ctrl+Shift+I）中的错误日志；
  尝试把数据目录（默认 `MarinMind/`）改名后重启（数据是普通 md 文件，改名即备份，
  排查后可改回）。
- **升级插件后数据丢失**：数据存放在 `MarinMind/`（或你设置的数据目录），与插件目录分离，
  正常更新插件不影响数据。
- **手动编辑 md 没生效？**：确认编辑的是数据目录内的文件且已保存；插件写盘有 2 秒
  防抖，若插件恰好也在写同一文件（如刚做完摘录），你的批注/文本/标签修改仍会被合并
  保留（有 Notice 提示）；vault 外的数据目录（桌面绝对路径）不支持手动编辑回灌。
- **PDF 移动/改名后卡片丢了？**：插件运行期间移动会自动跟随；若文件在插件未运行时
  移动过（跳原文提示"不在当前库中"），打开「文档管理」面板 → 该行会标"已失联" →
  点「重关联」选中新位置即可，卡片/复习进度/脑图节点全部保留。
- **移动端提示"数据目录设置无效，已回退到默认目录"**：多设备同步库中桌面端把
  数据目录设成了绝对路径，移动端无法使用该路径——正常现象，移动端数据落在默认目录，
  两端各自独立（云端统一数据请保持默认目录）。
- **从旧版本（SQLite 存储）升级**：首次启动会自动弹窗引导迁移；错过了可随时在命令面板
  执行「**从旧版数据库导入**」。旧 `.marinmind/` 目录在转换后原样保留，确认无误后
  可手动删除。
