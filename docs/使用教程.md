# 使用教程

> 当前版本（0.1.x）处于**开发早期**：数据层已就绪，尚无完整用户界面。
> 本文档先覆盖安装与开发流程；随功能落地逐步补充使用说明。

## 安装插件（开发者方式）

1. 克隆本仓库并安装依赖、构建：

   ```bash
   npm install
   npm run build
   ```

2. 将构建产物放入 Obsidian 库的插件目录：

   ```
   <你的库>/.obsidian/plugins/marinmind/
   ├── main.js        # 构建产物（含内嵌 SQLite WASM）
   ├── manifest.json  # 插件元数据
   └── styles.css     # 样式（阅读/复习/脑图）
   ```

   Windows 也可用符号链接代替复制（需管理员权限）：

   ```bat
   mklink /D "<库>\.obsidian\plugins\marinmind" "D:\work\ff_ProjCollection\marinmind"
   ```

3. 在 Obsidian 中打开 **设置 → 第三方插件**，关闭安全模式后启用 **MarinMind**。

## 日常验证

- 点击左侧功能区 📖（book-open）图标，或命令面板（Ctrl+P）执行
  **"打开 MarinMind 阅读器（选择 PDF）"**——模糊搜索库内 PDF 后新标签页打开。
  也可用「学习/研究模式工作区」一键分屏（见下文）。
- 执行 **"显示库统计（文档 / 卡片 / 待复习）"**——验证数据库是否正常初始化，
  会显示当前 文档数 / 卡片数 / 待复习数 / 脑图数。
- 启用插件后，库根目录会出现隐藏目录 `.marinmind/`，其中 `marinmind.db`
  即 SQLite 数据库（删除该目录 = 清空 MarinMind 数据）。

## 用阅读器做摘录（v1 核心功能）

### 方式一：区域框选（适合图表/公式/版面）

1. **打开 PDF**：功能区 📖 或命令面板 → 选择库内 PDF（支持输入目录名过滤）。
2. **浏览**：连续滚动阅读；工具栏 ＋ / ／"适应宽度"按钮调整缩放，
   拖动窗格宽度会自动重排。
3. **摘录**：点击工具栏 **✏（square-pen）** 开启摘录模式（按钮高亮）→
   在页面上按住左键拖出矩形 → 松手即生成知识卡片，黄色高亮即时回显。
   - 拖拽过程中点右键可取消；
   - 过小的框（< 6px）视为误触自动忽略；
   - 从右下往左上反向拖拽也可以，会自动归一。
4. **查看/删除卡片**：点击任意黄色高亮 → 菜单显示卡片信息 → 可删除。
5. **持久化**：关闭标签重开、重启 Obsidian 后高亮原位恢复；
   在文件管理器里重命名 PDF，卡片归属自动跟随。
6. 再次点击 ✏ 关闭摘录模式，恢复正常滚动/点击。

### 方式二：划选文字（适合定义/结论/段落）

1. 直接像普通网页一样在页面上**按住左键划选文字**（无需开任何模式）。
2. 松开鼠标即生成卡片：摘录文本 + 逐行蓝色高亮（多行选区 = 多个精确矩形）。
3. 点击蓝色高亮同样可查看信息/删除。
4. 选区跨页时会提示"跨页摘录请分次选择"——每页选一段分别生成即可。
5. 注意：扫描版 PDF 没有文字层，无法划选（OCR 支持在规划中）；
   区域摘录模式下文字层不可选中，先关闭 ✏ 模式再划选。

> 说明：阅读器是独立视图，**不改变** PDF 的默认打开方式——
> 文件管理器双击 PDF 仍是 Obsidian 内置视图。

## 用复习界面背卡片（v1 核心功能）

1. **转闪卡**：在阅读器点击任意高亮（黄色=区域摘录，蓝色=文字摘录）→
   菜单选「转为闪卡」。卡片默认只是摘录，转为闪卡后才进入复习队列。
   - 同一菜单还能「编辑批注」（弹窗输入，保存后成为卡片答案面）与「删除卡片」。
2. **开始复习**：命令面板（Ctrl+P）执行「开始复习（到期闪卡）」→ 打开复习标签页
   （已开过则复用并重新加载）。刚转为闪卡的卡片立即到期，马上可复习。
3. **翻面与评分**：
   - 正面显示摘录（区域摘录显示"区域摘录 · 第 N 页"占位）；
   - **空格 / 回车**（或点"翻面看答案"）显示批注与出处；
   - **1 / 2 / 3 / 4**（或点按钮）评分：重来 / 困难 / 良好 / 简单，自动排下次到期。
4. **"重来"的卡**：本组末尾会再次出现（Anki 风格），直到评过其他档位。
5. **跳转原文**：翻面后点「↗ 跳转原文」→ 新标签页打开阅读器，**精确定位到摘录矩形**
   （滚动到矩形上方并闪烁高亮两次）；照片/语音卡则闪烁页角徽标。
6. **完成**：队列耗尽显示四档统计；「再查一批到期卡片」可续刷下一组（每组 20 张）。
7. **取消闪卡**：回到阅读器点该卡高亮 → 「取消闪卡」即移出复习队列（调度历史保留）。

> 提示：复习界面只在它处于**激活标签页**时响应键盘；切到其他标签页按数字键不会误触。

## 用思维导图组织卡片（v1 核心功能）

### 建图与加卡片

1. **打开脑图**：命令面板执行「打开思维导图（选择 / 新建脑图）」→ 选图器里选已有图，
   或选首项「➕ 新建脑图」输入名称（留空默认"未命名脑图"）。
2. **三条加卡路径**：
   - **阅读器里**：点击高亮 →「加入思维导图…」→ 选图/新建图，卡片落在根节点区；
   - **脑图工具栏**「添加卡片」（list-plus）：模糊搜索最近 200 张卡片，
     次行显示出处（《书名》· 第 N 页 / 手工卡片），已在当前图中的不会出现；
   - **双击画布空白**或工具栏「新建文字卡片」（plus）：输入文字生成手工卡（无文档归属）。
3. 新节点自动落位：加到图里的卡片排在根节点区最下方顺延。

### 拖拽组树与画布操作

1. **拖节点到另一节点上** = 挂为它的子节点（自动连线重画）；
   **拖到空白处** = 只移动位置。
2. 拖到**自己的后代节点**上会被拒绝（防止成环），但位置照常保存。
3. **平移**：普通滚轮或按住左键拖空白处；**缩放**：Ctrl+滚轮（以鼠标位置为中心，0.25x–2.5x）。
4. 拖动过程中**点右键**取消，节点回到原位。
5. **节点右键菜单**：跳转原文（新开阅读器**精确定位到矩形并闪烁**）/ 编辑批注（保存后节点文字即时更新）/
   转为·取消闪卡 / 移出脑图（卡片保留，其子节点上浮为根）/ 删除卡片（节点一并删除）。

### 图的管理

- 视图顶部可**重命名**（✏️）与**删除**（🗑️，需确认；卡片保留，只删组织结构）；
- 工具栏「刷新」（rotate-cw）：在阅读器里改了卡片（如编辑批注、删除）后手动同步到画布；
- 重启 Obsidian 后标签页自动恢复上次打开的图。

> v1 约定：同一张卡片可在多张图中各自成节点；同一图内一张卡只有一个节点。

## 用工作区模式同屏学习（v1 核心功能）

### 学习模式（阅读 + 复习）

1. 命令面板执行「学习模式工作区（阅读 + 复习）」。
2. 没有已开的阅读器标签时会先弹出 PDF 选择器：选文件 → 阅读器在新标签页打开，
   右侧自动分裂出复习窗格并开始到期会话；**按 Esc 取消选择器则什么都不发生**
   （不会动你正在看的笔记）。
3. 已有阅读器/复习标签则直接复用（不重复开窗格），复习会话重启，焦点回到阅读器。
4. 重复执行、两种模式交替执行都不会累积窗格（至多 阅读器 + 复习 + 脑图 三个）。

### 研究模式（阅读 + 脑图）

1. 命令面板执行「研究模式工作区（阅读 + 脑图）」。
2. 布局同上，右侧是脑图窗格并自动弹出选图器——**输入框可以直接打字过滤**
   （焦点不会被工作区抢占），选图/新建图后即可开始组织卡片。

### 拖卡入图（研究模式核心交互）

1. 在阅读器里**按住任意高亮并拖动**（无需开任何模式，与单击弹菜单不冲突）。
2. 超过约 5px 即进入拖拽：一张半透明卡片预览跟随指针。
3. 拖到脑图画布上：画布出现轮廓高亮；拖到某个**节点上**：该节点高亮。
4. 松手落卡：
   - 落在**空白处** = 新增根节点（就在指针所指位置）；
   - 落在**节点上** = 挂为它的子节点（自动排到该父节点既有子节点下方，连线正确）。
5. 该卡片已在此图中会有提示；拖到脑图以外区域松手 = 取消，无任何变化；
   拖动中点右键也可取消。
6. 注意：**单击**高亮（没拖动）仍然弹出管理菜单，两者互不影响；
   跨弹出窗口（popout）与触摸屏暂不支持拖卡。

> 提示：脑图窗格的工具栏「刷新」可同步阅读器里后续对卡片的修改（编辑批注/删除）。

## 备份与恢复（.marginpkg）

### 导出备份

1. 命令面板执行「**导出备份（.marginpkg）**」。
2. 插件把 SQLite 笔记库 + 库内全部 PDF 文档 + 媒体附件打包成单个文件，写入
   `Backups/MarinMind/marinmind-<时间戳>.marginpkg`（大库打包时界面可能卡顿数秒，属正常）。
3. 已从库中移除的 PDF 会在提示中计数说明（数据库记录仍在，文件不再打包）。
4. 该文件可拷贝到网盘/移动硬盘留存；它本质是 zip，改后缀即可用解压工具查看内容。

### 导入备份

1. 命令面板执行「**导入备份（.marginpkg）**」→ 弹出**系统文件选择器**
   （可选库外任意位置的备份文件）。
2. 确认对话框会显示备份统计（文档数 / 卡片数 / 导出时间）；继续后：
   - 当前数据先自动快照到 `.marinmind/pre-import-snapshot-<时间戳>.db`（只保留最近一份）；
   - **库内已存在的同名 PDF 跳过不覆盖**（你本地的版本优先），缺失的才从备份恢复；
   - 全部笔记数据（卡片/脑图/复习进度）被备份中的数据**整体替换**。
3. 桌面端导入完成后 Obsidian **自动重载**（注意：其他未保存的编辑会丢失）；
   移动端需**立即手动重启** Obsidian，否则旧会话可能把数据写回覆盖。
4. 误导入想回退：把 `.marinmind/` 里的 `pre-import-snapshot-*.db` 改名为 `marinmind.db`
   再重启即可回到导入前状态。

> 损坏的包、来自更新版本插件的备份会被拒绝导入，原数据不受影响。

## 媒体摘录（照片 / 手写 / 语音）

三种摘录形态都**要求当前在阅读器中打开了文档**（卡片锚定当前阅读位置所在页）；
附件保存在库内 `.marinmind/assets/`（单文件 ≤ 20MB），会随 `.marginpkg` 备份一并导出。

### 照片摘录

1. 打开 PDF 后，任选一种方式插入图片：
   - 工具栏 **🖼（image-plus）** 按钮选择图片文件（可多选）；
   - 直接 **Ctrl+V 粘贴**截图（阅读器标签页处于激活状态时生效）；
   - 把图片文件**拖入**阅读视图。
2. 卡片建在当前视口中心所在的页；页面上不留矩形痕迹，
   该页右上角出现「N 个媒体摘录」徽标作为入口。
3. 点击徽标 → 菜单列出该页媒体卡 → 点击打开预览弹窗
   （查看图片 / 编辑批注 / 转闪卡 / 删除）。

### 手写批注（手写摘录）

1. 点击工具栏 **✎（pencil-line）** 开启手写模式（与区域摘录模式互斥，开启一个会关闭另一个）。
2. 在页面任意位置直接书写（红色笔迹，支持触屏/手写笔）；此时页面不响应滚动，
   缩放后笔迹依然清晰（内部按页面比例记录）。
3. **提交**：滚动离开该页 / 再点 ✎ 退出模式 / 切换文档 / 关闭标签页时，
   该页笔迹自动聚合成一张卡片（透明底 PNG 图片，精确裁剪到笔迹范围）。
4. 回显为**绿色虚线框内的图片**：单击弹管理菜单（转闪卡/批注/删除），
   按住拖动可拖入脑图——与其他高亮的操作完全一致。

### 语音摘录

1. 点击工具栏 **🎤（mic）** 开始录音：页面顶部出现状态条
   （红点呼吸 + 计时 + 「保存并建卡」「丢弃」按钮）。
2. 再点一次 🎤 或点「保存并建卡」结束并建卡（锚定当前页）；
   点「丢弃」放弃本次录音。
3. 误关标签页/切换文档时**录音自动保存**，不会丢失已录内容。
4. 回放：该页徽标 → 菜单 → 预览弹窗中直接播放；复习界面媒体卡正面也可播放。

### 复习媒体卡

媒体卡（照片/手写/语音）转为闪卡后，复习界面正面直接显示图片或音频播放器
（下方标注形态与页码），翻面评分流程与普通卡一致。

> 注意：语音摘录需要系统授予 Obsidian 麦克风权限（首次会弹系统询问）；移动端录音格式
> 依平台自动回退（webm/mp4/ogg）。

## OCR 识别扫描版文字

扫描版 PDF 没有文字层（划选不出文字）——用区域摘录 + OCR 补齐：

1. 按前文「区域框选」把要识别的部分框成摘录（黄色高亮）。
2. **点击该高亮 → 菜单选「识别文字 (OCR)」**。
3. 首次使用会联网下载识别引擎与中文语言包（约 10-20MB，看网络需几十秒），
   之后缓存在本地、离线可用；识别中提示条显示进度百分比。
4. 识别结果自动写入卡片的摘录文字——**复习正面直接显示文本**、脑图节点也改用该文字，
   与普通文字摘录卡一致。卡片原本已有文字时会弹确认框（结果替换旧文字）。
5. 手写摘录（绿色框）同样可以 OCR（把手迹当图片识别，效果取决于字迹工整度）。

> 提示：识别失败多为网络问题（引擎下载被墙/代理未生效），恢复网络后重试即可
> （引擎不会重复下载）。**移动端不支持 OCR**，菜单项已禁用。

## 开发工作流

```bash
npm run dev   # watch 模式：修改 src/ 自动重建 main.js（Obsidian 中重载插件即可看到变化）
npm test      # 运行全部单元测试（vitest）
npm run build # 生产构建（类型检查 + 打包）
```

## 常见问题

- **启用后提示"数据库初始化失败"**：查看控制台（Ctrl+Shift+I）中的错误日志；
  尝试删除 `.marinmind/marinmind.db` 后重启（当前版本尚无生产数据，可安全重建）。
- **升级插件后数据丢失**：数据存放在 `.marinmind/`，与插件目录分离，
  正常更新插件不影响数据。
