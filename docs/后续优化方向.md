# 后续优化方向

> 记录已知的 v1 限制与计划中的优化项，随版本推进消化。

## 阅读视图（v1 遗留）

- [ ] **文字层定位精度**：span 用基线近似定位（保证可选中即可）；
      复杂排版（竖排、多栏基线偏移）下选中体验可能偏差，
      必要时改用 pdf.js 官方 `TextLayer` 渲染器。
- [ ] **多标签同步**：同一 PDF 开多个阅读标签时，高亮各自持有快照互不同步；
      可引入事件总线或定期 `listByDocument` 刷新。
- [ ] **混合页尺寸**：当前统一按第 1 页宽 fit；混合尺寸 PDF 可按页自适应。
- [ ] **摘录颜色/样式**：多种高亮颜色、透明度设置（数据层 `Card.color` 字段已预留，
      当前区域=黄、文字=蓝两档固定）。
- [ ] **页码跳转 / 目录（PDF outline）导航栏**。
- [ ] **滚动位置记忆**：视图状态（当前页、缩放）存入 ViewState，
      重开时恢复（当前重开回到第一页 + 适应宽度）。
- [ ] **Esc 取消拖拽**：当前仅右键取消。
- [ ] **移动端验证**：`loadPdfJs` 移动端可用，但 canvas 内存压力大，
      dpr/像素钳制与懒卸载已做，需真机验证（长按选中文字交互也需验证）。

## 复习界面（v1 遗留）

- [ ] **跳原文精确定位**：当前只滚到卡片所在页；可再滚到 rects 区域并短暂闪烁高亮。
- [ ] **due 分批与统计面板**：`due()` 每组固定 20 张；可做每日复习量设置、
      热力图/累计统计（数据都在 review_states 表）。
- [ ] **复习界面编辑批注**：翻面后发现批注要改，需回阅读器；可在背面直接挂编辑入口
      （NoteEditModal 已有，接上即可）。
- [ ] **新卡混排策略**：当前只有到期卡（新转闪卡立即到期）；可加"新卡每日上限 +
      到期优先"的混排。
