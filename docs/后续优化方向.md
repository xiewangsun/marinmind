## Markdown 文档阅读（㊻-B 遗留）

      ㊽ 起矩形/套索已有内容快照，数据前提就绪；
      价值有限（md 本身是文字），优先级低。
- [ ] **库外 md**：桌面绝对路径 md 直读（cachedRead 换 readExternalBinary +
      MarkdownRenderer，sourcePath 语义需处理内链解析降级）。

## EPUB 文档阅读（㊼ 遗留）

- [ ] **书籍自带 CSS（部分尊重）**：统一主题排版刻意忽略全部书籍样式，个别
      精排书（固定版式教科书/绘本）观感损失——候选：白名单 CSS 属性子集
      （缩进/对齐/字体族）经净化后内联，或每书"跟随书籍样式"开关。
- [ ] **竖排（vertical-rl）**：日文原版书竖排元数据被忽略，横排渲染——
      需 writing-mode 支持与划选/摘录几何适配，工程量大单独评估。
- [ ] **音频/视频摘录内嵌播放**：净化层整删 audio/video（DRM 之外也有体积/
      性能考量）——外语音书场景需媒体引用卡（excerptRef 存 zip 内条目 +
      提取落盘附件仓）。
- [ ] **字体混淆（obfuscation）解密**：encryption.xml 一律拒开（与 DRM 同判）；
      IDPF 字体混淆算法已知（sha1 前缀异或）可解——解开后书内字体可用，
      但 DRM 仍必须拒。需区分两种加密类型分级处理。
- [ ] **AI 一键摘录**：与 md 同因（无 pdf 文字层几何）挂账；EPUB 章节 DOM
      结构化程度更高（p/h 层级明确），DOM 版面分析可行性反而更好，可与
      md 的 AI 摘录合并做一套 DOM 版块识别。
- [ ] **图片直链预览**：a 链接指向 zip 内图片条目（非 spine）当前 Notice 拒——
      可弹 MediaPreviewModal 式预览窗（blob URL 已有管线）。
- [ ] **超长单章分段渲染**：单章几十万字渲染/测量有可感卡顿（当前整章一次
      渲染）——按 h2/h3 边界分片 + 章内懒加载（㊾ 后深跳只渲染目标章，前置章
      不再是瓶颈，卡顿只剩目标章自身的体量）。
- [ ] **占位页骨架完全虚拟化**：㊾ 后骨架仍为每章建一个占位 div（千章级
      ensurePagesUpTo 跳页前同步补齐会有可感耗时）——极致方案是章级虚拟列表
      （只建视口附近的占位），依赖 contain-intrinsic-size 全部就绪后可做。
- [ ] **章内图片单趟批量预热（可选）**：readEntry 按需解压后，插图多的章滚入
      视口时逐图单条目解压（每图一趟 central directory 扫描）——可改为章渲染
      前按该章 manifest 收集图片名合一趟 filter 解压，收益中等优先级低。
- [ ] **book-format「第 N 页」章节措辞**：epub 书的书文件分节标题显示「第 N 页」
      （序列化层无文档格式感知）——显示层换词需动序列化（字节稳定优先挂账），
      或读取时按扩展名映射不改字节。
- [ ] **跨书 spine 资源链接**：a 链接解析只查本书 spine，跨书引用（罕见）
      unsupported——低价值挂账。
