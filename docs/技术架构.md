## 数据层

- **SQLite 经 sql.js（WASM）**：无原生依赖，跨桌面/移动端；WASM 经 esbuild binary loader
  内联进 main.js。库文件在库根 `.marinmind/marinmind.db`，写操作标脏后防抖 2s 整库导出落盘，
  onunload 时 flush。
- **仓储模式**：仓储只依赖 `MarinMindDatabase`（不 import obsidian），测试用内存库
  （`MarinMindDatabase.open()` 无参即可）。
- **迁移**：`MIGRATIONS` 数组按 `PRAGMA user_version` 递增应用；只允许追加，禁止改历史脚本。
- **级联**：删除文档级联删卡片/链接/复习状态（`PRAGMA foreign_keys=ON`，open 时按连接开启）。
- **脑图级联链（v2 迁移）**：删图→节点全删（CASCADE）；删卡→节点删（CASCADE）；
  删文档→卡删→节点删（两跳）；删中间节点→子节点 **SET NULL 上浮为根**（子树不静默丢失）。
  `UNIQUE(map_id, card_id)` 保证一图一卡一节点（仓储 addNode 查重先返 undefined）。

## 阅读视图

- **渲染**：`loadPdfJs()` 复用 Obsidian 内置 PDF.js，不自带 pdfjs-dist；
  只用 getDocument/getPage/getViewport/render/destroy 稳定 API 面（局部类型 `pdfjs-types.ts`）。
- **层级**：canvas（底）→ 透明文本层（可选中，划选文字摘录）→ overlay
  （默认穿透，摘录模式捕获）。高亮块挂 overlay，% 定位（缩放免重排），data-color 区分黄/蓝。
- **懒渲染**：IntersectionObserver（root=滚动容器，rootMargin 100% 预渲染一屏）；
  离开视口 unrender 释放 canvas/文本层，容器高度保留防滚动跳动。
- **竞态防护**：
  - `whenReady()`：视图/命令等待 DB 就绪；
  - `loadToken` 代际守卫：onLoadFile 重入时旧流程作废；
  - 渲染序号：文本层异步填充时校验，缩放/卸载后的过期结果丢弃；
  - 同页在途 RenderTask 取消：防 "same canvas" 并发渲染错误。
- **打开方式**：必须 `leaf.setViewState({type, state:{file}})`——openFile 会落入内置 PDF 视图
  （未 registerExtensions，刻意不接管默认打开）。
- **页码定位（revealPage）**：页码经 setViewState state 传入，`setState` 覆写暂存 pendingPage，
  **`await super.setState()` 之后**应用（同文件时 FileView 不重跑 onLoadFile，只在加载末尾
  应用会永不消费）；滚动用 getBoundingClientRect 差值（offsetTop 的 offsetParent 链不可靠），
  滚前 getPageSize 校正占位尺寸，目标页渲染交给 IO。

## 复习界面

- **分层**：`ReviewSession`（纯逻辑，零 obsidian 依赖，vitest 覆盖）负责快照队列、翻面态、
  again 队尾重现、统计；`MarinMindReviewView`（ItemView）只做渲染与事件。
- **会话语义**：构造收 `reviews.due()` 快照（默认 limit 20，Done 态"再查一批"续刷）；
  again 卡本地队尾重现（Anki 风格同会话再考），DB 侧 SM-2 照常 dueAt=+10min——两者解耦，
  会话中断后卡约 10 分钟重新到期。
- **键盘**：keydown 挂 document（contentEl 是 div 不可聚焦），`activeLeaf === this.leaf`
  才响应；过滤 Ctrl/Meta/Alt 组合键与 INPUT/TEXTAREA/contentEditable 目标；
  Space/Enter 在 keydown 级 preventDefault（防触发聚焦按钮 click 与页面滚动）。
- **闪卡入口**：阅读器高亮菜单"转为闪卡/取消闪卡"（每次开菜单即时查 DB）。

## 思维导图

- **分层**：`mindmap-graph.ts` 纯逻辑（零 DOM，vitest 覆盖：环检测 isDescendantOrSelf——
  visited 防脏数据成环死循环；新节点落位 suggestRoot/ChildPosition；三次贝塞尔 edgePath）；
  `MarinMindMindmapView`（ItemView "marinmind-mindmap"）负责画布渲染与手势。
- **渲染结构**：viewport（事件宿主，点阵背景）→ world（唯一 transform 容器：
  `translate(tx,ty) scale(s)`）→ svg 连线 + 节点 div。节点 left/top 与 SVG path **均为未缩放
  世界坐标**，天然对齐；`toWorld()` 是唯一客户端→世界换算点。
- **两个必须**：svg `overflow:visible`（SVG 默认 300x150 视口会裁掉画布外连线）；
  事件挂 viewport 不挂 world（world 是 0×0 容器收不到事件）。
- **拖拽状态机**：单 pointerdown 入口按 `closest(".marinmind-mm-node")` 分流节点/平移；
  4px 位移阈值（未超过=点击，右键可取消）；setPointerCapture 保证移出元素仍收到 move/up；
  升级拖动时被拖节点 `pointerEvents:none` 给 `elementFromPoint` 命中检测让路，pointerup 恢复；
  **拖动过程只写内存与 DOM，pointerup 才写库**（moveNode + 命中他节点且非后代时 setParent；
  命中自己后代 Notice 拒绝但坐标仍落库）。
- **缩放**：wheel `passive:false`（registerDomEvent 第三参）；Ctrl/Cmd 时
  `k=exp(-deltaY*0.0015)`，`next=clamp(s*k, 0.25, 2.5)`，平移量按 `tx = px - (px-tx)*(next/s)`
  反推（指针下的世界点不动）；普通滚轮直接平移。连线描边 `vector-effect:non-scaling-stroke`
  保持视觉宽度稳定。
- **环检测归属**：仓储 setParent 只校验存在/同图/非自身；环检测在视图层用内存快照
  O(深度) 完成（repo 无递归 SQL，职责清晰）。
- **状态恢复**：getState/setState 存 mapId；setState 先于 onOpen 执行，骨架未建时暂存
  pendingMapId 由 onOpen 消费，已建则立即切换（镜像 reader 的 pendingPage 模式）。
- **跨视图同步**：打开时快照 + 工具栏手动刷新（v1 不做事件总线）。

## 多窗格工作区与拖拽入图

- **工作区预设**（main.ts）：学习=阅读+复习、研究=阅读+脑图，各一条命令。
  幂等布局：`getLeavesOfType(target)` 有则复用（复习重启会话、脑图保持当前图），
  没有才分裂。**split 锚点竞态**：`getLeaf("split","vertical")` 从调用时刻的激活 leaf
  右侧分裂（'horizontal'=下方，命名反直觉）——setActiveLeaf 与 getLeaf('split') 必须
  同一同步块零 await。研究模式创建路径 `focus:false`，避免抢走脑图选图器 Modal 的输入焦点。
- **拖拽入图分层**：excerpt-layer 拖卡状态机（起点）→ mindmap-view 模块级 `activeViews`
  注册表 + `updateMindmapDropHint`/`clearMindmapDropHints`（落点提示）→ 视图 public
  `dropCard`（落库 + 增量渲染）。落位决策在 `mindmap-graph.dropPlacement` 纯函数
  （命中节点→suggestChildPosition 子落位；空白→指针世界坐标，vitest 覆盖）。
- **pointer 机制要点**：capture 只改事件路由、`elementFromPoint` 是几何 hit-test 互不影响
  （ghost 必须 pointer-events:none）；但 capture 下 click 仍派发到捕获元素（高亮自身），
  须 overlay **捕获阶段** stopPropagation；pointerdown 不 preventDefault（否则连带抑制 click）。
- **清理全路径**：pointercancel / contextmenu / setExcerptMode / destroy / 高亮被删
  （pointermove 的 isConnected 守卫 + 一次性 lostpointercapture 兜底）统一走 cancelCardDrag，
  ghost 挂 body、状态类驱动样式，杜绝泄漏残留。
- **多脑图同屏防串图**：命中节点 `nodeEls.get(id) === el` 归属验证；提示遍历全部注册视图清理。
- **已知限制**：跨 popout 窗口不支持（capture 与 elementFromPoint 均限本 document）；
  触摸端不支持拖卡（高亮不设 touch-action:none 保滚动）；无公开"移动 leaf 到 split"API，
  目标视图被并成同组后台标签时不强制拆分。

## 备份（.marginpkg）

- **分层**：`backup-zip.ts` 纯函数（fflate zipSync/unzipSync 组包解包 + 校验，vitest 覆盖，
  零 obsidian 依赖）；`backup-service.ts` 编排（vault/adapter/Notice 只在此层）。
- **包结构**：`manifest.json`（format/version/schemaVersion/计数/导出时间）+
  `marinmind.db`（level 6 压缩）+ `documents/<vault相对路径>`（PDF 已压缩，level 0 store）+
  `assets/<相对路径>`。解包校验：format、必备条目、zip-slip（拒 `..` 段/绝对路径/前缀不符）、
  `schemaVersion` 高于当前拒绝（低于放行，打开时迁移链自然升级）。
- **导出**：`db.exportBytes()` 是**内存权威快照**（flush 在 !dirty 时直接 return、且 async 有
  竞态，读回文件不可靠）；文档经 adapter.readBinary 逐个读取，缺失跳过计数；
  落盘 `Backups/MarinMind/`（vault.createFolder/createBinary，进 Obsidian 索引便于右键打开目录）。
- **导入顺序（关键）**：安全快照（`pre-import-snapshot-*.db`，只留 1 份）→
  **`flush(); close();` 之后才覆盖 DB_PATH**——close 清掉防抖定时器且让 onunload 的 flush
  失效，否则 reload 触发的旧库写回会覆盖刚导入的数据 → 文档已存在跳过（TFile 优先）、
  缺失的 vault.createBinary 恢复（ensureParentFolder 递归）→ assets 覆盖写 →
  桌面 `app:reload` / 移动端提示立即重启（内存中各视图仍持旧库快照，disable/enable 不彻底）。
- **导入入口**：隐藏 `<input type="file" accept=".marginpkg">`——可选 vault 外文件，
  比 FuzzySuggestModal 更符合备份文件的使用场景。
- **取舍**：同步 zipSync 大库卡 UI 数秒（低频操作 + Notice 预告；异步 fflate 依赖
  Blob worker，Obsidian CSP 下未验证）；Uint8Array 写盘前统一 `.slice().buffer`
  拷独立 buffer（fflate/sql.js 返回值可能共享或带 byteOffset）。

## 媒体摘录（照片 / 手写 / 语音）

- **附件体系**：`AttachmentStore`（main 构造期挂单例，注入 MediaStorageAdapter 可测）——
  媒体存 `.marinmind/assets/<uid>.<ext>`（20MB 上限）；`Card.excerptRef` 全链路预留故
  **零数据库迁移**；excerptRef 存完整 vault 相对路径（自包含）；**uid 唯一命名 ⇒ 一卡一附件**，
  deleteCard 直接 `attachments.remove`（失败静默）；备份导出收集整个 assets 目录。
- **照片**：三入口（按钮选图 / paste / drop）共用 handleImageFiles；paste 挂 **document** +
  activeLeaf 守卫（否则吞别的标签的复制）；dragover 必须 preventDefault 否则 drop 不触发；
  原样存字节不重编码（保 EXIF 方向）；锚定 `getCurrentPage()`（视口中心命中页，间隙回退最近页）。
- **手写**：`handwrite-layer.ts` 每页一 canvas 层（与 ExcerptLayer 同构），关键机制：
  - **归一化笔迹模型**（0-1 相对页面）——canvas width/height 赋值会清空内容，
    ResizeObserver 触发的重设尺寸后按模型全量重绘，缩放无忧；
  - **commit() 同步快照**：进入函数即快照 strokes 并清空模型，再异步渲染 PNG——
    destroy/cleanup 与渲染完成之间的竞态不影响提交数据；页基准尺寸 =
    displayWidth / getScale() 同步可算（不依赖异步存活的 pdf 实例）；
  - **提交时机全路径**：滚离视口（scroll 监听 + 防抖）/ 退出模式 / 切文档 / 关视图——
    cleanupContent 里 fire-and-forget，docId 同步捕获，**卡片入库优先于高亮回显**
    （cleanup 后 layers 已清，回显跳过，重开文档自然恢复）。
- **手写回显**：excerpt-layer 的 handwriting 卡走专用分支——透明虚线框内嵌 `<img>`
  （PNG 按 bbox 裁剪，容器比例 = 图片比例，铺满无失真）；点击菜单/拖卡入图复用高亮机制零改动。
- **语音**：`audio-recorder.ts`——pickAudioMime 回退链（webm;codecs=opus→webm→mp4→ogg，
  isTypeSupported 可注入测试）；MediaRecorder timeslice 1000ms（中途崩溃最多丢 1s）；
  **stop 是异步的**：docId/page 在 await 前同步捕获；cleanupContent 时 stop+保存不丢弃
  （误关标签不损失已录内容）。
- **页角徽标**：photo/audio 卡无页面矩形（rects 为空），按 `mediaCardsByPage` 分组，
  页容器右上角挂徽标（DOM 由 updateMediaBadge 维护）→ 菜单列卡 → `MediaPreviewModal`
  （img/audio + 批注 + 闪卡/编辑/删除，hooks 回调与 reader 联动）。
- **复习展示**：review-view 正面媒体分支 fire-and-forget 加载（`.then` + isConnected 守卫，
  渲染后立刻翻页则丢弃）；`mediaUrls Map` 同 ref 复用。
- **blob URL 生命周期（三处，漏一处长期泄漏）**：ExcerptLayer Map +
  removeHighlight/destroy；review-view Map + onClose；MediaPreviewModal onClose。

## 区域 OCR

- **加载链**：tesseract.js 主包（API 面）经 npm 进 bundle（约 +49KB）；worker 脚本与核心
  WASM 运行时**首次使用时从 CDN 下载**（jsdelivr worker/core + tessdata 语言包，合计
  10-20MB），语言包缓存 IndexedDB 二次离线可用。`workerBlobURL:true` 让 worker 代码经
  Blob URL 装载，绕开远程 worker 脚本的 CSP 限制（Text Extractor 插件已验证该链路可行）。
- **版本锁（关键坑）**：`TESS_VERSION` 常量与 package.json 双处同步——CDN 资源与主包
  版本不一致时 worker 与主包消息协议不匹配，报错极难排查；升级必须双改并重测。
- **worker 单例**：模块级 workerPromise 懒创建；**失败 catch 后重置为 null**
  （网络恢复后重试不必重启 Obsidian）。logger 在 createWorker 时固定注册，进度经
  模块级 statusSink 转发（ocrCanvasRegions 开头设置、finally 清除）。
- **逐矩形识别**：`worker.recognize(canvas, {rectangle})` 原生支持子区域，不 crop+stitch；
  **rectangle 必须用 canvas 内部像素**（width/height 属性）换算——renderTo 已按 dpr 与
  16M 像素钳制设定物理分辨率，CSS 尺寸与识别无关；换算后不足 1 像素的矩形跳过。
- **渲染隔离**：`pdf-document.renderTo` 新增 `opts.isolated`——OCR 离屏高清渲染
  （目标物理宽约 2200px）不取消同页在途显示渲染、也不注册 inFlight，互不抢占
  （pdf.js 允许同页并发渲染到不同 canvas）；渲染期文档被销毁时 done 静默返回，
  调用方以 `canvas.width === 0` 判定放弃。
- **文本清洗**：ocr-text 纯函数——全角空格归一、CRLF 归一、行内空白折叠、去空行
  （保留换行反映版面段落）；多矩形按顺序 \n 拼接。写入 `cards.update(excerptText)`，
  复习/脑图现有文本分支自动受益。
- **入口约束**：仅 area/handwriting 且有 rects 的卡显示菜单项；移动端
  `Platform.isMobile` 直接 Notice 禁用。

## 已知取舍（v1）

| 取舍 | 理由 | 后续 |
| ---- | ---- | ---- |
