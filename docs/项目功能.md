# 项目功能

> MarinMind —— Obsidian 学习插件：电子书阅读器 + 思维导图 + 学习卡"一站式学习工具"。
> 口号：革新性整合阅读标注工具、思维导图和学习卡。
>
> 本文档按模块记录功能的设计目标与当前实现状态，随开发进度更新。

## 功能总览

## 阅读视图（v1，已实现）

- **入口**：功能区 📖 图标或命令面板「打开 MarinMind 阅读器（选择 PDF）」→
  模糊搜索库内 PDF（支持按目录名搜索）→ 新标签页打开。
  刻意不接管 PDF 默认打开方式（文件管理器双击仍用 Obsidian 内置视图）。
- **渲染**：复用 Obsidian 内置 PDF.js（`loadPdfJs`），连续滚动 + 视口懒渲染
  （远离视口的页自动释放显存），高分辨率屏按 devicePixelRatio 渲染保证清晰。
- **缩放**：工具栏 ± 按钮与"适应宽度"；调整窗格宽度自动重排。
- **区域摘录**：工具栏 ✏（square-pen）开启摘录模式 → 在页面上拖拽框选 →
  自动生成知识卡片（记录页码 + 归一化矩形，缩放/设备无关）→ 黄色高亮即时回显。
  拖拽中右键取消；过小的框选视为误触忽略。
- **文字摘录**：直接在页面上划选文字（无需开任何模式，透明文本层承载原生划选）→
  松开鼠标即生成卡片，摘录文本与逐行高亮矩形（选区实测，多行 = 多矩形）一并入库 →
  蓝色高亮回显，与区域摘录的黄色区分。跨页选区会提示分次选择。
  扫描版 PDF 无文字层，划选不可用（待 OCR 支持）。
- **持久化**：摘录写入 SQLite（`.marinmind/marinmind.db`），关闭重开、重启 Obsidian
  后高亮原位恢复；PDF 文件重命名后卡片归属自动跟随。
- **卡片管理**：点击任意高亮 → 菜单可"转为闪卡 / 取消闪卡"（进入/移出复习队列）、
  "编辑批注"（弹窗 textarea）、"加入思维导图…"（选图/新建图后卡片落为根节点）、"删除卡片"。
- **多标签实时同步**：同一 PDF 开多个阅读标签时，任一标签的新摘录/编辑/删除即时同步
  到其他标签（高亮与页角徽标），无需重开。

## 媒体摘录（v1，已实现）

照片 / 手写 / 语音三种摘录形态，附件存库内 `.marinmind/assets/`（uid 命名，一卡一附件，
随 `.marginpkg` 备份一并导出）。**需先在阅读器打开文档**（v1 不做无文档归属的自由媒体卡）。

- **照片摘录**：三个入口任选——工具栏 🖼（image-plus）按钮选图 / 直接 **Ctrl+V 粘贴**
  截图 / 把图片文件**拖入**阅读视图。图片原样保存（保留 EXIF 方向信息），
  卡片锚定当前阅读位置所在页；页面上无框选痕迹，以页角徽标为入口。
- **手写摘录**：工具栏 ✎（pencil-line）开启手写模式（与区域摘录模式互斥）→
  在页面上直接书写（红笔，支持触摸）→ 笔迹按归一化坐标记录，缩放/重排后依然清晰。
  **提交时机**：滚动离开该页 / 退出手写模式 / 切换文档 / 关闭视图时，单页聚合为一张卡
  （精确包围盒 + 透明底 PNG），绿色虚线框内嵌图片回显——点击弹管理菜单、可拖入脑图，
  与其他高亮完全同构。
- **语音摘录**：工具栏 🎤（mic）开始/结束录音，录音中顶部悬浮状态条
  （红点计时 + 保存/丢弃）。误关标签页不丢内容（自动保存）；音频格式按环境自动回退
  （webm/opus → mp4 → ogg）。
- **页角徽标**：有照片/语音卡的页面右上角显示「N 个媒体摘录」，点击列出该页媒体卡 →
  打开预览弹窗（图片/音频播放 + 批注），弹窗内可转闪卡 / 编辑批注 / 删除卡片（附件随之删除）。
- **复习界面**：媒体卡正面直接显示图片或播放器（手写/照片显示笔迹图片，语音可播放），
  翻面批注/评分流程与其他卡一致。

## 区域 OCR（v1，已实现）

- **用途**：扫描版 PDF 无文字层（划选不可用）——先框选区域摘录，再 OCR 得到文本；
  手写摘录也可识别（把笔迹区域当图片识别，实际效果取决于字迹工整度）。
- **入口**：点击区域（黄色）或手写（绿色）摘录的高亮 → 菜单「识别文字 (OCR)」。
- **流程**：插件把该页以约 2200px 宽高清渲染到离屏画布 → 对卡片矩形逐块识别
  （中英文混排）→ 清洗拼接后写入卡片的摘录文字——复习正面、脑图节点随即显示该文本。
  卡片已有文字时弹确认框（OCR 结果替换）。
- **引擎**：tesseract.js 懒加载——**首次使用需联网下载引擎与中文语言包（约 10-20MB）**，
  下载后缓存本地，二次使用离线可用；下载/识别进度在提示条中显示。
- **限制**：移动端不可用（tesseract 移动端 Obsidian 环境不支持）；识别精度受扫描质量影响；
  仅桌面端、需接受联网下载。

## 复习界面（v1，已实现）

- **转闪卡**：在阅读器点击任意高亮 → "转为闪卡"。卡片默认只是摘录，需显式转为闪卡
  才进入复习队列（与 MarginNote 语义一致）。
- **开始复习**：命令面板「开始复习（到期闪卡）」→ 独立标签页。会话取当前到期卡片
  （每组最多 20 张，做完可"再查一批"续刷）。
- **卡片流程**：正面显示摘录（文字摘录显示原文，区域摘录显示"区域摘录 · 第 N 页"占位）→
  空格/回车翻面 → 背面显示批注（无则"暂无批注"）与出处（书名 · 页码）→ 四档评分：
  **重来(1) / 困难(2) / 良好(3) / 简单(4)**，SM-2 自动排下次到期时间。
- **重来语义**：评"重来"的卡在本组队尾重现（Anki 风格，同会话再考），
  数据库里 10 分钟后重新到期——中断会话也不丢。
- **跳转原文**：翻面后点"跳转原文"→ 打开阅读器并**精确定位到摘录矩形**（滚动到
  矩形上方约 1/4 视口处并闪烁高亮两次）；照片/语音卡无矩形则闪烁页角徽标；
  文件不在库中时提示。
- **完成统计**：队列耗尽显示四档评分统计与总次数。

## 思维导图（v1 + 折叠/自动布局，已实现）

- **多张命名脑图**：命令「打开思维导图」弹出选图器（首项可就地新建/重命名），
  跨书混排——任何卡片都能加入任何图，天然支持"多本书放一张脑图"。
- **卡片即节点**：一卡一节点（同一图内不重复）；节点显示 批注 > 摘录文字 > 形态占位，
  左侧颜色条沿用摘录色（黄=区域/蓝=文字），带「第 N 页 / 手工」出处徽标。
- **加卡片三条路**：阅读器高亮菜单「加入思维导图…」；画布工具栏「添加卡片」
  （模糊搜索最近 200 张，已在图的不出现，次行显示《书名》·页码）；
  双击空白/工具栏「新建文字卡片」（无文档归属的手工卡）。
- **拖拽组树**：拖节点到另一节点上 = 挂为其子节点（连线重画）；拖到空白 = 移动位置；
  拖到自己后代会被拒绝（环检测）。删除中间节点时子节点上浮为根，子树不丢。
- **画布手势**：普通滚轮 / 拖空白 = 平移；Ctrl+滚轮 = 以指针为中心缩放（0.25x–2.5x）；
  拖动中右键取消还原。
- **折叠子树**：有子节点的节点右缘悬停出现 ▾ 按钮，点击折叠整个子树——节点缩为
  带后代计数的 "▸ N" 胶囊（N = 隐藏的后代数，含多层）；折叠态写入数据库，
  重启 Obsidian 后保留。折叠期间拖卡到该节点照常挂为其子节点（展开后自动落位）。
- **自动布局**：工具栏「自动布局」（layout-template）→ 确认后一键整理为标准层级树
  （同层对齐一列、父节点垂直居中于子块、多根自上而下堆叠；折叠隐藏的子树也一并
  排好，展开后位置合理），完成后自动缩放居中到全图可见。会覆盖手动摆放的位置。
- **节点右键菜单**：跳转原文（打开阅读器**精确定位到矩形并闪烁高亮**，同复习界面）/
  编辑批注（就地更新节点文本）/ 转为·取消闪卡 / 移出脑图（卡片保留）/ 删除卡片（级联删节点）。
- **实时同步（跨视图）**：在阅读器里编辑批注、OCR 写入文字、删除卡片——打开着的脑图
  视图**即时同步**（节点文本更新/节点消失），无需手动刷新；同一 PDF 开多个阅读标签时
  新摘录也互相同步。
- **持久化**：图与节点结构（含折叠态）存 SQLite；重启 Obsidian 后标签页恢复上次打开的图。
  节点加入/移出等结构变化后用工具栏「刷新」手动同步。

## 多窗格工作区与拖拽入图（v1，已实现）

- **学习模式工作区**：命令一键布局——左侧阅读器 + 右侧复习窗格（自动开始到期会话）。
- **研究模式工作区**：左侧阅读器 + 右侧脑图（自动弹选图器；输入框焦点不被抢占）。
- **幂等**：已有阅读器/目标窗格则复用（不重复分裂，焦点回到阅读器）；没有阅读器时
  弹 PDF 选择器新标签页打开，取消选择即放弃布局（不动当前笔记）。
- **拖卡入图**：在阅读器**按住任意高亮拖动**（非摘录模式）→ 半透明卡片跟随指针 →
  拖到脑图画布上出现落点提示 → 松手：
  - 落在**空白**=新增根节点（指针所指位置，缩放/平移后依然准确）；
  - 落在**节点上**=挂为其子节点（自动落到标准子节点位置，与既有兄弟顺延）。
  已在图中的卡片会提示，不重复添加。单击高亮（未拖动）仍弹管理菜单。
- **限制**：跨弹出窗口（popout）拖拽不支持；触摸端不支持拖卡（桌面特性）；
  用户手动把脑图/复习并成阅读器同组后台标签时，预设不会强制重新拆分。

## 核心设计

### 以"卡片"为中心的数据模型

摘录即卡片，卡片既是脑图节点又是闪卡——**一份数据三种用途**（脑图、复习、回链原文），这是区别于普通阅读器的核心设计。

当前落地的数据模型（`src/types.ts`）：

- **BookDocument（文档）**：被阅读的书籍（PDF/EPUB），以库内路径为唯一业务键。
- **Card（知识卡片）**：由摘录生成，携带原文回链（PDF 页码 + 归一化矩形列表，
  与缩放/设备无关），支持五种摘录形态：文字 / 区域 / 手写 / 语音 / 照片。
- **CardLink（双向链接）**：卡片间手动建立的关联，两个方向等价。
- **Mindmap / MindmapNode（脑图）**：节点 = 卡片在图中的引用（父子 + 坐标），
  同一卡片可出现在多张图中；删除卡片级联删节点，删除中间节点子节点上浮为根。
- **ReviewState（复习状态）**：闪卡调度数据（SM-2：ease / interval / repetitions /
  lapses / dueAt），卡片需显式"转为闪卡"才进入复习队列。

### 原文双向回链

卡片记录 `page + rects`（归一化矩形），脑图节点与复习界面都能跳回 PDF 原位置，
复习时可回看上下文。

### 面向学习流程

不只做标注，还内建记忆算法（当前 SM-2，可替换为 FSRS），
把阅读笔记变成可复习的记忆资产，覆盖预习—上课—复习—演练—长期记忆全流程。

## 存储与备份

- 笔记数据（卡片、链接、复习状态、文档元数据）存储在 **SQLite 数据库**
  （sql.js / WASM 实现，无原生依赖，跨桌面与移动端）。
- 库文件位于 Obsidian 库根目录 `.marinmind/marinmind.db`，写入防抖落盘。
- **备份 `.marginpkg`（已实现）**：命令「导出备份」把 SQLite 库 + 全部文档 PDF + 媒体附件
  打成单个 zip 包，写入库内 `Backups/MarinMind/`（文件名含时间戳）；
  「导入备份」经系统文件选择器选包 → 确认后整库替换（当前数据自动快照到
  `.marinmind/pre-import-snapshot-*.db`，库内已存在的 PDF 跳过不覆盖）→ 自动重载生效。
  包损坏 / 来自更新版本插件 / 含非法路径时拒绝导入，原数据无损。
