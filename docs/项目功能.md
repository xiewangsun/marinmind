# 项目功能

> MarinMind —— Obsidian 学习插件：电子书阅读器 + 思维导图 + 学习卡"一站式学习工具"。
> 口号：革新性整合阅读标注工具、思维导图和学习卡。
>
> 本文档按模块记录功能的设计目标与当前实现状态，随开发进度更新。

## 阅读视图（v1，已实现）

- **入口**：功能区 📖 图标或命令面板「打开 MarinMind 阅读器（选择 PDF）」→
  模糊搜索库内 PDF（支持按目录名搜索）→ 新标签页打开。
  刻意不接管 PDF 默认打开方式（文件管理器双击仍用 Obsidian 内置视图）。
- **渲染**：复用 Obsidian 内置 PDF.js（`loadPdfJs`），连续滚动 + 视口懒渲染
  （远离视口的页自动释放显存），高分辨率屏按 devicePixelRatio 渲染保证清晰。
- **缩放**：工具栏 ± 按钮与"适应宽度"；调整窗格宽度自动重排。
- **区域摘录**：工具栏 ✏（square-pen）开启摘录模式 → 在页面上拖拽框选 →
  自动生成知识卡片（记录页码 + 归一化矩形，缩放/设备无关）→ 黄色高亮即时回显。
  拖拽中右键取消；过小的框选视为误触忽略。
- **文字摘录**：直接在页面上划选文字（无需开任何模式，透明文本层承载原生划选）→
  松开鼠标即生成卡片，摘录文本与逐行高亮矩形（选区实测，多行 = 多矩形）一并入库 →
  蓝色高亮回显，与区域摘录的黄色区分。跨页选区会提示分次选择。
  扫描版 PDF 无文字层，划选不可用（待 OCR 支持）。
- **持久化**：摘录写入 SQLite（`.marinmind/marinmind.db`），关闭重开、重启 Obsidian
  后高亮原位恢复；PDF 文件重命名后卡片归属自动跟随。
- **卡片管理**：点击任意高亮 → 菜单可"转为闪卡 / 取消闪卡"（进入/移出复习队列）、
  "编辑批注"（弹窗 textarea）、"加入思维导图…"（选图/新建图后卡片落为根节点）、"删除卡片"。

## 复习界面（v1，已实现）

- **转闪卡**：在阅读器点击任意高亮 → "转为闪卡"。卡片默认只是摘录，需显式转为闪卡
  才进入复习队列（与 MarginNote 语义一致）。
- **开始复习**：命令面板「开始复习（到期闪卡）」→ 独立标签页。会话取当前到期卡片
  （每组最多 20 张，做完可"再查一批"续刷）。
- **卡片流程**：正面显示摘录（文字摘录显示原文，区域摘录显示"区域摘录 · 第 N 页"占位）→
  空格/回车翻面 → 背面显示批注（无则"暂无批注"）与出处（书名 · 页码）→ 四档评分：
  **重来(1) / 困难(2) / 良好(3) / 简单(4)**，SM-2 自动排下次到期时间。
- **重来语义**：评"重来"的卡在本组队尾重现（Anki 风格，同会话再考），
  数据库里 10 分钟后重新到期——中断会话也不丢。
- **跳转原文**：翻面后点"跳转原文"→ 打开阅读器并滚动到卡片所在页（含出处上下文回看）。
- **完成统计**：队列耗尽显示四档评分统计与总次数。

## 思维导图（v1，已实现）

- **多张命名脑图**：命令「打开思维导图」弹出选图器（首项可就地新建/重命名），
  跨书混排——任何卡片都能加入任何图，天然支持"多本书放一张脑图"。
- **卡片即节点**：一卡一节点（同一图内不重复）；节点显示 批注 > 摘录文字 > 形态占位，
  左侧颜色条沿用摘录色（黄=区域/蓝=文字），带「第 N 页 / 手工」出处徽标。
- **加卡片三条路**：阅读器高亮菜单「加入思维导图…」；画布工具栏「添加卡片」
  （模糊搜索最近 200 张，已在图的不出现，次行显示《书名》·页码）；
  双击空白/工具栏「新建文字卡片」（无文档归属的手工卡）。
- **拖拽组树**：拖节点到另一节点上 = 挂为其子节点（连线重画）；拖到空白 = 移动位置；
  拖到自己后代会被拒绝（环检测）。删除中间节点时子节点上浮为根，子树不丢。
- **画布手势**：普通滚轮 / 拖空白 = 平移；Ctrl+滚轮 = 以指针为中心缩放（0.25x–2.5x）；
  拖动中右键取消还原。
- **节点右键菜单**：跳转原文（打开阅读器滚到该页）/ 编辑批注（就地更新节点文本）/
  转为·取消闪卡 / 移出脑图（卡片保留）/ 删除卡片（级联删节点）。
- **持久化**：图与节点结构存 SQLite；重启 Obsidian 后标签页恢复上次打开的图。
  跨视图改卡后用工具栏「刷新」手动同步（v1 无实时联动）。

## 核心设计

### 以"卡片"为中心的数据模型

摘录即卡片，卡片既是脑图节点又是闪卡——**一份数据三种用途**（脑图、复习、回链原文），这是区别于普通阅读器的核心设计。

当前落地的数据模型（`src/types.ts`）：

- **BookDocument（文档）**：被阅读的书籍（PDF/EPUB），以库内路径为唯一业务键。
- **Card（知识卡片）**：由摘录生成，携带原文回链（PDF 页码 + 归一化矩形列表，
  与缩放/设备无关），支持五种摘录形态：文字 / 区域 / 手写 / 语音 / 照片。
- **CardLink（双向链接）**：卡片间手动建立的关联，两个方向等价。
- **Mindmap / MindmapNode（脑图）**：节点 = 卡片在图中的引用（父子 + 坐标），
  同一卡片可出现在多张图中；删除卡片级联删节点，删除中间节点子节点上浮为根。
- **ReviewState（复习状态）**：闪卡调度数据（SM-2：ease / interval / repetitions /
  lapses / dueAt），卡片需显式"转为闪卡"才进入复习队列。

### 原文双向回链

卡片记录 `page + rects`（归一化矩形），脑图节点与复习界面都能跳回 PDF 原位置，
复习时可回看上下文。

### 面向学习流程

不只做标注，还内建记忆算法（当前 SM-2，可替换为 FSRS），
把阅读笔记变成可复习的记忆资产，覆盖预习—上课—复习—演练—长期记忆全流程。

## 存储与备份

- 笔记数据（卡片、链接、复习状态、文档元数据）存储在 **SQLite 数据库**
  （sql.js / WASM 实现，无原生依赖，跨桌面与移动端）。
- 库文件位于 Obsidian 库根目录 `.marinmind/marinmind.db`，写入防抖落盘。
- 备份格式 `.marginpkg` 风格（SQLite 笔记数据库 + 全部文档打包）——规划中。
