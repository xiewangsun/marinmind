# 项目功能

> MarinMind —— Obsidian 学习插件：电子书阅读器 + 思维导图 + 学习卡"一站式学习工具"。
> 口号：革新性整合阅读标注工具、思维导图和学习卡。
>
> 本文档按模块记录功能的设计目标与当前实现状态，随开发进度更新。

## 主页（㉟ 起，㊲ 增强，㊵ 书架视图，㶈 卡片预览，㊸ 优化，已实现）

插件**功能区图标点击即进入主页**（原 PDF 选择器入口改为主页侧栏按钮 + 命令面板）。
Linear 风格深色侧栏导航（概览/文档/卡片/脑图）为默认；设置「外观 → 主页主题」
三态可切（㊸）——Linear 深色（默认）/ **Linear 浅色** / 跟随 Obsidian 主题
（即时生效，浅色走专用变量组、跟随走全局变量）。

- **概览**：文档/卡片/待复习/脑图统计砖（可点跳对应页）+ 快捷操作（打开 PDF /
  开始复习 / 新建脑图）+ 最近卡片（点击弹**摘录预览**，㶈）/ 最近文档 / 最近脑图。
- **文档分类（多层虚拟文件夹，㊲）**：分类只是书文件 frontmatter 里的一个标签
  字段（支持 `/` 多层路径如 `学习/英语`），**不移动文件、不建实体目录**——备份/
  手编/同步全部自动兼容，数据层零迁移。文档页左列按层级缩进的文件夹树（徽标
  显示含子孙的文档数），**点文件夹 = 显示子树全部文档**；左列可经搜索框旁 ▣ 钮
  **整栏收起**（㊸，选择自动记住，收起后列表/书架占满全宽）；归档三入口——**拖拽**
  文档行到文件夹（高亮提示）/ 右键「归入分类」（全路径扁平项）/「新建分类并
  归入…」；右键分类文件夹重命名（**子路径级联跟随**）或删除（子树文档移入
  未分类，文档与卡片不受影响）。路径上限 120 字符。
- **文档搜索（㊲）**：文档页列表上方搜索框，标题/路径小写包含过滤，与分类选择
  叠加；输入即时刷新且不打断中文输入法组字。
- **窗格视图（㊵ PDF 封面书架）**：文档页搜索框旁**列表 / 窗格**双图标切换——
  窗格以 PDF 首页封面缩略图书架展示（**每行 6 个**瓷片（㊸，窄窗口自动降列数）+
  3/4 统一开本 + 书名 + 卡数 + 状态/分类
  徽标叠放封面右上）；偏好持久化（`homeDocsView` 设置，重启保持）；封面经
  pdf-cache 共享解析按需渲染（LRU 24 缓存、并发限 3，与阅读器复用同一次解析），
  失联/移动端库外显示占位图标；瓷片交互（点击打开/右键菜单/拖拽归档）与列表
  行为完全一致。
- **卡片页（㊲ 完整浏览器；㶈 摘录预览）**：全部卡片按更新时间倒序——文档/形态双下拉筛选 +
  结果计数 + 每页 50 条分页（越界自动钳制，切换筛选回第 1 页），点击卡片**先弹摘录预览**
  （只框定摘录区域：媒体卡显示内容快照、文字/留白卡显示原文页裁剪窗口 + 高亮标示，
  需要时再「跳原文」精确定位——概览最近卡片同入口，复习/脑图跳原文保持直跳）。
- **脑图页**：全部脑图列表（节点数 + 更新时间 + 📖 书籍图徽标），一键打开或新建。
- **实时刷新**：阅读器中建卡/编辑/删除，打开的主页约 0.1s 内自动更新（计数与列表）。

## 阅读视图（v1，已实现）

- **入口**：主页侧栏底部「打开文档」按钮或命令面板「打开 MarinMind 阅读器
  （选择文档）」→ 模糊搜索库内 PDF / Markdown（支持按目录名搜索；**数据目录
  MarinMind 内的卡片文件从列表排除**）→ 新标签页打开。
  刻意不接管 PDF 默认打开方式（文件管理器双击仍用 Obsidian 内置视图）。
- **Markdown 文档阅读（㊻-B 核心版）**：库内 md 笔记可当"书"打开——Obsidian
  原生预览排版（固定栏宽居中，内链可点跳转），目录侧栏变 **h1-h6 标题导航**
  （点击滚动定位）；划选文字/留白/矩形/套索（矩形/套索 ㊽ 起有内容快照——DOM 截图，
  插图照进快照）/照片/语音（锚页 1）摘录照常，跳原文/复习/脑图自动入图/翻译/闪卡遮挡
  全链路一致；手写/AI 摘录/
  OCR/缩放/书签不适用（按钮隐藏或空态提示）；md 源被编辑后高亮为近似锚定。
- **库外 PDF（㉞ 桌面）**：选择弹窗底部「📂 打开库外 PDF…」或命令
  「打开库外 PDF（桌面）」→ 系统文件对话框选库外绝对路径文件**直接阅读不复制入库**，
  摘录/复习/脑图与库内文档完全同构（文档管理面板标「库外」徽标；移动端不可用）。
  **重开入口（㉞-A）**：打开过的库外文件置顶出现在 PDF 选择器列表（「库外」徽标，
  最近 8 本、可模糊搜索），一键重开。**同目录改名自动跟随 + 一键复制入库（㊳）**：
  桌面端监视库外文档所在目录，文件在原目录内改名记录自动跟上（无法确定归属时
  宁拒不赌，提示手动重关联）；「复制入库」（文档管理面板/主页右键）把库外 PDF
  拷进库根并改道记录——之后备份打包、跨机器不失联。备份默认不打包库外 PDF
  仅保留记录。
- **渲染**：复用 Obsidian 内置 PDF.js（`loadPdfJs`），连续滚动 + 视口懒渲染
  （远离视口的页自动释放显存），高分辨率屏按 devicePixelRatio 渲染保证清晰；
  **共享解析缓存（㊳）**——多标签/AI 摘录弹窗/复习缩略图共用同一次文档解析，
  同一本书双开秒出；**混合页尺寸统一列宽（㊳）**——所有页显示宽一致（高按
  各自宽高比换算），宽窄页混排不再裁切；**页骨架分块构建（㊳）**——首屏 40 页
  同步、其余后台批量补齐，千页文档首开不卡；后台逐批取真实页尺寸（锚定当前页，
  阅读中不跳动）。
- **缩放**：工具栏 ± 按钮与"适应宽度"；调整窗格宽度自动重排；**缩放档位与页内
  位置记忆（㊳）**——固定缩放档 + 当前滚动偏移随工作区保存，重启/切回标签原样
  恢复不弹回页顶。
- **工具行（手型 + 选择 + 四类摘录工具，MarginNote 式）**：视图顶部独立一行
  `[目录] | [手型] | [选择][文字][矩形][套索][留白] | [AI 摘录][复习] …`（图标+文字标签，
  当前工具高亮）——
  **选定后保持激活可连续摘录**，Esc 随时退回文字摘录；标签页头部只留
  手写/插图/录音/缩放按钮。
- **目录/书签侧栏（㉓ + ㉙ 分页展示，㉝ 目录样式回归 Obsidian 默认）**：
  「目录」按钮开关的左侧抽屉（覆盖显示，不打扰阅读布局），顶部「目录 | 书签」
  胶囊分页切换（㉙，与三视图切换条同一设计语言）——**目录** = PDF 内嵌大纲树
  （**㉝ 与 Obsidian 默认 PDF 阅读器的目录样式一致**：层级缩进 + ▸/▾ 折叠箭头 +
  标题，无附加格式；点击跳页、悬停只提亮文字、手动折叠状态重渲染不丢）；
  **书签** = 自定义阅读位置标记（「＋ 当前页」一键添加、
  可命名、行内页码、悬停显示删除、入库持久化），PDF 无自带大纲
  也能自建导航；**增删书签跨标签即时同步（㊳）**；跳页与跳原文共用同一套精确定位路径。
- **手型工具**：只读浏览——按住拖拽平移页面（grab/grabbing 光标），
  阻断文字选中与摘录误触。
- **选择工具（㉖）**：纯文本选择——划选文字 Ctrl+C 复制，**不生成卡片**
  （对标 Acrobat「文本选择工具」，紧随手型之后）；想划选成卡用「文字」工具。
- **文字摘录**（默认）：像普通网页一样在页面上划选文字（透明文本层承载原生划选）→
  松开鼠标即生成卡片，摘录文本与逐行高亮矩形一并入库；
  **㊹ 线稿式回显——逐行只画彩色下划线、不填充背景**（逐行矩形天然逐行下划线）；
  **逐行自动修剪**——选区逐字符测量、按行聚类后收缩到每行首/末个实际文字，
  行尾空白与整行空行不再圈进高亮，文本按行拼接。
  跨页选区会提示分次选择；扫描版 PDF 无文字层不可用（待 OCR 支持）。
- **矩形摘录**：拖拽框选规则区域 → 自动生成卡片（记录页码 + 归一化矩形，
  缩放/设备无关）；**㊹ 回显只有彩色边框、不填充**；
  **区域内容同步截为图片快照**（㉛ 起优先 WebP，体积约为 PNG 的
  1/3~1/5；iOS 自动回退 PNG）——脑图节点与复习正面直接显示
  所框图像。拖拽中右键取消；过小的框选视为误触忽略。
- **套索摘录**：自由绘制闭合路径圈选不规则区域 → 松手自动生成卡片；
  **㊹ 回显只描彩色轮廓线（原始多边形描边）、不填充**；
  **可连续圈选**；**高亮保持你画的原始轮廓**（多边形原样入库，不再是矩形近似），
  **内容快照按原始轮廓裁形**（轮廓外透明，脑图/复习原样显示）；兼容跳转原文
  精确定位；右键取消当前套索；极小抖动自动丢弃；**旧区域/套索卡在页面再次
  渲染时自动补拍快照**。
- **留白摘录**：在页面空白处点击放置锚点 → 弹出"留白备注"输入框输入文字 →
  生成留白卡片（**页面上直接显示备注胶囊**——㊹ 改为不透明主题底 + 彩色边框，
  锚点矩形入库供精确定位）；工具保持激活可连续添加；
  点击已有高亮块不触发。
- **四色体系与循环切色（㊹，MarginNote 3 式）**：摘录颜色收敛为
  **浅黄 / 浅绿 / 浅蓝 / 浅红** 四色；**点击已激活的四类摘录工具按钮 =
  循环切换该工具色系**（黄→绿→蓝→红，按钮色点即时变化 + 提示条反馈），
  后续摘录按已选色，**四种工具各自独立记忆**（重启保持）；拖框/套索预览同色。
  存量旧色卡（青/橙/粉/紫）继续按原色相渲染，仅形态随线稿化。
- **持久化**：摘录写入笔记文件（`MarinMind/<书名>.md`），关闭重开、重启 Obsidian
  后高亮原位恢复；PDF 文件重命名后卡片归属自动跟随。
- **卡片管理**：点击任意高亮 → 菜单可"转为闪卡 / 取消闪卡"（进入/移出复习队列）、
  "编辑批注"（弹窗 textarea）、"颜色…"（**㊹ 四色色板改色**，本页/
  跨标签/脑图节点标题栏/拖卡预览四处即时同步）、
  "复制卡片链接 / 复制嵌入代码"（㊻-A，贴进普通笔记或 Canvas 白板，见
  「与 Obsidian 整合」）、
  "翻译"（有文字的卡，见「翻译」章节）、
  "加入思维导图…"（选图/新建图后卡片落为根节点）、"删除卡片"。
- **多标签实时同步**：同一 PDF 开多个阅读标签时，任一标签的新摘录/编辑/删除即时同步
  到其他标签（高亮与页角徽标），无需重开。

## 媒体摘录（v1，已实现）

照片 / 手写 / 语音三种摘录形态，附件存数据目录 `MarinMind/assets/`（uid 命名，一卡一附件，
随 `.marginpkg` 备份一并导出）。**需先在阅读器打开文档**（v1 不做无文档归属的自由媒体卡）。

- **照片摘录**：三个入口任选——工具栏 🖼（image-plus）按钮选图 / 直接 **Ctrl+V 粘贴**
  截图 / 把图片文件**拖入**阅读视图。图片原样保存（保留 EXIF 方向信息），
  卡片锚定当前阅读位置所在页；页面上无框选痕迹，以页角徽标为入口。
- **手写摘录**：工具栏 ✎（pencil-line）开启手写模式（与摘录工具互斥）→
  在页面上直接书写（红笔，支持触摸）→ 笔迹按归一化坐标记录，缩放/重排后依然清晰。
  **提交时机**：滚动离开该页 / 退出手写模式 / 切换文档 / 关闭视图时，单页聚合为一张卡
  （精确包围盒 + 透明底 PNG），绿色虚线框内嵌图片回显——点击弹管理菜单、可拖入脑图，
  与其他高亮完全同构。
- **语音摘录**：工具栏 🎤（mic）开始/结束录音，录音中顶部悬浮状态条
  （红点计时 + 保存/丢弃）。误关标签页不丢内容（自动保存）；音频格式按环境自动回退
  （webm/opus → mp4 → ogg）。
- **页角徽标**：有照片/语音卡的页面右上角显示「N 个媒体摘录」，点击列出该页媒体卡 →
  打开预览弹窗（图片/音频播放 + 批注），弹窗内可转闪卡 / 编辑批注 / 删除卡片（附件随之删除）。
- **复习界面**：媒体卡正面直接显示图片或播放器（手写/照片显示笔迹图片，语音可播放），
  翻面批注/评分流程与其他卡一致。

## 区域 OCR（v1，已实现）

- **用途**：扫描版 PDF 无文字层（划选不可用）——先框选区域摘录，再 OCR 得到文本；
  手写摘录也可识别（把笔迹区域当图片识别，实际效果取决于字迹工整度）。
- **入口**：点击区域或手写摘录的高亮（彩色边框/绿色虚线框）→ 菜单「识别文字 (OCR)」。
- **流程**：插件把该页以约 2200px 宽高清渲染到离屏画布 → 对卡片矩形逐块识别
  （中英文混排）→ 清洗拼接后写入卡片的摘录文字——复习正面、脑图节点随即显示该文本。
  卡片已有文字时弹确认框（OCR 结果替换）。
- **引擎**：tesseract.js 懒加载——**首次使用需联网下载引擎与中文语言包（约 10-20MB）**，
  下载后缓存本地，二次使用离线可用；下载/识别进度在提示条中显示。
- **限制**：移动端不可用（tesseract 移动端 Obsidian 环境不支持）；识别精度受扫描质量影响；
  仅桌面端、需接受联网下载。

## AI 一键摘录（㉓ + ㉕ 增强，已实现）

参照 MarginNote「一键摘录」：**基于文档文字层自动识别 标题 / 正文 内容块**，
预览勾选后**批量生成卡片**——不用逐段划选，整页/整章一次性变成卡片集。

- **识别原理（规则版面分析，非外部 LLM）**：对 pdf.js 文字层的逐项几何数据做
  行聚类（y 容差 + 同带 x 切分应对双栏）→ 段落合并（段距/字号跳变/水平同栏
  判定 + **段首缩进切分**）→ 标题判定（**字号 + 文本模式 + 居中短行**三路信号）
  → 页眉页脚带内整行排除。纯函数实现，vitest 覆盖。
- **标题识别（㉕ 增强后）**：字号明显大于正文之外，补三路信号——文本模式
  （第X章 / 1.2 / 一、/ Chapter 1 / INTRODUCTION 全大写等，配"短行且非句末
  标点"门槛防列表误伤）、居中短行（图注/表注排除）、模式行独立成块——
  **仅加粗但与正文同字号的小标题大多也能认出**。
- **段落质量（㉕）**：中文书籍段首缩进正确切分（相邻段不黏连成一坨）；
  英文行尾断词自动拼接（不出现 "pow-ered" 破碎词）。
- **重复去重（㉕）**：重复执行时与已有卡片重复的块（同页且文本一致或位置
  高度重叠）灰显 +「已有」徽标 + 默认不勾选——不会重复建卡。
- **入口**：阅读器工具行「AI 摘录」按钮 → 选范围（当前页 / 页码区间，单次 ≤ 50 页）
  与元素类型（标题 / 正文）→ 预览列表逐项勾选 → 一键生成。
- **同类型同色（MN4 同款，㊹ 收编四色）**：标题块生成浅红高亮卡，正文块跟随
  「文字」工具当前色系——脑图里一眼区分两类内容。
- **与既有体系完全同构**：生成的卡片就是普通文字摘录卡（摘录文本 + 逐行矩形），
  跳原文精确定位、拖卡入图、转闪卡、自动入图全部直接可用。
- **限制**：扫描版 PDF 无文字层不可用（提示改走矩形摘录 + OCR）；个别列表
  编号行可能被误判为标题（预览中取消勾选即可）。

## 翻译（㉔，已实现）

参照 MarginNote「翻译及保存译文」：摘录文字即时翻译，译文**存为留白**
（与原文并排对照）或**复制到剪贴板**。

- **入口**：阅读器点击有文字的高亮（文字摘录 / OCR 过的区域、手写卡）→
  菜单「翻译」→ 弹窗显示原文/译文对照与**源语言检测结果**。
- **目标语言（MN4 同款 13 种）**：简体/繁体中文、英语、日语、韩语、法语、
  德语、西班牙语、意大利语、葡萄牙语、俄语、粤语、文言文——弹窗下拉切换
  **立即重译并记住选择**（设置页可改默认值）。
- **存为留白**：译文以留白胶囊放在**原文正下方**（㊹ 色随「留白」工具当前色系）
  并排对照；它是一张
  普通卡片（可编辑批注/转闪卡/拖入脑图/自动收录），无任何新数据概念。
- **复制**：译文一键进系统剪贴板。
- **引擎**：Google 免费翻译接口（免密钥，`sl=auto` 自动检测源语言），
  经 Obsidian requestUrl（绕 CORS，桌面/移动端均可用）；**需网络可达
  translate.googleapis.com（国内通常需代理）**。单次上限 5000 字符。
- **限制**：无文字的卡（照片/语音、未 OCR 的区域/手写）不出现翻译入口；
  译文留白不折叠（MN4 留白可折叠，MarinMind 留白胶囊为固定展示）。

## 复习界面（v3，已实现）

- **转闪卡**：在阅读器点击任意高亮 → "转为闪卡"。卡片默认只是摘录，需显式转为闪卡
  才进入复习队列（与 MarginNote 语义一致）。
- **按书自动转闪卡（㊷）**：阅读器工具行「闪卡」按钮（闪电图标）按书开关——开启后本书
  新摘录（含 AI 批量/翻译留白）自动进入复习队列，**每本书独立记忆**（书文件
  frontmatter `auto_flashcard`）；批量摘录聚合一条 Notice 汇总。
- **三种进入入口**：命令面板「开始复习（到期闪卡）」；阅读器工具行「复习」按钮；
  脑图顶部「复习」按钮（均打开/复用复习标签页并重启会话）。
- **按书范围（㊷）**：阅读器「复习」按钮与学习模式工作区**默认只考当前书籍**
  （顶部《书名》徽标，点 × 切「全部书籍」；空屏/完成屏另有切换按钮）；命令面板与
  脑图入口默认全部书籍；主页待复习计数仍为全库。
- **卡片流程（MN4 正反面语义：正面=问题，背面=全部内容）**：有批注的卡正面显示
  批注（问题）、翻面显示摘录内容（答案）；无批注的卡正面即摘录（文字显示原文；
  区域/套索/手写/照片显示内容快照图片，语音显示播放器；无快照旧卡显示占位）→
  空格/回车翻面 → 四档评分：**重来(1) / 困难(2) / 良好(3) / 简单(4)**，
  SM-2 自动排下次到期时间。
- **闪卡遮挡（㊷，Anki Image Occlusion 同思路）**：高亮菜单「遮挡区域…」在页上
  拖框划重点（可连续多个，**起点可落在摘录区域内部**㊿-C；阅读器里只显示虚线标记
  不影响阅读，「遮挡预览」看复习观感）；复习**正面**自动出图（内容快照/原文裁剪，
  与主页卡片预览同一管线）并用实心色块遮住——**色块颜色跟随摘录高亮色系**（㊿-C），
  点击单块临时揭开、「显示全部遮挡」全揭/重遮（不翻面），翻面与已考回看 =
  **同一张视觉，遮挡块透明化、保留同色系虚线边框**（㊿-B/C，各形态与正面同构）；
  遮挡存卡片机器层（occ 键），仅支持有页面矩形的形态（照片/语音卡无入口）。
- **卡片浏览切换（㉑）**：顶部导航条 ◀ 第 i/N 张 ▶ 与 ←/→ 方向键在卡片间切换——
  已考卡只读回看（正反面 + 档位徽标）、后面的卡只看正面；评分只作用于待考卡，
  浏览不破坏 SRS 推进；完成统计屏仍可 ◀ 回看本组。
- **溯源上下文（㉒，MN4"闪卡复习②"对齐）**：翻面后背面底部出现「溯源上下文」
  切换条，**默认收起**（手册：先回忆，记不起来再看——一开始就看会降低主动回忆），
  换卡/评分自动收起。**📄 文档栏**：摘录所在页缩略图 + 高亮摘录区域（㊹ 线稿同源：
  矩形描边/文字下划线/套索原始轮廓），PDF 文档 LRU 缓存（≤2 份），失联文档与无页面矩形的媒体卡静默
  跳过（提示改看脑图栏）；**🧠 脑图栏**：卡片在各图中的位置摘要（祖先 › 本卡 ›
  子节点/同级数量），未入图给提示。
- **跳转原文**：导航条「↗ 原文」**正面即可点击** → 打开阅读器并**精确定位到摘录矩形**
  （滚动到矩形上方约 1/4 视口处并闪烁高亮两次）；照片/语音卡无矩形则闪烁页角徽标；
  文件不在库中时提示。
- **重来语义**：评"重来"的卡在本组队尾重现（Anki 风格，同会话再考），
  复习记录里 10 分钟后重新到期——中断会话也不丢。
- **完成统计**：队列耗尽显示四档评分统计与总次数，可"再查一批"续刷。

## 思维导图（v1 + 折叠/自动布局，已实现）

- **多张命名脑图**：命令「打开思维导图」弹出选图器（首项可就地新建/重命名），
  跨书混排——任何卡片都能加入任何图，天然支持"多本书放一张脑图"。
- **卡片即节点**：一卡一节点（同一图内不重复）；**节点三栏化（㊺ MN3 式）**——
  上栏**标题栏**（摘录色系 tint 彩底 + 卡片标题，默认「…」）、中栏**摘录内容**
  （文字摘录显示文本；**区域/套索/手写/照片直接显示内容快照图片**，OCR 文字作图注⑳）、
  下栏**批注栏**（有批注才显示）；带「第 N 页 / 手工」出处徽标。
- **编辑标题/批注 + 单击跳原文（㊺；㊺-A 交互回调）**：**右键节点 →「编辑标题/批注」**
  弹出浮动编辑面板（含手工卡；标题框 + 批注框 + 取消/↗原文/保存），保存后三栏即时刷新、
  连线重锚，标题同步主页卡片列表/预览/复习脑图栏；Esc 取消、Ctrl/Cmd+Enter 保存、
  画布平移缩放时面板跟随；**左键单击节点 = 直接跳原文**（联动定位恢复旧行为）。
- **加卡片三条路**：阅读器高亮菜单「加入思维导图…」；画布工具栏「添加卡片」
  （模糊搜索最近 200 张，已在图的不出现，次行显示《书名》·页码）；
  双击空白/工具栏「新建文字卡片」（无文档归属的手工卡）。
- **拖拽组树（㉜ XMind 化）**：拖节点到另一节点上分三区——命中节点上 1/3 插为同级前方 /
  下 1/3 插为同级后方 / 中间 1/3 挂为子节点；松手后受影响分支自动整理（**仅新旧父
  两棵子树回流归位**，无关分支的连线与位置一律不动），连线锚点同步自适应
  （tree/tree-left 现在按子相对方位选边，不再打结）；拖到空白 = 自由定位
  （整棵子树随指针移动，落库位置但不整理）。
  拖动中实时提示（目标高亮 / before/after 画插入线）；命中自己或自己后代不提示（防成环）。
  拖动整棵子树跟随（含折叠隐藏），指针距视口边缘 <36px 自动滚屏；取消 = 右键或
  **Esc（㊳，document 级键位路由进拖拽状态机）**还原快照。
  拖到自己后代会被拒绝（环检测）；删除中间节点时子节点上浮为根，子树不丢。
  `dropCard`（reader 拖卡入图）与 auto-collect 独立。
- **画布手势**：普通滚轮 / 拖空白 = 平移；Ctrl+滚轮 = 以指针为中心缩放（0.25x–2.5x）；
  拖动中右键取消还原。
- **折叠子树**：有子节点的节点右缘悬停出现 ▾ 按钮，点击折叠整个子树——节点缩为
  带后代计数的 "▸ N" 胶囊（N = 隐藏的后代数，含多层）；折叠态写入笔记文件，
  重启 Obsidian 后保留。折叠期间拖卡到该节点照常挂为其子节点（展开后自动落位）。
- **自动布局**：工具栏「自动布局」（layout-template）→ 确认后一键按各节点的分支样式
  整理为标准排布（同层对齐一列/一行、父居中于子块、多根自上而下堆叠；**间距按节点
  实际高度计算**，含图片的高节点不与相邻节点重叠；折叠隐藏的子树
  也一并排好，展开后位置合理），完成后自动缩放居中到全图可见。会覆盖手动摆放的位置。
- **分支样式（六种，MarginNote 4 同款语义）**：树形（右）/ 树形（左）/ 树形（下，
  组织架构图）/ 直线（横向链条）/ 双向（根居中左右对称）/ 框架（子节点收进圆角
  收纳框，不画连线）。图级默认在脑图顶部下拉框设置；单个节点右键「分支样式…」可
  覆盖（只影响该节点的子树）。样式决定连线形状与自动布局方向，切换即时生效不动
  节点位置；新挂的子节点按父节点样式自动落位。
- **摘录自动入图（边摘录边生成脑图，㊴：打开即建同名图 + 按书切换目标图 + 固定根节点）**：
  脑图顶部「添加到脑图」开关（**全局持久化、默认开启**）——开启后任何阅读器的
  新摘录（七种形态均可）自动入图，**无需打开脑图视图**；**每张卡入图后弹出
  提示告知落点图名**（㉘），选图器中书图带 📖 徽标。落点三级：**固定根节点
  优先**（右键任意节点「设为固定根节点」后，所有新摘录直挂该节点下——跨文档
  收拢，📌 徽标标示，删节点自动解钉）＞ **本书目标图**（㊴ 按书记住——阅读器
  工具行「脑图」按钮可把这本书的摘录切到任意图，图内自动建《书名》分组归拢，
  多书共图各自分组，随时切回默认）＞ **同名默认脑图**——**打开书即自动创建**
  （不等首张摘录），一本书一张以书名命名的图，《书名》分组卡作根节点，摘录
  依次挂下自动连线（连线随分支样式）；多本书各自成图。**PDF 改名后图名与
  《书名》根节点跟随新书名**（手动改过的不覆盖）；目标图被删自动回默认不悬空。
  分组卡是普通卡片，可拖动/编辑/移出。已有卡片与
  手工卡不受影响，仍走手动加入。
- **节点右键菜单**：跳转原文（打开阅读器**精确定位到矩形并闪烁高亮**，同复习界面）/
  编辑批注（就地更新节点文本）/ 转为·取消闪卡 / **设为·取消固定根节点（㉗）** /
  移出脑图（卡片保留）/ 删除卡片（级联删节点）。
- **实时同步（跨视图）**：在阅读器里编辑批注、OCR 写入文字、删除卡片——打开着的脑图
  视图**即时同步**（节点文本更新/节点消失），无需手动刷新；同一 PDF 开多个阅读标签时
  新摘录也互相同步。
- **持久化**：图与节点结构（含折叠态）存 `MarinMind/脑图/<图名>.md`；重启 Obsidian 后
  标签页恢复上次打开的图。
  节点加入/移出等结构变化后用工具栏「刷新」手动同步。

## 多窗格工作区与拖拽入图（v1，已实现）

- **学习模式工作区**：命令一键布局——左侧阅读器 + 右侧复习窗格（自动开始到期会话）。
- **研究模式工作区**：左侧阅读器 + 右侧脑图（**自动定位当前书的摘录目标图**，
  ㊴——同名图/按书覆盖/固定根所在图，无需手动选图；输入框焦点不被抢占）。
- **幂等**：已有阅读器/目标窗格则复用（不重复分裂，焦点回到阅读器）；没有阅读器时
  弹 PDF 选择器新标签页打开，取消选择即放弃布局（不动当前笔记）。
- **拖卡入图**：在阅读器**按住任意高亮拖动**（非摘录模式）→ 半透明卡片跟随指针 →
  拖到脑图画布上出现落点提示 → 松手：
  - 落在**空白**=新增根节点（指针所指位置，缩放/平移后依然准确）；
  - 落在**节点上**=挂为其子节点（自动落到标准子节点位置，与既有兄弟顺延）。
  已在图中的卡片会提示，不重复添加。单击高亮（未拖动）仍弹管理菜单。
- **三视图切换（单文档 / 单脑图 / 联动，MarginNote 学习集同款）**：阅读器工具行与
  脑图顶部共用 **[文档|脑图|联动]** 切换条（亦有命令面板入口）。隐藏侧的阅读页码与
  脑图会被记住，切回原样恢复；模式由实际布局推导（手动关标签=隐式切换，重启保持
  退出前布局）。**切到「脑图/联动」自动定位当前书的目标图（㊴）**——同名图/按书
  覆盖/固定根所在图优先，其次恢复上次浏览的图，都没有才弹选图器。
  **联动视图一对一跟随（㊿）**：脑图侧始终显示当前书的目标图——打开另一本书或
  切换摘录目标图立即跟随，不弹选图器（文档加载完自动补开）；**联动互关**——
  关闭文档标签脑图随之关闭，关闭脑图标签文档随之关闭（无关图并排不误伤）。
  **联动视图点击互相定位**：文档点高亮 → 脑图平移到节点并闪烁；
  脑图单击节点 → 文档滚到原文并闪烁（异书卡片直接切换阅读窗格文件）。
- **限制**：跨弹出窗口（popout）拖拽不支持；触摸端不支持拖卡（桌面特性）；
  用户手动把脑图/复习并成阅读器同组后台标签时，预设不会强制重新拆分；
  折叠隐藏的节点不参与联动定位（不自动展开）。

## 核心设计

### 以"卡片"为中心的数据模型

摘录即卡片，卡片既是脑图节点又是闪卡——**一份数据三种用途**（脑图、复习、回链原文），这是区别于普通阅读器的核心设计。

当前落地的数据模型（`src/types.ts`）：

- **BookDocument（文档）**：被阅读的书籍（PDF/EPUB/Markdown），以库内路径或库外绝对路径为唯一业务键；
  含分类字段 `category`（㉟ 主页虚拟文件夹，㊲ 起支持 `/` 多层路径，null=未分类）。
- **Card（知识卡片）**：由摘录生成，携带原文回链（PDF 页码 + 归一化矩形列表，
  与缩放/设备无关），支持七种摘录形态：文字 / 区域 / 套索 / 留白 / 手写 / 语音 / 照片。
- **DocumentBookmark（文档书签，㉓）**：用户手动添加的阅读位置标记（页码 + 自定义标签），
  目录侧栏展示与跳转。
- **CardLink（双向链接）**：卡片间手动建立的关联，两个方向等价。
- **Mindmap / MindmapNode（脑图）**：节点 = 卡片在图中的引用（父子 + 坐标），
  同一卡片可出现在多张图中；删除卡片级联删节点，删除中间节点子节点上浮为根。
- **ReviewState（复习状态）**：闪卡调度数据（SM-2：ease / interval / repetitions /
  lapses / dueAt），卡片需显式"转为闪卡"才进入复习队列。

### 原文双向回链

卡片记录 `page + rects`（归一化矩形），脑图节点与复习界面都能跳回 PDF 原位置，
复习时可回看上下文。

### 面向学习流程

不只做标注，还内建记忆算法（当前 SM-2，可替换为 FSRS），
把阅读笔记变成可复习的记忆资产，覆盖预习—上课—复习—演练—长期记忆全流程。

## 存储与备份

- 笔记数据（卡片、链接、复习状态、文档元数据）以 **Markdown 文件**存储（㉚）：
  **每书一文件**（`<书名>.md`，内含摘录卡片/批注/书签/复习进度）、
  **一图一文件**（`脑图/<图名>.md`，嵌套列表即节点树）——可直接在 Obsidian 中
  浏览、搜索、打标签，支持 git/同步盘版本管理；手动编辑批注/文本/标签后保存即自动回灌。
- 数据目录默认库内 `MarinMind/`，写入防抖分文件落盘；媒体附件存同目录 `assets/`。
  旧版本（SQLite 存储）用户首次启动自动弹窗引导迁移，或经命令「从旧版数据库导入」
  （复制式转换，旧 `.marinmind/` 原样保留）。
- **设置页（已实现）**：数据目录与备份目录可配置——桌面端支持本机绝对路径
  （可把数据迁出 Obsidian 库/同步盘），移动端仅库内路径。数据目录修改走
  「应用并迁移数据」：复制式迁移（旧位置保留作为回退，失败无损失），完成后自动重载；
  备份目录修改即时生效。
- **备份 `.marginpkg`（已实现）**：命令「导出备份」把全部笔记 md 文件 + 全部文档 PDF +
  媒体附件打成单个 zip 包，写入备份目录（默认库内 `Backups/MarinMind/`，文件名含时间戳）；
  「导入备份」经系统文件选择器选包 → 确认后整库替换（当前数据自动快照到数据目录
  `pre-import-snapshot/`，库内已存在的 PDF 跳过不覆盖）→ 自动重载生效。
  旧版 v1 备份包（SQLite 形态）导入时自动转换为 Markdown 存储。
  包损坏 / 来自更新版本插件 / 含非法路径时拒绝导入，原数据无损。
- **文档管理面板（已实现）**：列出全部文档记录与失联状态（文件已不在库中的记录
  标红）；失联文档一键**重关联**到新位置——卡片、复习进度、脑图节点全部原地保留；
  或删除无用记录（级联清理卡片/附件/复习状态，确认弹窗写明影响范围）。
  vault 内文件移动/改名由全局监听自动跟随（文件删除刻意不级联——Obsidian 删除可撤销，
  不应不可逆地蒸发笔记数据）；**库外文件同目录改名由 fs watcher 自动跟随（㊳）**，
  库外文档另有「复制入库」转正入口（面板按钮 + 主页右键）。
