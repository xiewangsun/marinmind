## 区域 OCR（v1 + 83 全面强化，已实现）

- **用途**：扫描版 PDF 无文字层（划选不可用）——先框选区域摘录，再 OCR 得到文本；
  手写摘录也可识别（83-D 起识别**笔迹本身**：读笔迹图片附件合成白底画布
  2× 放大后识别，修复旧版误识笔迹下方原页的错位；tesseract 对自由手写
  识别率有限，较工整字迹效果更好）。
- **入口**：点击区域或手写摘录的高亮（彩色边框/绿色虚线框）→ 菜单「识别文字
  (OCR)」；**拖框即识**（83）——设置开启后区域摘录框完松开即自动识别（默认关，
  仅桌面 PDF）；**整页 OCR**（83）——PDF 页面右键「识别本页文字 (OCR)」，
  行级坐标生成一张逐行下划线的文字摘录卡（不走自动翻译，防整页长文留白洪水）。
- **流程**：插件把该页以约 2200px 宽高清渲染到离屏画布 → 对卡片矩形逐块识别
  （**83 PSM 版面自动细分**：面积 ≥0.5→AUTO、宽高比 ≥6→单行、双 <100px→单词、
  其余→单块；手写固定 SPARSE_TEXT）→ 清洗拼接后写入卡片的摘录文字——复习
  正面、脑图节点随即显示该文本。卡片已有文字时弹确认框（OCR 结果替换）。
  85-D 起识别文字在编辑标题/批注面板与卡片预览弹窗以「摘录（只读）」块展示。
- **引擎与并发（83-A）**：tesseract.js 懒加载——**首次使用需联网下载引擎与
  语言包（约 10-20MB）**，下载后缓存本地二次离线可用（不做离线打包：+30MB
  包体不值）；**识别语言 12 组合可选**（设置「识别语言」，引擎层按语言键自动
  重建 worker）；**promise 链串行队列**——连续拖框即识逐框依次识别，进度条
  与版面参数互不抢乱；**85-C 就绪态提示**——引擎加载成功后登记（会话级
  `readyLangs`），同会话二次识别不再弹「首次需联网下载」，失败提示也按
  是否就绪分流（未就绪→提示检查网络）。
- **OCR→翻译流水线（83-D，MN4「AI OCR 翻译」）**：设置「识别后自动翻译」
  开启后，OCR 成功自动翻译识别文字并存为原文正下方留白；翻译失败不影响
  已识别文字（fire-and-forget 解耦）。
- **限制**：移动端不可用（tesseract 移动端 Obsidian 环境不支持）；识别精度受扫描质量影响；
  仅桌面端、需接受联网下载。

## AI 一键摘录（㉓ + ㉕ 增强，已实现）

参照 MarginNote「一键摘录」：**基于文档文字层自动识别 标题 / 正文 内容块**，
预览勾选后**批量生成卡片**——不用逐段划选，整页/整章一次性变成卡片集。

- **识别原理（规则版面分析，非外部 LLM）**：对 pdf.js 文字层的逐项几何数据做
  行聚类（y 容差 + 同带 x 切分应对双栏）→ 段落合并（段距/字号跳变/水平同栏
  判定 + **段首缩进切分**）→ 标题判定（**字号 + 文本模式 + 居中短行**三路信号）
  → 页眉页脚带内整行排除。纯函数实现，vitest 覆盖。
- **标题识别（㉕ 增强后）**：字号明显大于正文之外，补三路信号——文本模式
  （第X章 / 1.2 / 一、/ Chapter 1 / INTRODUCTION 全大写等，配"短行且非句末
  标点"门槛防列表误伤）、居中短行（图注/表注排除）、模式行独立成块——
  **仅加粗但与正文同字号的小标题大多也能认出**。
- **段落质量（㉕）**：中文书籍段首缩进正确切分（相邻段不黏连成一坨）；
  英文行尾断词自动拼接（不出现 "pow-ered" 破碎词）。
- **重复去重（㉕）**：重复执行时与已有卡片重复的块（同页且文本一致或位置
  高度重叠）灰显 +「已有」徽标 + 默认不勾选——不会重复建卡。
- **入口**：阅读器 ⋯ 溢出菜单「AI 摘录」（89-A 起收进菜单，仅 PDF）→ 选范围（当前页 / 页码区间，单次 ≤ 50 页）
  与元素类型（标题 / 正文）→ 预览列表逐项勾选 → 一键生成。
- **同类型同色（MN4 同款，㊹ 收编四色）**：标题块生成浅红高亮卡，正文块跟随
  「文字」工具当前色系——脑图里一眼区分两类内容。
- **与既有体系完全同构**：生成的卡片就是普通文字摘录卡（摘录文本 + 逐行矩形），
  跳原文精确定位、拖卡入图、转闪卡、自动入图全部直接可用。
- **限制**：扫描版 PDF 无文字层不可用（提示改走矩形摘录 + OCR）；个别列表
  编号行可能被误判为标题（预览中取消勾选即可）。

## 翻译（㉔ + 83 多引擎/侧栏/折叠，已实现）

参照 MarginNote「翻译及保存译文」：摘录文字即时翻译，译文**存为留白**
（与原文并排对照）或**复制到剪贴板**。

- **三入口（83-E/F 语义分工）**：
  - 阅读器点击有文字的高亮 → 菜单「翻译」→ **弹窗**对照 + 存留白；
  - 划选工具栏「翻译」→ **侧栏翻译页签**（「目录 · 书签 · 翻译」第三页签，
    即时对照**不建卡**；停在翻译页签时划选 500ms 防抖自动刷新——百度 QPS
    限频的第一道闸）；
  - **复习界面顶部「翻译」钮**（83-F，后续优化方向 :258 清账）——无摘录文字的
    卡置灰；有页码定位可存留白，手工卡仅对照 + 复制。
- **目标语言（MN4 同款 13 种）**：简体/繁体中文、英语、日语、韩语、法语、
  德语、西班牙语、意大利语、葡萄牙语、俄语、粤语、文言文——下拉切换
  **立即重译并记住选择**（设置页可改默认值）。
- **四引擎（83-C 注册表架构；85-B 增有道）**：
  - **Google**（默认）：免密钥免费接口，`sl=auto` 自动检测源语言（需网络可达
    translate.googleapis.com，国内通常需代理）；
  - **百度翻译**：国内直连——设置页填 APP ID + 密钥（fanyi.baidu.com「通用
    翻译API」标准版免费，限 1 次/秒）；签名 MD5(appid+原文+salt+密钥) 为
    零依赖自实现；
  - **有道翻译**（85-B）：国内直连——设置页填应用 ID + 应用密钥
    （ai.youdao.com 创建应用并绑定「文本翻译服务」）；经典 MD5 签名
    MD5(appKey+原文全文+salt+密钥)（与百度同构；input 截断/curtime/sha256
    仅属 v3 不使用）；errorCode 中文错误表（108/110/202/411 等）；**不支持
    粤语/文言文**目标语言（mapTarget null → 友好提示）；
  - **DeepL**：设置页填 Auth-Key（免费版 `:fx` 后缀自动走 api-free 端点）；
    **不支持粤语/文言文**目标语言（mapTarget 返回 null → 友好错误提示）。
  引擎经 `TranslateEngineDef` 注册表分派（mapTarget/请求构造/解析/网络提示
  四件套），requestUrl 绕 CORS；凭据缺失在入口处中文报错。
- **存为留白**：译文以留白胶囊放在**原文正下方**（㊹ 色随「留白」工具当前色系）
  并排对照；它是一张
  普通卡片（可编辑标题/批注/转闪卡/拖入脑图/自动收录），无任何新数据概念。
- **留白折叠（83-F 轻量版）**：胶囊 = 单行 ellipsis 标签（替代 JS 40 字截断）
  + chevron 小钮（stopPropagation 不触发点击菜单）；展开态多行全文
  （32em / 30vh 内滚动）；展开态会话级 Set 记忆不持久化。
- **复制**：译文一键进系统剪贴板。
- **限制**：无文字的卡（照片/语音、未 OCR 的区域/手写）不出现翻译入口；
  单次上限 5000 字符；凭据明文存插件数据文件。

## AI 服务（96 P0 基础设施，已实现；P1-P5 功能批次推进中）

OpenAI / oneapi 系中转站等），后续 AI 功能（划选操作/文档问答/制卡/脑图

  **自动降级整包返回**（进程内记住，不再反复试错）；可强制关闭。
- **上下文 token 预算**（2000-200000，默认 24000）：文档问答/摘要送入内容
  的裁剪上限（中文约一字一 token 的估算口径）。
- **AI 制卡自动转闪卡**（默认开）：AI 生成卡片的复习队列开关（制卡入口见
  下文 99 P3 节）。
- **累计用量**：请求次数与输入/输出 token（流式为估算值），可清零。
- **凭据安全**：API Key 明文存于插件数据文件（与翻译凭据同惯例），请勿在
  共享库中使用。

## 多窗格工作区与拖拽入图（v1，79 全面优化）

- **学习模式工作区**：命令一键布局——左侧阅读器 + 右侧复习窗格（自动开始到期会话）。

  阅读侧滚到原文 + 脑图侧定位节点（卡片不在当前图时自动切图），翻面去重、

  duplicateLeaf 对延迟加载后台标签的 state 搬运需实机验证（失败自动回退手工
  搬运）；隐藏侧缓存不记缩放（只恢复页码）；触摸拖卡建议真机验证。

## 网页剪藏为笔记文档（113，已实现）

把网页正文保存为库内 Markdown 笔记——自研零依赖（不引入 turndown/readability
库），全平台（桌面/移动端）可用。

- **三入口**：命令面板「保存网页为笔记文档」、主页侧栏底部「剪藏网页」、
  弹窗内 Enter 直达；URL 自动补 `https://`、协议白名单、去锚点片段。
- **正文提取（readability-lite，115 四项加固）**：剥 script/nav/aside/footer
  及**隐藏 UI**（modal/dialog/popup/drawer/aria-hidden）等噪声 → 语义候选
  （article/main/[role=main]）**并入统一评分不再首个早退**（多 article 站的
  侧栏推荐卡不抢跑）→ 评分 = 文本量（封顶）+ 段落数 + 类名关键词 − **负向
  关键词强扣**（sidebar/comment/recommend…，`side-content` 判负不误加分）+
  语义加分 + 链接密度惩罚 + 文本密度；**成段正文门槛**——按分降序取首个
  p/blockquote/pre 文本 ≥120 字的候选，全不过（正文由脚本渲染的整页壳，
  如 gitee 仓库页）**诚实报错**返回 null，不写半截文件；body 仅作终极兜底
  （老式手写页段落直接挂 body 时）。
- **DOM→Markdown 白名单转换**：标题/段落/嵌套列表/引用/围栏代码块（class 语言
  推断）/GFM 表格（| 转义、colspan 平铺）/figure；文本转义特种字符 + 行首
  标记符防误解析（正文里 "# " 开头的普通文字不会变标题）。
- **图片本地化（两遍法）**：转换期占位符 `__MMIMG_n__` 收集引用（URL 绝对化、
  懒加载 data-src、data: URI），服务层并发 3 下载（≤20 张、单张 ≤20MB）经
  `attachments.save` 落数据根 `assets/` 后回填相对路径引用；失败与超限自动回退
  **远程链接**；CT 为 HTML 错误页判失败不存假图；入库压缩复用照片管线
  （>300KB 转 WebP）。
- **编码识别**：BOM → Content-Type charset → 前 4KB meta 扫描 → utf-8 容错，
  GBK 老站可解（字节级单测覆盖）。
- **产物（124 数据根落盘）**：数据目录 `clips/<标题>.md`（与 books/、
  mindmaps/ 同级的剪藏子目录，无需配置）+ 图片统一 `assets/`（附件审计保留
  集扫描 clips md 引用，不判孤儿）；打开走 reader clip kind（图片渲染经
  blob URL 替换，不依赖 embed 相对解析）；frontmatter 记 `source`（原网址）/
  `clipped`（时间），**无 `marinmind:` 键**（book-format 不误认领为书文件）；
  同名冲突 `-2` 递增。旧库 vault 内 `WebClips/` 存量启动自动迁移
  （webclip-migrate，documentId 保留卡片回链无损）。
- **全链路复用**：剪藏 md 即普通文档——打开自动登记、划选/区域/套索摘录
  （DOM 快照含嵌入图）、目录、转闪卡、复习回链、备份全部与 md 文档一致。
- **框选剪藏（116）**：剪藏弹窗内「框选剪藏…」次按钮——网页在弹窗内
  srcdoc 沙箱 iframe 预览（`sandbox="allow-same-origin"` 无 allow-scripts，
  站点脚本不执行但插件可解析 DOM；X-Frame-Options/CSP 不约束 srcdoc，任意
  站点可预览），「框选区域」后拖框/单击选目标（命中元素蓝框高亮 + 标签
  提示，拖框自动上溯到覆盖 ≥95% 的正文容器、单击直取命中最深元素，可反复
  重选），确认后 domToMarkdown + 图片本地化 + 落盘全复用自动模式管线——
  所选即所得，绕开「算法猜正文」；已知限制：纯 JS 渲染页预览同为空壳。

## 核心设计

### 以"卡片"为中心的数据模型

摘录即卡片，卡片既是脑图节点又是闪卡——**一份数据三种用途**（脑图、复习、回链原文），这是区别于普通阅读器的核心设计。

当前落地的数据模型（`src/types.ts`）：

- **BookDocument（文档）**：被阅读的书籍（PDF/EPUB/MOBI 家族/Markdown），以库内路径或库外绝对路径为唯一业务键；
  含分类字段 `category`（㉟ 主页虚拟文件夹，㊲ 起支持 `/` 多层路径，null=未分类）。
- **Card（知识卡片）**：由摘录生成，携带原文回链（PDF 页码 + 归一化矩形列表，
  与缩放/设备无关），支持七种摘录形态：文字 / 区域 / 套索 / 留白 / 手写 / 语音 / 照片。
- **DocumentBookmark（文档书签，㉓）**：用户手动添加的阅读位置标记（页码 + 自定义标签），
  目录侧栏展示与跳转。
- **CardLink（双向链接）**：卡片间手动建立的关联，两个方向等价。
- **Mindmap / MindmapNode（脑图）**：节点 = 卡片在图中的引用（父子 + 坐标），
  同一卡片可出现在多张图中；删除卡片级联删节点，删除中间节点子节点上浮为根。
- **ReviewState（复习状态）**：闪卡调度数据（SM-2：ease / interval / repetitions /
  lapses / dueAt；FSRS 模式下另有 stability / difficulty，103-A 起可切换），卡片需
  显式"转为闪卡"才进入复习队列。

### 原文双向回链

卡片记录 `page + rects`（归一化矩形），脑图节点与复习界面都能跳回 PDF 原位置，
复习时可回看上下文。

### 面向学习流程

不只做标注，还内建记忆算法（SM-2 与 FSRS-4.5 双算法可切换，103-A 起），
把阅读笔记变成可复习的记忆资产，覆盖预习—上课—复习—演练—长期记忆全流程。

## 存储与备份

- 笔记数据（卡片、链接、复习状态、文档元数据）以 **Markdown 文件**存储（㉚）：
  **每书一文件**（`books/<书名>.md`，内含摘录卡片/批注/书签/复习进度）、
  **一图一文件**（`mindmaps/<图名>.md`，嵌套列表即节点树）、**网页/屏幕剪藏**
  （`clips/<标题>.md`，124 起）——可直接在 Obsidian 中
  浏览、搜索、打标签，支持 git/同步盘版本管理；手动编辑批注/文本/标签后保存即自动回灌。
- 数据目录默认库内 `MarinMind/`，写入防抖分文件落盘；媒体附件存同目录 `assets/`。
  极老版本（SQLite 存储）用户需先用旧版插件迁移（129 批起旧库导入通道已移除，
  sql.js 不再打包，main.js 瘦身约 1MB）。
- **设置页（已实现）**：数据目录与备份目录可配置——桌面端支持本机绝对路径
  （可把数据迁出 Obsidian 库/同步盘），移动端仅库内路径。数据目录修改走
  「应用并迁移数据」：复制式迁移（旧位置保留作为回退，失败无损失），完成后自动重载；
  备份目录修改即时生效。
- **备份 `.marginpkg`（已实现）**：命令「导出备份」把全部笔记 md 文件 + 全部文档 PDF +
  媒体附件打成单个 zip 包，写入备份目录（默认库内 `Backups/MarinMind/`，文件名含时间戳）；
  「导入备份」经系统文件选择器选包 → 确认后整库替换（当前数据自动快照到数据目录
  `pre-import-snapshot/`，库内已存在的 PDF 跳过不覆盖）→ 自动重载生效。
  旧版 v1 备份包（SQLite 形态）已不再支持导入（129 批移除转换通道，导入时明确报错）。
  包损坏 / 来自更新版本插件 / 含非法路径时拒绝导入，原数据无损。
- **文档管理面板（已实现）**：列出全部文档记录与失联状态（文件已不在库中的记录
  标红）；失联文档一键**重关联**到新位置——卡片、复习进度、脑图节点全部原地保留；
  或删除无用记录（级联清理卡片/附件/复习状态，确认弹窗写明影响范围；书籍
  PDF/EPUB 文件本身保留）。**126 起主页文档右键「删除文档…」同款单源实现**
  （doc-delete.ts 共用，且对正常文档开放）。
  vault 内文件移动/改名由全局监听自动跟随（文件删除刻意不级联——Obsidian 删除可撤销，
  不应不可逆地蒸发笔记数据）；**库外文件同目录改名由 fs watcher 自动跟随（㊳）**，
  库外文档另有「复制入库」转正入口（面板按钮 + 主页右键）。
