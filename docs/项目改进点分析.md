## 一、发布上架（P0 —— 唯一进行中的里程碑）

**物料定稿度：100%。** manifest.json（id 唯一 / version 1.0.0 / 英文 description
动词开头句号结尾 149 字符 / isDesktopOnly=true 与 Node·Electron 使用相符 /
无 fundingUrl）、LICENSE（MIT）、版本一致性（manifest = package.json =
versions.json：1.0.0 / minAppVersion 1.7.2）、release.yml（tag↔manifest 强校验
→ 干净构建 → 三件套）全部就绪。

**流程卡点：停在第二步之前——本仓库无 git remote**（`git remote -v` 为空）。
docs/发布与上架流程.md 九步中 ② 以后全部未动，后续 CI / tag / BRAT / 社区
提交全部被堵。待办序：

1. 创建 GitHub 公开仓库 `xiewangsun/marinmind`（与插件 id 一致）+ push main；
2. 确认 ci.yml（lint / format / test / build）首跑全绿；
3. `git tag v1.0.0 && git push origin v1.0.0` → 核对 Release 三件套
   （main.js / manifest.json / styles.css）与 tag=manifest version；
4. BRAT 真机内测（Add Beta plugin → 核心链路：导入 → 摘录 → 脑图 → 复习）；
5. community.obsidian.md 提交（人工审核积压数周至数月，早提交早排队）。

**README 三小补（随下次提交带上，前两项影响审核观感与通过速度）：**

- **截图缺失**：README.md:7 自带 `<!-- TODO: add screenshots -->`——主页 /
  阅读器摘录 / 脑图 / 复习四张，放 `./images/`；
- **desktop-only 未显式披露**：正文只在数据目录节顺带提 "desktop
  installations"；建议 Features 表后加一句（依赖 Node.js/Electron：文件系统、
  系统托盘、原生窗口截图）；
- **网络披露缺剪藏行**：Network usage 表（README.md:55-64）漏了网页剪藏——
  会抓取用户输入的任意网址并从其图床下载图片，属审核方关注的网络行为。

## 二、安全与隐私（P1 —— 无高危，两条小改）

**总评**：代码安全意识显著高于社区插件平均水平——EPUB 白名单净化
（epub-session.ts:321-412：20 标签 DROP + 双白名单 + on\*/style 剥除 + URL
一律不透传）、剪藏文件名净化（clip-naming.ts:42-68：非法字符/Windows 保留名/
80 字符截断）、目录校验（paths.ts:52-72 拒 `..`/绝对路径/.obsidian）均为
教科书级实现。以下为审查确认的全部改进项：

- [x] **settings 凭据输入框明文显示**（140 已实现）：百度密钥（settings-tab.ts
      ~345）、有道（~371）、DeepL（~389）、Tavily（~596）、博查（~612）五处
      补 `text.inputEl.type = "password"`（noAssist 原有防线不变）。
- [ ] README Network usage 表补剪藏行（同第一节，安全维度同一件事）。
- [ ] **（长期可选）OCR worker 供应链面**：worker/core 从 jsdelivr 远程加载
      （ocr-service.ts:21-24），CDN 污染即注入代码；已做缓解是版本严格锁定

      仅指 worker/core 两个小 JS 的本地打包，社区有先例；现阶段锁定已可接受，
      观察项。

**已确认无风险（不列为待办，防重复审查）**：innerHTML 全库仅 3 处且全安全
（doc-search 转义纪律有注释、review 缩略图五实体 esc、AI 回复走
